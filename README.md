# 机器人关节电机 · 实验室分层底层系统（交接版）

**定位**：实验室统一维护的**分层电机底层系统**——在粗糙实验硬件上开发并验证了功能主体（标定 S0–S8 / 参数 Flash 固化 / 电流闭环 FOC-4 验收通过 / 速度环代码就绪待编码器换新收尾）。**换芯片只动板级与驱动两层，算法与流程层免改**；上位机与上层控制算法（位置环/轨迹/多机）在此基座上交叉适配——接入契约与新芯片适配指南见[仓库主文档](STM32F103C8T6_BASE/README.md) §9/§10。

## ⚠️ 安全红线

- **供电严禁超过 10V（12V 烧毁驱动板）**；
- 上电默认功率失能；一切功率步骤须人工按 `p` 确认；
- 台面硬件为实验形态（杜邦线/转接板），接线后必按原理图复核再上电。

## 快速上手（新人 30 分钟剧本）

1. **读交接主文档**：[STM32F103C8T6_BASE/README.md](STM32F103C8T6_BASE/README.md)——硬件构成、双 Target 架构、构建/烧录、串口命令速查、验收链，全在那一篇；
2. **构建**：Keil 打开工程切 target（测试固件=标定 / `F103-run`=运行+速度环），或 `MDK-ARM/_build_cli.cmd <target>` 命令行；烧录后串口 115200；
3. **首航**：F103-run 上 `p`（零流使能）→ `s`（速度模式）→ `+++`（n*=60rpm）——完整命令表见主文档 §4。
