# STM32F103C8T6 硬件基线冻结测试工程

## 工程用途

本工程是《STM32F103C8T6 电机控制基线适配说明》对应的冻结测试实现。

它将基线文档中定义的 MCU 引脚、三相 PWM、功率使能、ADC 电流采样、MT6701 编码器和串口诊断链路固化为一套可重复构建、下载和运行的测试程序，用于快速检查电机控制硬件基础链路是否正常。

当电机系统出现无法启动、PWM 无输出、驱动无法使能、停止无效、编码器无数据、电流采样异常或串口无日志等问题时，应优先下载本工程，通过串口日志、示波器和基础开环测试判断问题是否位于以下范围：

- 供电、共地、限流和接线；
- STM32 引脚映射与转接板连接；
- PWM、`MOTOR_EN` 与驱动板接口；
- ADC 电流采样链路；
- MT6701 编码器及 I2C 通信；
- 驱动板、电机或功率级硬件。

本工程不承担正式电机控制功能，不作为 FOC、速度环、位置环或产品控制器的持续开发工程。

## 冻结原则

本工程对应已经确定的基线接口，原则上不持续增加控制功能，也不随 FOC 开发过程修改。

后续工程发生问题时，应使用本工程进行对照测试：

- 本工程正常：基础硬件链路大概率正常，应继续在后续工程的控制算法、参数、相序、采样标定或状态机中排查。
- 本工程异常：优先检查硬件供电、接线、引脚映射、PWM/使能接口、ADC、编码器、驱动板和电机本体。
- 硬件接口或基线定义发生变化：先更新基线文档，再建立新的冻结测试版本；不要直接修改当前冻结工程。

## 当前测试能力

- 安全上电：`MOTOR_EN` 保持低电平，功率驱动关闭；TIM2 三相 PWM 比较值清零；M1 未使用通道保持低电平。
- 串口诊断：USART1 输出启动信息、版本号和静态诊断结果。
- ADC 检查：读取两路相电流采样的原始 ADC 值。
- 编码器检查：通过 I2C2 检查 MT6701 是否响应，并读取 14 位角度原始值。
- PWM 与使能检查：支持显式启动短时、低速、低调制度的三相开环 SVPWM。
- 安全停机：接收停止命令、运行超时、ADC 异常或编码器通信异常时，关闭驱动使能并停止 PWM 输出。

## 硬件与引脚

| 功能 | 外设/引脚 |
| --- | --- |
| 三相 PWM（M0） | TIM2 CH1/CH2/CH3：PA0、PA1、PA2 |
| 电机使能 | PA8，`MOTOR_EN`，高电平使能 |
| 相电流采样 | ADC1_IN8 / PB0、ADC1_IN9 / PB1 |
| MT6701 编码器 | I2C2：PB10（SCL）、PB11（SDA） |
| 串口日志 | USART1：PA9（TX）、PA10（RX），115200 8N1 |
| 状态 LED | PC13 |

系统时钟为 72 MHz，TIM2 的 ARR 为 3599，对应约 20 kHz PWM。

## 串口命令

| 命令 | 说明 |
| --- | --- |
| `s` 或 `S` | 请求开始一次短时低速开环测试 |
| `x` 或 `X` | 停止测试并回到安全态 |
| `c` 或 `C` | 清除故障并回到安全态 |
| `?` | 输出当前控制状态和故障状态 |

开环测试流程：先以低调制度对齐 300 ms，再从 5 Hz 起步，于 1 s 内升至 20 Hz；总运行时间最长 3 s。发生超时或异常时，程序进入故障态并关闭输出。

## 编译与下载

1. 使用 Keil MDK 打开 `MDK-ARM/STM32F103C8T6_BASE.uvprojx`。
2. 编译工程并生成 Hex 文件。
3. 使用 ST-Link 通过 SWD 下载。
4. 连接串口工具，设置为 115200 baud、8N1。
5. 上电后先检查启动日志和静态诊断结果；确认硬件状态正常后，再发送 `s` 进行空载开环检查。

CubeMX 配置文件为 `STM32F103C8T6_BASE.ioc`。

## 安全限制

- V3P 驱动板供电不得超过 10 V，禁止接入 12 V。
- 首次测试必须空载进行，并使用限流电源、急停和必要的机械防护。
- 当前 ADC 仅用于读取两路相电流原始值，尚未完成零偏、比例、方向和量程标定，不可作为精确电流值或正式保护依据。
- 当前未接入母线电压 ADC，无法提供软件过压或欠压保护。
- PWM 时序、死区适配和驱动实际失能响应仍应以示波器和实机测试结果为准。
- 本工程仅用于硬件基础链路检查和低风险测试，禁止用于闭环 FOC、带载运行、长期运行或无人值守运行。

## 目录说明

- `Core/Src`：测试程序、诊断、开环控制和硬件适配代码。
- `Core/Inc`：对应模块头文件与板级配置。
- `Drivers`：STM32 HAL 与 CMSIS 驱动。
- `MDK-ARM`：Keil 工程和构建产物。
- `STM32F103C8T6_BASE.ioc`：STM32CubeMX 工程配置。
