### 5.4 S3 电感辨识重设计规格（随 F4/G4 迁移实施，2026-09-16 入档）

**背景**：现 S3 差分斜率法三靴 iqr_ratio=4.33/2.36 越限（门限 0.25），长期回退标称 0.86mH（见标定报告 FR-1.4/D7）。理论实算（V=2V、R=3.46Ω、τ≈0.25ms、Ts=0.1ms、σᵢ≈13mA）：差分法单样本误差 10%→32% 随拍数快速退化（√2 差分噪声÷指数衰减的小分母），对数法 6~8% 平坦且每样本独立进噪声——且 `ln(V−R·i) = lnV − (R/L)·t` 对 t **严格线性**，直线拟合直接复用现成 `calib_least_squares`。方法谱系：trig 快表=函数级近似（模型精确）；旧 S3 斜率法=模型级近似（有损）；本方案=对数域变换（模型精确）+ 函数级近似（查表），两者合流。

**重设计内容**：

1. **激励**：电流环阶跃 → **开环恒压阶跃**（对数法成立前提=恒定 V；幅度由 S2 实测 R 反推，限 1A 红线内）；
2. **估计器**：差分斜率 → **对数线性最小二乘**。单一真值源变量：`y = (V−R·i)/V`，样本门 `y ∈ [0.30, 0.75]`（避开 x→1 与 x→0 两个病态区），V 用 `V−Voff` 修正（Voff 取 S2 拟合截距，此点优于 SimpleFOC 的 correction_factor 手调）；拟合 `ln(V−R·i_k)` 对 `t_k = k·Ts` 的直线，斜率 b 满足 `L = −R·Ts / b`；常数 lnV 不影响斜率可省略；
3. **加权**：`w_k ∝ y_k²`（σ_z = (R/V)·σᵢ/y ∝ 1/y，只需平方不需除法）；
4. **每脉冲前插零矢量参考**，差分消零偏/温漂；
5. **多脉冲重复取中位数**（独立噪声按 1/√N 收缩）。

**log 实现分支注记**：

- **F4/G4（带 FPU）**：直接 `logf`——标定非实时（慢路径 EVAL 阶段，几十~几百次调用），Flash 充足，无压力；
- **C8T6 若需复跑**：**不链 libm logf**（软浮点连包装约 1~2KB，测试 target ROM 余量 1136B 装不下）。用 **32 点 ln(y) 查表 + 线性插值**：表覆盖 `y ∈ [0.25, 0.80]`（样本门外加余量），float 存表 ~128B（Q15 存 64B，差别非决策点），加插值与 LS 共几百字节。插值误差上界按 `|f''|max = 1/y² = 16`（y=0.25 处）计约 **0.06% ≪ 6% 测量噪声地板**，符合《05_详细设计/08_ISR计算重构需求》设计原则四"精度预算内近似"（trig 快表同款纪律）；
- **表生成与验收**：PC 端生成静态表 + 对拍 libm 单测，沿用 trig 表验收格式（`tests/pc/test_foc_trig_table.c` 先例）。

**迁移后首验判据**（随 README §9 回归序列用真实数据验证）：三靴 iqr_ratio ≤ 0.25 且 L 落 0.5~2 倍标称。
