## 2. 后继路线图（按建议优先级）

### 2.1 收尾即做（编码器到货后）

1. 换 MT6701 → README §7 验收链 → 速度环 kp/ki 整定 → **FR-4.5 四项指标回填 SPEC-RUN**（稳态误差带/超调/调节时间/最低平稳转速）；
2. 稳定一周 → 收回诊断姿态（问题 #2）→ 复验；
3. git 打 `v0.5-demo-handover` 终版标签。

### 2.2 R3 剩余（运行态完善，证据已立项）

| 项 | 内容 | 证据/动机 |
| --- | --- | --- |

### 2.3 R5 及以上（新里程碑）

- **位置环（FOC-6）**：SPEC-RUN §7 已立边界（位置环输出速度目标、不得直接给 iq/操作 PWM）——**上层算法项目从这里接入**（读 README §10 契约）；
- **CAN 总线/多关节**：当前零代码，属机器人整机层需求；FR-3.6 注册式指令 hook 是它的固件侧预留；
- **上位机**：速度环遥测行格式（`[RUN] id/iq/n/n*`）已可被脚本解析，上位机从此处接入；
- **多芯片适配**：按 README §9 五步指南（板级+驱动两层），首个新芯片适配建议从同家族（F103→F103 高型号或 F4）起步，跑测试固件全序列做回归。

### 2.4 建议不做 / 慎做

- **不再升 I2C 频率**（问题 #4）；
- 测试固件不再加大功能（ROM 余量问题 #5），新功能进 F103-run（28KB 余量）；
- 冻结基线目录勿改（回退锚点，readme 有变更记录制度）。

## 3. 硬件组需求清单（本周硬件斗争的教训凝结）

| # | 需求 | 动机（本周实证） |
| --- | --- | --- |
| 1 | 编码器线改**带屏蔽双绞/排线+可靠连接器**（告别杜邦线） | I2C 间歇失败/深挂的土壤；摇线试验方法论见经验10 |
| 2 | 编码器供电**独立 LDO/强去耦** | 受损编码器拖垮 3.3V 轨连带 ADC 劣化——单点故障变全系统故障 |
| 3 | 板间连接（转接板↔驱动板）**固定连接器化** | 接触劣化同时打击 I2C 与模拟采样（共地路径） |
| 4 | PCB 化整机（或至少 MCN 板） | 三块板+飞线的台面是全部 EMI 问题的放大器 |
| 5 | 预留编码器**机械固定+磁环间隙规范** | 振动下磁环/接线松脱（455rpm 急停×2 后开始劣化） |
