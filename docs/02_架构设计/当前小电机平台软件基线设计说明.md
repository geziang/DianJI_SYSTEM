# 通用电机控制软件基线设计说明

> 原文件名保留为 `当前小电机平台软件基线设计说明.md`，但文档定位已调整。  
> 新定位：面向 BLDC/PMSM 电机控制的软件基线，而不是某套硬件的专用工程说明。  
> 当前参考平台 A：STM32F103C8T6 + DengFOC V3P/V3Pro + 2804 电机 + MT6701。

---

## 1. 基线目标

本基线定义一套可移植、可验证、可逐步扩展的电机控制软件基础。它应满足：

- 默认上电安全失能。
- 硬件差异收敛到板级配置和适配层。
- ADC 电流采样、母线采样、PWM/SVPWM、功率使能、位置反馈具有清晰接口。
- 控制状态机、故障管理、诊断、参数和测试流程可以跨硬件复用。
- 每一级能力都有明确进入条件、退出证据和禁止使用边界。

本基线不是一次性测试程序，也不是最终完整关节控制器。它是后续 FOC、电流环、速度环、位置环、通信协议和关节应用继续生长的技术底座。

---

## 2. 适用范围

### 2.1 适用对象

本基线适用于满足以下信号模型的电机控制系统：

- BLDC/PMSM 三相电机。
- 三相逆变或等价功率级。
- 至少一套可控 PWM 输出链路。
- 至少一套电流采样链路，推荐两相或三相电流采样。
- 可测量或可估算母线电压。
- 有功率级使能/失能路径。
- 有位置传感器、速度传感器、Hall、无感估算或其他转子状态来源。
- MCU 或控制器算力满足控制周期和故障响应要求。

### 2.2 不适用或需降级的情况

以下情况不能直接套用本基线：

- 无法安全失能功率输出。
- PWM 与 ADC 无法满足目标控制周期。
- 电流采样比例、偏置、极性不可确认。
- 功率级没有可解释的故障和保护边界。
- 位置反馈延迟、噪声或异常行为不满足闭环要求。
- 目标硬件只能做低速开环，不能承载 FOC 或伺服闭环。

## 3. 平台分层

| 层级 | 主要职责 | 当前代码对应 |
| :--- | :------- | :----------- |
| 应用入口 | 初始化顺序、主循环钩子、模式入口 | `app_baseline` |
| 控制状态机 | 安全空闲、测试模式、运行、停止、故障 | `control_loop`，后续扩展 |
| 诊断与遥测 | 启动日志、静态检查、周期监控、故障快照 | `baseline_diag`、`debug_log` |
| 功率级抽象 | 使能、失能、安全态、故障输入 | `motor_drv` |
| PWM 输出 | 三相 PWM 启动、停止、compare 限幅 | `motor_pwm` |
| 电流/电压采样 | 原始 ADC、零偏、比例、有效性、时间戳 | `motor_adc`，后续扩展 |
| 位置传感器 | 原始角度、状态、方向、错误检测 | `mt6701`，后续抽象化 |
| 板级适配 | 外设句柄、GPIO、电平极性、周期常量 | `board_config` |
| CubeMX/HAL | MCU 外设初始化和底层库 | `main.c`、HAL 驱动 |

核心原则：

- 上层不直接依赖 `hadc1`、`htim8`、`GPIO_PIN_x` 等硬件细节。
- 控制算法只接收物理量、状态和有效标志。
- 适配层负责把具体硬件转成平台接口。
- CubeMX 生成代码只提供外设初始化，不承载平台业务逻辑。

## 4. 硬件适配契约

### 4.1 MCU 与外设能力

| 能力 | 平台要求 | 当前参考平台 A |
| :--- | :------- | :------------- |
| 主频 | 控制周期内完成采样、控制、保护和通信预算 | STM32F103 72 MHz，当前先做基线和低速空载实验 |
| PWM | 三相输出，频率、极性、占空比可控 | TIM2 CH1/CH2/CH3 |
| ADC | 电流、母线采样，后续可同步触发 | ADC1 IN8/IN9 两相原始采样，VBUS 当前不可用 |
| 时间基准 | 周期调度和超时判断 | SysTick，后续可升级定时器 |
| 位置接口 | I2C/SPI/ABI/Hall/Observer 之一 | I2C2 + MT6701 |
| 通信诊断 | 日志、命令或遥测入口 | USART1 |
| GPIO 安全 | 使能脚和危险输出默认安全 | PA8，高电平使能、低电平失能 |

### 4.2 功率级能力

功率级适配必须回答：

- 三相输入信号的有效电平、允许频率和死区要求。
- 使能脚有效极性、默认态和硬件上下拉。
- 是否有故障输出，故障是否锁存。
- 电流采样电阻、放大倍数、偏置、极性和线性范围。
- 母线采样分压比、滤波、有效范围。
- 失能到相端关闭的最大延迟。
- 上电、掉电、复位、MCU 未初始化时的功率输出状态。

### 4.3 电机与传感器能力

电机和传感器适配必须回答：

- 极对数、相序、方向定义。
- 相电阻、相电感、磁链或等价辨识参数。
- 连续电流、峰值电流、热边界和测温位置。
- 编码器分辨率、方向、零位、延迟、跨零和异常状态。
- 机械限位、减速比、输出侧方向和应用限幅。

## 6. 驱动接口契约

### 6.1 功率使能

功率使能接口必须满足：

- 初始化默认失能。
- 故障处理优先调用失能。
- 使能入口命名必须体现测试或受控条件。
- 软件状态只能表示写入意图，不能替代硬件反馈。
- 使能前必须确认 PWM 已处于安全占空比。

当前代码：

- `motor_drv_init_safe()`
- `motor_drv_disable()`
- `motor_drv_enable_for_test()`
- `motor_drv_get_state()`

### 6.2 PWM 输出

PWM 输出接口必须满足：

- 启动前 compare 清零。
- 停止后 compare 清零。
- 原始 ticks 设置必须检查周期上限。
- 后续 SVPWM 输出先由调制层计算，再进入 PWM 输出层。
- PWM 层不包含 FOC、速度环或位置环逻辑。

当前代码：

- `motor_pwm_init_safe()`
- `motor_pwm_force_zero()`
- `motor_pwm_start_test_output()`
- `motor_pwm_stop_output()`
- `motor_pwm_set_raw()`

### 6.3 电流与母线采样

采样接口分两级：

1. 原始采样：只保证 ADC 通道能读数。
2. 物理量采样：加入零偏、比例、单位、时间戳和有效性。

当前 BL1/BL2 允许先使用阻塞式单次转换。进入 FOC 和高速电流环前，应升级为 PWM 同步触发、DMA 或中断方式。

采样链必须验证：

- 零电流偏置。
- 正负方向。
- 比例系数。
- 噪声和温漂。
- 饱和边界。
- 与 PWM 触发点的时序关系。

### 6.4 位置反馈

位置反馈接口不应绑定某个具体芯片。当前 F103 适配绑定 MT6701，平台层需要的是：

- 机械角度。
- 电角度或可计算电角度。
- 速度估计。
- 数据时间戳。
- 有效标志和错误原因。

MT6701 是当前第一套 `RotorSensor` 实现。其 I2C 读取已纳入基线诊断；进入高速闭环前仍需单独评估读取延迟和控制周期预算。

## 7. 控制链路

控制链路按阶段启用：

```text
安全空闲
  -> 静态诊断
  -> PWM 受限测试
  -> 开环电角度扫描
  -> 传感器方向/相序/极对数确认
  -> FOC 角度对齐
  -> 电流环
  -> 速度环
  -> 位置环
```

每一步都必须具备：

- 进入条件。
- 限幅条件。
- 超时条件。
- 立即停止条件。
- 记录信号。
- 退出证据。

控制算法输出不能直接写硬件。推荐路径：

```text
控制目标
  -> 限幅与有效期检查
  -> 控制环计算
  -> 电压矢量
  -> SVPWM
  -> 三相 duty/ticks
  -> PWM 输出层
  -> 功率级
```

## 8. 生命周期状态机

建议平台状态：

| 状态 | 功率输出 | 说明 |
| :--- | :------- | :--- |
| `BOOT` | 禁止 | MCU 和外设初始化 |
| `SAFE_IDLE` | 禁止 | 默认安全态 |
| `STATIC_DIAG` | 禁止 | ADC、编码器、状态检查 |
| `PWM_TEST` | 受限 | 验证 PWM 与失能路径 |
| `OPEN_LOOP_TEST` | 严格限幅 | 验证相序、方向、极对数 |
| `ALIGN` | 严格限幅 | 电角度和传感器对齐 |
| `CLOSED_LOOP` | 已验证边界内 | 电流/速度/位置闭环 |
| `STOPPING` | 逐步降输出 | 受控停止 |
| `FAULT` | 禁止 | 故障锁存，等待恢复条件 |

禁止从 `BOOT`、`SAFE_IDLE` 直接跳到高功率闭环。任何功率输出状态都必须可被故障路径立即打断。

## 9. 参数与标定

参数分为四类：

| 类型 | 示例 | 迁移规则 |
| :--- | :--- | :------- |
| 平台参数 | 控制周期、状态机策略、故障等级 | 尽量复用 |
| 硬件适配参数 | ADC 比例、PWM 周期、使能极性 | 换硬件必须重建 |
| 电机参数 | 极对数、Rs、Ls、磁链、限流 | 换电机必须重建 |
| 应用参数 | 减速比、限位、速度/位置边界 | 换应用必须重建 |

当前 2804 电机实验参数（图片标称值）：

| 参数 | 初始值 | 用途与限制 |
| :--- | :--- | :--- |
| 槽极数 / 极对数 | 12N14P / 7 | 开环电角度初始值；相序和方向通过试验确定 |
| 电机资料电压范围 | 7.4~20 V（图片标称） | 不代表 V3P 允许范围；当前 V3P 供电不得超过 10 V |
| 最大电流 | 1 A（按持续电流处理） | 实际空载预计低于 1 A；硬件限流优先 |
| KV | 约 220 RPM/V | 速度趋势参考，不替代实测 |
| 绕组电阻 | 5.1 ohm | 图片标称，测量定义待补充 |
| 相电阻 Rs | 2.3 ohm | 图片标称，FOC 前需统一测量定义 |
| 绕组电感 | 2.8 mH | 图片标称 |
| 相电感 Ls | 0.86 mH | 图片标称 |
| 磁链 | 0.0035 Wb | 图片标称，暂不用于当前基线 |
| 标称转速 | 约 2600 RPM / 12 V（图片标称） | 仅作电机资料参考；V3P 实验禁止接 12 V |
| 工作温度 | 0~60 degC | 实验温升边界参考 |

图片参数属于实验初始值。当前 V3P 驱动板电源上限为 10 V，12 V 供电可能烧毁驱动板；实验应从更低电压开始并使用限流。当前阶段不因参数未完全标定而阻塞基线，但不得据此宣称已具备精确 FOC 保护或最终性能。

每个参数至少需要：

- 名称。
- 单位。
- 数据类型。
- 默认值。
- 有效范围。
- 来源。
- 适用硬件。
- 版本。
- 是否需要标定。

禁止把未测量的经验值写成保护阈值或闭环冻结参数。

## 10. 故障与保护

故障管理至少覆盖：

| 故障 | 检测来源 | 默认动作 |
| :--- | :------- | :------- |
| 过流 | ADC、功率级故障脚 | 立即失能并锁存 |
| 母线过压 | Vbus ADC | 停止输出，必要时锁存 |
| 母线欠压 | Vbus ADC | 禁止使能或受控停止 |
| 编码器异常 | 传感器状态、跳变、超时 | 禁止闭环 |
| 通信超时 | 命令有效期 | 受控停止或失能 |
| PWM/使能异常 | 状态回读或诊断 | 禁止功率输出 |
| 参数无效 | CRC、版本、范围 | 禁止进入运行 |
| 控制饱和 | 控制环监测 | 限幅、降级或故障 |
| 过温 | 电机/驱动温度 | 降额或停止 |

故障处理原则：

- 第一故障原因必须保留。
- 故障发生时记录快照。
- 恢复条件必须独立于触发条件。
- 未查明故障不得自动重使能。
- 软件保护不能替代硬件安全链。

## 11. 诊断与遥测

诊断数据应服务于技术判断，而不是堆日志。

最低遥测：

- 固件版本。
- 平台适配 ID。
- 当前状态。
- 功率使能状态。
- PWM compare/duty。
- ADC 原始值。
- 电流/电压物理量，完成标定后启用。
- 编码器原始角度、状态、错误。
- 最近故障码和故障快照。
- 控制周期计数和最大执行时间。

实时路径中禁止阻塞式大量日志。调试输出应按低频、采样缓冲或事件触发方式组织。

## 12. 分阶段验收

| 级别 | 目标 | 通过标准 |
| :--- | :--- | :------- |
| BL0 | 可构建、可下载 | 干净工程可重复构建，版本可识别 |
| BL1 | 安全启动 | 上电、复位、下载后功率输出保持安全 |
| BL2 | 静态测量 | ADC/编码器原始链路可读，有原始记录；未标定物理量不作精度承诺 |
| BL3 | PWM/失能接口 | 当前按条件通过处理；开环异常时回溯 PWM、使能和功率级 |
| BL4 | 受限开环 | 电机能够按受限条件动作，停止边界有效 |
| BL5 | FOC/电流环 | 当前阶段暂缓，作为后续实验目标 |
| BL6 | 速度/位置基础 | 在已验证边界内稳定运行 |

每一级关闭需要：

- 固件版本。
- 硬件适配版本。
- 参数版本。
- 接线和供电条件。
- 原始数据或波形。
- 失败路径测试。
- 已知限制。

## 13. 当前参考平台 A 的首轮验证顺序

首轮顺序仍按低风险推进：

1. 只连接 MCU、电源、SWD，确认下载和默认安全态。
2. 打开 USART1 日志，确认版本和状态。
3. 连接 MT6701，确认 I2C 原始角度、方向和异常状态（当前基线已验证）。
4. 连接 ADC 采样线，确认零点、噪声和母线趋势。
5. 保持 TIM2 compare 为 0；当前基线不主动启动功率 PWM。
6. 示波器确认三相 PWM 输出、频率、极性和停止行为。
7. V3P 独立上电，两板只共地，确认使能脚默认失能。
8. 受限条件下测试使能和低占空比输出。
9. 低风险开环，记录电机动作、电流原始值、母线条件和角度变化；相序、方向和极对数作为后续 FOC 整定输入。
10. 先完成基线和低风险空载开环；FOC 作为后续实验阶段，不在当前基线工作包内。

立即停止条件：

- 电源电流异常。
- 使能极性与预期不一致。
- ADC 接近满量程或与物理现象矛盾。
- 编码器无效、跳变或通信连续超时。
- 电机不可控转动、异常振动、明显发热。
- 未使用通道出现有效输出。

## 15. 文档与代码下一步

### 15.1 当前辨识测试固件边界

`STM32F103C8T6_BASE` 当前已作为辨识测试固件使用：上电进入无功率 `TEST_BOOT`，经 ADC 零偏检查后停在 `POWER_ARMED`。该状态的 PWM compare 和 `MOTOR_EN` 仍为零，只有操作者确认 `p` 后才会执行一个有固定时限的低能量测试步骤，并在结果打印前重新失能。

这不是对本章基线“默认安全态”的否定：测试固件的默认安全态是可交互的无功率等待态，而不是自动转动。用于正常运行的后续固件仍应以 `SAFE_IDLE`、参数包校验、采样认证和传感器标定作为启动条件。

文档层面下一步：

- 将当前参考平台 A 的实测数据补入适配记录。
- 单独建立每个硬件平台的适配说明，例如 `platform_f103_v3p`。
- 将测试记录与 BL0-BL6 验收门绑定。

代码层面下一步：
