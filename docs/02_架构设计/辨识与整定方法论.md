# 辨识与整定方法论

> 文档定位：面对陌生电机/陌生板卡，从建模到整定收口的**十层闭环方法论**——每层回答一个独立问题，层间互相约束；任何一层崩了后面全崩。理论骨架来自通用参数辨识框架（九层），按本项目实证增补第〇层（安全与流程）与第十层（辨识→整定桥），并嵌入本项目五条血泪补丁（工作点三区/反馈可信性/分级验收门/双源交叉/挂流程验证）。
> 核心观点：辨识不是"套一个最小二乘"，是"安全流程 → 模型 → 可辨识性 → 实验 → 预处理 → 估计 → 误差 → 数值 → 验证 → 决策 → 整定"的链路；**好方法的标准不是最准，而是误差主导项清楚、实现代价可接受、失败能回退**。
> 变量约定（单一真值源）：**y = (V−R·i)/V**，即归一化指数残差；外部文献的 x=Ri/V 与本规范互换关系 x=1−y。样本门 y∈[0.30, 0.75]，与 08 交接 §5.4 规格一致。
> 状态：已对齐（初版 2026-09-16）。上游：ARC-01/02/03；证据：S0–S8 标定链、经验1–14、VESC/SimpleFOC/DengFOC 源码对比（2026-09-16 讨论定谳）。

---

## 序：为什么需要一套方法论

面对陌生系统，工程师的困境不是"不会算"，而是：不知道测什么、数据够不够、选哪个估计器、结果可不可信、误差从哪来、先改哪。本方法论的用途：**按层逐一归因，快速定位瓶颈层，选对方法，稳定落地**——并回答最后一步：参数怎么变成增益、增益怎么验收、验收怎么收口到整定。

## 第〇层：安全与流程层【本项目增补】

辨识=给陌生功率硬件通电。没有这一层，后面十层都是病历上的字。

| 制度 | 本项目实例 | 外部同类（VESC） |
| --- | --- | --- |
| 默认失能、功率步骤人工确认 | 上电 disabled，`p` 确认才进功率步骤 | — |
| 硬红线 | 供电 ≤10V（12V 烧板）、电流 ≤1A | 检测前临时恢复出厂限流，测完还原 |
| 善后协议 | `x` 停机、FAULT 通道、看门狗 | 进检测前保存全部配置+关 60s 超时+每 1ms 查故障码，异常即恢复配置安全下电 |

**关键教训**：辨识代码的第一版先写"怎么安全地停下来"，再写"怎么测"。

## 第一层：建模层

**理论**：模型是参数化映射 y(t)=f(θ,u(t),t)+e(t)。白箱（机理全知）/灰箱（结构已知参数未知）/黑箱（只拟合输入输出）。本项目全部走灰箱：RL+死区等效电路。

**方法与选型**：机理清楚→灰箱（参数少、可解释）；完全陌生→黑箱起步再逐步注入物理约束。

**我们的证据**：S2 的 V-I 三档拟合同时解出 R 与死区等效电压 Voff——**模型里有没有死区项，决定辨识是"测 R"还是"测 R+管压降混合物"**。

**关键教训**：辨识出的是"模型框架下的等效参数"，不是绝对真理——RL 模型忽略反电动势、磁饱和、死区时，估出的 L 是"等效 L"。**模型错了，后面全错；模型误差主导时先改模型，不要换估计器。**

## 第二层：可辨识性层

**理论**：给定输入输出，θ 是否唯一确定？Fisher 信息矩阵 J(θ)=Σ(1/σ²)(∂y/∂θ)(∂y/∂θ)ᵀ 满秩才可辨识；奇异=某参数方向完全没信息。工程上更多是**弱可辨识**：估计强相关、换组数据就跳、残差小但物理不合理。

**敏感度**：S_θ=∂y/∂θ（参数对输出的影响力，不是输入输出差异）。RL 例：|∂i/∂L|=(Vt/L²)e^(−Rt/L)——t=0 与 t→∞ 都是 0，**峰值在 t=τ**。稳态 V=Ri 时 L 完全不出现。

**我们的证据**：这就是 S2（稳态测 R）与 S3（瞬态测 L）分两步的机理依据；经验3"假门判据/物理简并"（n² 统计退化）是弱可辨识在验收门上的形态。

**关键教训**：不是所有数据都有信息——靠近稳态与刚起步的样本对时间常数几乎零信息。可辨识性决定信息量上限，实验设计只能逼近它，估计器不能超越它。条件数大时先改实验，不改估计器。

## 第三层：实验设计层

**理论**：实验设计决定信息量上限。四要素=激励波形/幅度/采样率/时长，外加偏置修正。

**激励选型**：阶跃（简单宽带，时间常数辨识）/脉冲（快速系统）/正弦扫频（频响）/PRBS（黑箱）；原则=覆盖敏感度峰值、持续激励。

**采样率经验**：τ/Ts <1 几乎不可辨识，1~2 勉强，2~5 合理，5~20 充裕；瞬态至少覆盖 3~5τ，样本门内 ≥5 点。**本项目现状 τ≈0.25ms、Ts=0.1ms → 2.5（合理下限）；F4/G4 迁移后 @20kHz → 5（充裕）——这是"挂迁移"判决的量化依据之一。**

**幅度设计与工作点三区【本项目补丁，20260910 复盘】**：太小→信噪比差；太大→饱和/发热/非线性。我们的三区论：小信号区（死区+管压降吃掉激励：相序 id≈0 一度误判"断线"）/工程窗口（本系统 0.2~0.6A）/大信号区（磁饱和+积热，**不迷信大信号**）。**SNR 在物理层建立，算法只守不创**——工作点选错区，后面全崩。参考 VESC 信号准则：老路径要求 R·I>1V 压倒管压降；我们 S2 上两档（0.4/0.6A × 3.46Ω = 1.4/2.1V）实际已达标。

**参考与偏置**：每脉冲前插零矢量测 Voff，用 V−Voff 修正，消死区/偏置/温漂（SimpleFOC 逐脉冲零参考的精髓）。

**关键教训**：实验设计不是"随便加点电压看看"，是围绕可辨识性与噪声增益选型；幅度、采样、参考每一项都有理论依据。

## 第四层：数据预处理层

**理论**：去偏置/去趋势、异常值剔除、滤波、重采样、**样本门**。

**样本门的数学依据**：噪声传播 σ_z=(R/V)·σᵢ/y——y→1（刚起步）信息趋零、y→0（近稳态）噪声发散，两头都是病态区；Fisher 峰值在 y=e⁻¹≈0.368。**门 y∈[0.30,0.75] 把峰值包住，同时兼顾数值稳定（远离奇点）与信息量（贴近敏感度峰）**。样本门不是拍脑袋，是统计最优与数值可实现的对齐点。

**异常值**：中位数、MAD、三靴重复看一致性、iqr_ratio 判据。

**反馈可信性【本项目补丁，经验13】**：当数据不是脏，而是**说谎**——编码器欠流说谎案（差分电流 ≥0.06A 即输出方向一致/幅度虚高 3~5 倍的假角度，电流归零恢复）确立标定的边界：**标定能治"固定且可重复"的误差；工况依赖、不可重复的误差在标定定义之外**。对策=双源交叉（S7 动态 R 用 EMF-free 的 d 轴 vd=R·id−ωL·iq 与 S2 静态 R 互证，偏差 ≤25%）+ 防御栈（九层）+ 尸检快照。**任何辨识开工前先问：我的传感器在什么工况会说谎？**

**关键教训**：预处理是"把脏数据挡在门外"，而反馈可信性是"确认门外站的不是骗子"——后者不解决，前者的统计全是精确的错误。

## 第五层：估计层

**估计器阶梯（高斯噪声下由差到好）**：

| 方法 | 公式 | 信息利用 | 统计效率 | 鲁棒性 | 判语 |
| --- | --- | --- | --- | --- | --- |
| 差分斜率 | L̂_k=(V−R·i_k)Ts/(i_{k+1}−i_k) | 局部两点 | 差（方差 ~e^{2t/τ} 增长） | 差 | 我们的旧 S3：IQR 4.33/2.36 越限三靴全拒【A-实测】 |
| 单点对数 | L̂=−Rt/ln(y) | 单点 | 差 | 差 | SimpleFOC 基础形态 |
| 对数中位数 | 多个单点取中位数 | 多点 | 中（高斯下方差比均值大 π/2） | **好** | 重尾噪声下反超 LS |
| 对数线性 LS | z_k=ln(V−R·i_k)=lnV−(R/L)t_k；b̂=Σ(t−t̄)(z−z̄)/Σ(t−t̄)²；L̂=−R/b̂ | 全局 | 接近 ML | 中 | **本项目选型**（08 交接 §5.4） |
| 加权 LS | 权 w_k∝y_k²（σ_z∝1/y，只需平方） | 全局 | 接近 ML | 中 | 异方差正确处理 |
| 非线性 ML | L̂=argmin Σ[i_k−(V/R)(1−e^{−Rt_k/L})]² | 全局 | 最优 | 中 | 基准用，非凸计算重 |

**选型原则**：能线性化就线性化、能闭式就闭式、能加权就加权；噪声重尾要鲁棒就上中位数；计算预算紧就退一档。窄带路线（VESC：30kHz 注入+双 bin DFT，把噪声问题在频域消灭）是采样率充裕时的替代解，C8T6 算力不够【已判例】。

**关键教训**：好方法的标准不是最准，而是**误差主导项清楚、实现代价可接受**——对数线性 LS 的剩余误差已低于噪声主导项（6%），再往上优化是浪费。

## 第六层：误差分析层

**误差源清单与合成**：电流噪声（ADC/PWM，主导）/R 误差（标定温漂）/电压偏移（死区，需 Voff 修正）/log 插值（小）/定点量化（小）/时间抖动（小）。独立误差按 √Σε² 合成；**ε_k ≤ ε_dom/10 的项贡献 <1%，不进预算**。

**精度预算的本项目实践**：√(6²+0.06²)%≈6.0003%——32 点 ln 查表误差 0.06% 不配进预算，所以查表是免费的；同理 trig 表 8.2e-5 vs 1.612mA。

**噪声传播**：对数法 σ_z=(R/V)σᵢ/y（单样本 6~8% 平坦，实测噪声 σᵢ≈13mA 反推）；差分法 Var~e^{2t/τ}（晚期样本报废）。误差传播分析决定样本门、估计器选择与精度预算——三层共用一张账。

**关键教训**：精度不是越高越好，是分配合理——主导项要准，次要项够用就行。

## 第七层：数值实现层

**公式世界 vs 代码世界的断层**：实数→有限精度、除法/log 免费→百周期级软浮点库调用、无时间约束→ISR 预算、无内存→ROM/RAM、无溢出→会溢出。

**四类断层与对策（本项目全部实锤，经验14）**：①数值范围——样本门本身就是防负防零的哨兵；②算子代价——`logf` 约 1~2KB ROM，测试 target 余量 1136B 装不下 → 32 点 ln(y) 查表+线性插值（误差 h²/8·|f″|max=0.0177²/8×16≈0.06%）；③时间与中断——能离线算的离线算（D6 双编译：估计器 PC/MCU 同源，先 PC 验算再上板）、能闭式的不迭代；④现实特性——死区（V−Voff）、反电动势（锁转子/EMF-free 轴）、磁饱和（限幅）、温漂（零参考差分）逐项修正。

**关键教训**：公式是理想世界的真理，代码是现实世界的近似；工程优化=在误差预算内用更便宜的实现逼近同一个数学结果。**近似选在函数层（查表近似 ln），别选在模型层（把指数砍成直线）**——后者把这一层的问题伪装成第五层的失败。

## 第八层：验证层——分级验收门【本项目补丁：分级】

**验证手段**：残差分析（残差应有无趋势，有趋势=模型不对）/重复性（三靴 iqr_ratio ≤0.25）/置信区间（Cramér-Rao：Var(θ̂)≥J⁻¹）/物理合理性（L>0、落 0.5~2 倍标称）。

**分级哲学（四库对比的教训）**：我们旧五道门全硬 → S3 从未通过、永远回退标称；SimpleFOC 警告不拦截（Ld>Lq 只打 "Likely error." 照样存值）→ 永不失败但错了也不知道；VESC 故障码分级中止。**正确姿势：安全门硬拦截（会烧板/伤人的判据），质量门告警+记录（r²、Voff、对称性这类测量质量指标），混在一起就是把"测不准"伪装成"故障"。**

**拒收与回退**：门内样本不足/iqr 超限/物理不合理 → 回退标称值继续运行。**系统必须能在辨识失败时安全运行**（我们的 D7 决策：S3 回退标称 0.86mH，电流环 PI 兜住，FOC-4 照样验收通过）。

**关键教训**：估出来不等于可信——要有判据、能拒收、能回退；但门要分级，否则拒绝的不是坏数据而是整个功能。

## 第九层：工程决策层

**决策链**：十层环环相扣，任何一层可否决上层、回退重来。折中四维：精度 vs 成本（主导项准次要项省）/理论 vs 工程（理论锁定方法、工程选实现）/实验 vs 迁移（能挂到必跑流程就不单独做）/最优 vs 够用（够用且稳 > 最优但脆）。

**本项目判例（2026-09-16）**：S3 对数拟合理论已锁定、C8T6 专项实验判"不做"——四理由：非关键路径（FOC-4 已过、速度环阻塞在编码器）/ROM 1136B 装不下激励改造/存档无瞬态数据/反正随迁移重写；方法与规格入档 §5.4，验证挂到 F4/G4 迁移回归（三靴 iqr≤0.25 且 L 落 0.5~2 倍标称）。

**关键教训**：不是所有理论都要马上做实验——**理论锁定方法，验证挂到必然要跑的流程上，才是工程最优**。

## 第十层：辨识→整定桥【本项目增补】

参数不是终点。辨识的产出要沿这条链落到可交付的控制性能：

| 环节 | 内容 | 本项目实例 |
| --- | --- | --- |
| 增益换算 | kp=L/τ_c、ki=R/τ_c（电流环 PI 由 R/L 直接导出） | `foc_identification_derive_current_pi`：S2 出 ki、S3 出 kp，时间常数 τ_c=10ms |
| 闭环自检 | 阶跃响应四门：建立时间（≤10τ_c）/静差（<15%）/振荡（穿出占比+最长连续）/饱和（<10% 拍） | S4 步骤，`calib_s4_*` 引擎 |
| 运行态验收 | 零流保持/电流阶梯/负载响应/故障链 | FOC-4：零流 ±0.02A、iq 阶梯 ±0.5A 双向 ~400rpm、encoder lost 断使能 |
| 上层整定 | 速度环保守起步→阶梯整定→指标回填 | `p→s→+`（振荡按 2、偏软按 1、稳差按 3），kp=0.0015/ki=0.008 起步，整定数据取自无 [FB SUSPECT] 窗口，FR-4.5 四项回填 |

**关键教训**：辨识方法论止于"参数可信"，整定方法论始于"参数可用"——中间的桥（增益换算+闭环自检+验收链）必须显式存在，否则辨识做完没人知道参数对不对。

## 层间交互网

九层+两个增补层不是线性而是互相约束的网：建模↔可辨识性（模型决定参数能否分开）、可辨识性↔实验（信息上限决定激励）、实验↔预处理（采样率决定门内点数）、预处理↔估计（门决定估计器输入）、估计↔误差（方法决定误差传播）、误差↔数值（预算决定实现精度）、数值↔验证（实现决定判据）、验证↔决策（判据决定采用）、决策↔建模（失败反馈改模型）。**本项目增补两条边**：反馈可信性↔实验设计（传感器说谎的工况决定激励窗口可信度，经验13）；验收分级↔决策（质量门告警不改变安全决策链）。任何一层崩了后面全崩；任何一层改，前面要复查。

4. 实验：τ 多少？τ/Ts 几？幅度在哪个区（小信号/工程窗口/大信号）？偏置怎么修？（三）
5. 反馈可信性：传感器在什么工况会说谎？有没有第二真理源交叉？（四）
6. 预处理：偏置/趋势/野值？样本门怎么定？（四）
7. 估计：能线性化吗？噪声什么分布？计算预算？（五）
8. 误差：主导项是谁？哪些项 ≤1/10 可忽略？（六）
9. 数值：平台 ROM/RAM/CPU？哪些算子贵？能离线/查表吗？（七）
10. 验证：判据分级了吗？失败回退到哪？（八）
11. 决策：瓶颈在哪层？改哪层投入产出最高？能不能挂到必跑流程？（九）
12. 整定：增益怎么换算？闭环自检与验收链是什么？（十）

## 附录C：经验法则速查

| 主题 | 法则 |
| --- | --- |
| 采样 | τ/Ts≥3 为宜、门内 ≥5 点、总覆盖 3~5τ |
| 激励 | 覆盖敏感度峰值（RL 即 t≈τ、y≈0.368）、持续激励 |
| 幅度 | 工作点三区论：避开小信号陷阱，不迷信大信号 |
| 样本门 | Fisher 信息+噪声增益折中（本项目 y∈[0.30,0.75]） |
| 估计 | 能线性化就线性化、能闭式就闭式、能加权就加权；重尾上中位数 |
| 误差 | 主导项准、次要项省；≤1/10 主导项的不进预算 |
| 近似 | 选函数层（查表），别选模型层（砍物理）；误差锚定噪声地板 |
| 查表 | 窄区间+线性插值，误差 O(h²) |
| 验证 | 安全门硬拦截、质量门告警；判据+拒收+回退 |
| 决策 | 理论锁定方法、验证挂到必跑流程 |
| 整定 | 参数→增益→闭环自检→运行验收→上层整定，一桥到底 |

## 结语：三句话

1. **辨识不是调参，是"安全+模型+实验+估计+验证+决策+整定"的十层闭环**；任何一层崩了，后面全崩。
2. **好方法的标准不是最准，而是误差主导项清楚、实现代价可接受、失败能回退。**
3. **理论告诉你哪条路最优，工程告诉你哪条路现在值得走**——本项目的答案：方法入档（§5.4），验证挂迁移（ARC-03），血泪留经验（经验1–14）。
