# STM32F103C8T6 电机控制 FOC 开发目标与验证计划

> 文档定位：本文件是当前平台进入 FOC 阶段后的目标、范围、软件架构和验证总计划。它承接已经结档的 F103 基线，不替代基线设计说明、F103 硬件适配说明和 V3P 驱动板适配说明。
>
> 当前参考平台：STM32F103C8T6 + DengFOC V3P/V3Pro + 2804 电机 + MT6701。首轮只使用 M0，电机空载，目标是建立可重复的基础 FOC 闭环，不追求最终关节电机的高精度性能。
>
> 重要供电约束：V3P 驱动板电源最大为 10 V，12 V 会烧毁驱动板。所有上电和 FOC 实验必须使用不超过 10 V 的外部限流电源，并从更低电压开始。

---

## 1. 文档目标

本文件把“开始写 FOC”定义为一组可分阶段验收的工程任务，而不是一次性打开所有闭环。目标是：

- 在现有基线的 PWM、ADC、MT6701、`MOTOR_EN` 和故障接口之上建立 FOC 软件层。
- 正确完成机械角度到电角度的转换，以及电机相序、编码器方向和电角度零位对齐。
- 将两相电流原始 ADC 数据转换为可用于 Clarke/Park 变换的物理电流量。
- 在 STM32F103 的算力和外设限制内运行稳定的电流环。
- 在电流环稳定后，逐级增加速度环和位置环。
- 保持基线已经建立的默认失能、显式启动、故障停机和可回退能力。

本项目当前的完成定义是“基础 FOC 链路可验证”，不是最终产品级伺服控制器。额定转矩、额定转速、精确位置控制、通信协议和完整保护策略均不在首轮目标内。

### 2.1 已结档的基线能力

基线阶段已经形成以下可复用接口和行为：

### 2.2 基线完成定义与 FOC 入口

基线已经按其既定目标完成。基线阶段负责确认平台基础软件链路、传感器通信、PWM/使能接口、低风险开环动作和安全停机路径可用，并提供可独立构建和回退的工程版本。

以下项目不属于基线缺陷，也不需要回填到基线验收中：

- 三相 U/V/W 的最终软件映射；
- MT6701 方向和电机正方向的统一；
- 编码器机械零位到电角度零位的偏移；
- ADC 零偏、比例、方向和饱和范围；
- PWM 中点采样和 ADC 触发时序；
- F103 最坏控制执行时间和目标控制频率；
- 母线过压/欠压保护能力。

这些内容属于 FOC 运行前的准备、参数整定和实时性评估阶段，集中在后文 `FOC-PRE` 执行。基线通过不能替代这些准备，但这些准备未完成也不否定基线已经结档。

## 4. FOC 总体架构

```text
MT6701 原始角度
        -> 机械角度/方向/异常
        -> 电角度 = 机械角度 × 7 + 零位偏移
                              |
ADC 原始值 -> 零偏/比例/方向 -> Ia/Ib/Ic
                              |
                      Clarke 变换
                              |
                       Park 变换
                              |
                    Id/Iq 电流 PI 环
                              |
                       电压矢量限幅
                              |
                      反 Park 变换
                              |
                         SVPWM
                              |
                  TIM2 三相 PWM compare
                              |
                    V3P -> 2804 电机
```

控制算法只接收物理量、角度和有效标志，不直接访问 `hadc1`、`htim2`、GPIO 引脚或具体 I2C 句柄。底层适配层负责硬件绑定和安全失能。

## 5. 软件模块规划

### 5.1 角度与传感器模块

职责：

- 读取 MT6701 14 bit 原始角度；
- 应用编码器方向；
- 处理跨零；
- 乘以 7 极对数得到电角度；
- 加入可配置电角度零位偏移；
- 输出角度有效标志、读取错误和更新时间。

建议接口语义：

```text
sensor_read_angle() -> mechanical_angle, status
foc_angle_update()  -> electrical_angle, electrical_speed, valid
```

### 5.2 电流采样模块

职责：

- 读取两路 ADC 原始值；
- 减去零偏；
- 应用 ADC 参考电压、分流电阻和放大倍数；
- 输出 `Ia`、`Ib`，按 `Ic = -Ia - Ib` 重构第三相；
- 检查饱和、越界、采样无效和异常跳变。

V3P 使用 0.01 ohm 分流电阻和 INA240A2。INA240A2 的标称增益需要结合实际板级连接和实测信号确认，不能只凭芯片型号推断完整采样比例。

### 5.3 坐标变换模块

职责：

- Clarke：`Ia/Ib/Ic -> Ialpha/Ibeta`；
- Park：`Ialpha/Ibeta + electrical_angle -> Id/Iq`；
- 反 Park：`Vd/Vq + electrical_angle -> Valpha/Vbeta`。

模块必须统一角度单位、定点/浮点表示和符号约定。初版优先保证可读性和验证性，再根据 F103 的执行时间决定是否改为定点实现。

### 5.4 PI 电流环模块

职责：

- `Id` 和 `Iq` 两个独立 PI 控制器；
- 输出 `Vd`、`Vq`；
- 电压矢量限幅；
- 抗积分饱和；
- 使能、复位和故障时清除积分状态。

初期只使用较小电流目标和电压限幅，不追求额定转矩。PI 参数必须与实际控制周期和电机电阻、电感一致，不能直接照搬其他平台参数。

### 5.5 SVPWM 与 PWM 输出模块

职责：

- 将 `Valpha/Vbeta` 转为三相占空比；
- 保证 compare 在 `[0, ARR]` 范围内；
- 复用现有 TIM2 输出接口；
- 在驱动失能前清零 compare；
- 不在软件中重复实现 V3P 板内 FD6287T 的互补和死区功能。

### 5.6 FOC 状态机

建议状态：

```text
SAFE_IDLE
  -> SENSOR_CHECK
  -> ALIGN
  -> CURRENT_LOOP
  -> STOPPING
  -> SAFE_IDLE

任意运行状态 -> FAULT -> 手动清除 -> SAFE_IDLE
```

状态进入条件、退出条件和安全动作必须显式定义。串口命令只能确认当前已准备好的受限阶段，禁止绕过状态机直接进入功率闭环。

### 5.7 测试固件状态机

为建立首轮静态参数，本工程的测试固件可在上电后自动进入无功率的 `TEST_BOOT`。这不是绕过安全检查：功率级仅能从 `POWER_ARMED` 收到 `p` 确认后开启，并在每个阶段结束时自动关闭。

```text
TEST_BOOT -> TEST_READY -> POWER_ARMED
POWER_ARMED --p--> ALIGN -> R -> L -> TEMP_CURRENT -> SENSOR -> LOW_SPEED_CAPTURE
LOW_SPEED_CAPTURE -> CANDIDATE_REVIEW --a/d/r--> TEST_READY / TEST_BOOT
任意有功率阶段 --x / ADC fault / FOC fault--> SAFE_IDLE 或 FAULT
```

测试模式仅省略“已有正式参数”的前置条件，未省略 PWM 范围、ADC 回调有效性、FOC 故障、人工停止或阶段超时保护。正常 FOC 模式仍必须要求参数包和完整采样认证。

## 6. FOC 运行前准备与参数整定

`FOC-PRE` 是从已结档基线进入功率闭环前的必要阶段。它的作用是把电机、编码器、采样链路和 F103 实时性转换成 FOC 可以使用的参数和边界，不重新定义基线目标。

### FOC-PRE：准备与整定清单

必须完成以下检查后，才允许进入 FOC 功率闭环：

- 完成三相线序的软件映射或低能量实验匹配；
- 确认 MT6701 方向和电机正方向；
- 确认极对数并完成电角度零位对齐；
- 标定 ADC 电流零偏、比例、方向和有效范围；
- 确认 PWM/ADC 采样时序；
- 测量完整控制周期的最坏执行时间；
- 确认母线保护能力，或明确继续依赖外部电源限流；
- 设定初始电流、电压、速度和超时限制。

这些项目的结果应写入参数版本和实验记录。它们属于机器整定和控制器运行准备，不回写为“基线未完成”。

### 6.1 电机相序

### 6.1 电机相序

确认 MCU 输出 A/B/C 与电机 U/V/W 的实际对应关系。交换任意两根线通常会改变旋转方向；相序错误可能造成反转、抖动、失步和过流。

### 6.2 编码器方向

确认电机按约定正方向旋转时，MT6701 原始角度是增加还是减少，并在软件中统一正方向。

### 6.3 电角度零位

通过固定 d 轴电压使转子对齐，读取 MT6701 角度并计算偏移。对齐电压和时间必须从低能量开始，且必须有外部限流和立即断电条件。

### 6.4 电流采样比例与方向

至少完成：

- 零电流 ADC 偏置；
- ADC 参考电压；
- INA240A2 实际增益；
- 分流电阻实际值；
- ADC 数值到安培的比例；
- 正负方向；
- 有效范围和饱和点。

### 6.5 PWM/ADC 采样时序

确认 ADC 采样发生在 PWM 周期内的稳定窗口。若当前 TIM2 普通定时器和软件 ADC 读取不能满足同步要求，应先降低电流环频率，不能默认 20 kHz FOC 一定可靠。

### 6.6 控制周期预算

测量一次完整控制周期的最坏执行时间，包括：

- ADC 读取；
- MT6701 读取或缓存角度；
- 坐标变换；
- 两个 PI；
- SVPWM；
- 故障检查；
- PWM 更新。

目标控制周期必须留出中断、通信和故障响应余量。

## 7. 分阶段开发与验收

### FOC-0：安全框架冻结

目标：确保增加 FOC 模块不会破坏基线安全行为。

工作内容：

- 定义 FOC 配置结构和状态机；
- 复用 `MOTOR_EN`、PWM 清零和故障停机接口；
- 增加 FOC 参数的默认安全值；
- 保留手动停止和故障清除命令。

通过标准：

- 正常固件上电默认 `SAFE_IDLE`；测试固件上电默认无功率 `TEST_BOOT`；
- 未完成传感器和采样检查时不能使能功率级；
- 任意故障都先拉低 `MOTOR_EN`，再停止 PWM；
- 编译 `0 Error(s), 0 Warning(s)`。

### FOC-2：角度链路

目标：得到稳定、方向正确的电角度。

工作内容：

- MT6701 连续读取和异常处理；
- 方向配置；
- 7 极对数换算；
- 跨零处理；
- 电角度零位偏移参数。

通过标准：

- 手动转动一圈时机械角度连续；
- 电角度完成 7 个周期；
- 正方向和反方向符合约定；
- 编码器断线或连续读取失败能够进入故障。

### FOC-3：电流采样链路

目标：得到可信的 `Ia/Ib/Ic`。

工作内容：

- 记录无电流时 ADC 原始值；
- 使用已知小电流确认比例；
- 确认正负方向和第三相重构；
- 增加饱和和无效采样检测。

通过标准：

- 零电流换算值接近零且重复性良好；
- 已知电流下比例误差在当前实验允许范围内；
- 三相电流和接近零；
- ADC 超范围立即限制输出或停机。

### FOC-1：数学链路离线验证

目标：先验证 FOC 计算，不接通功率输出。

工作内容：

- Clarke/Park 和反变换测试；
- PI 限幅、复位和抗积分饱和测试；
- SVPWM 边界、零矢量和方向测试；
- 角度跨零和极对数换算测试；
- 使用固定测试向量检查数值结果。

通过标准：

- 变换前后幅值关系符合定义；
- 角度增加和减少时方向一致；
- 所有 PWM compare 不越界；
- 零输入不会产生持续非零输出。

### FOC-PRE-ALIGN：编码器电角度对齐

目标：建立可重复的机械零位到电角度零位关系。

工作内容：

1. 保持低母线电压和外部限流；
2. 施加小幅固定 d 轴电压；
3. 等待转子稳定；
4. 读取 MT6701 角度；
5. 计算并保存电角度偏移；
6. 断电后重复验证。

通过标准：

- 重复对齐得到的偏移在允许误差内；
- 转子不会持续振荡或快速升温；
- 失能后电机无有效功率输出。

### FOC-4：低风险电流闭环

目标：在空载、低电压、低电流下稳定运行 `Id/Iq` 电流环。

测试顺序：

```text
Id=0, Iq=0
  -> 小幅 Id
  -> 小幅 Iq
  -> 小转矩保持
  -> 极低速旋转
```

初次电流限值应显著低于电机标称 1 A，具体数值以采样标定结果和外部电源限流为准。电机出现剧烈振动、异响、快速温升或电流异常时立即停止。

通过标准：

- `Id/Iq` 能跟踪小目标且无持续振荡；
- 电流限幅有效；
- 编码器异常、ADC 异常和停止命令均能在一个可接受的控制周期内关闭输出；
- 低速旋转方向与目标一致。

### FOC-5：速度闭环

仅在电流闭环稳定后进入。

工作内容：

- MT6701 角度差分或定时速度估算；
- 速度环 PI；
- 速度、加速度和电流限制；
- 失速、超速和方向切换保护。

首轮仍保持空载和低速，不追求电机资料标称转速。

### FOC-6：位置闭环

仅在速度闭环稳定后进入。

工作内容：

- 位置误差计算；
- 位置环输出速度目标；
- 机械角度范围和软限位；
- 通信目标与停止策略。

位置环不应绕过电流限值和速度限值，也不应直接操作 PWM。

## 8. 安全、故障与回退策略

### 8.1 立即停止条件

以下任一条件出现，立即停止 PWM 并拉低 `MOTOR_EN`：

- 外部电源电流异常上升；
- ADC 接近满量程、饱和或读数失效；
- MT6701 连续读取失败或角度跳变异常；
- 电机失控、剧烈振动、异响或快速温升；
- `MOTOR_EN` 拉低后功率级仍有有效输出；
- PWM compare 越界或控制周期超时；
- 发现 V3P 供电超过 10 V。

### 8.2 软件故障类别

建议至少保留以下故障分类：

```text
FOC_FAULT_SENSOR
FOC_FAULT_CURRENT_SAMPLE
FOC_FAULT_ADC_SATURATION
FOC_FAULT_TIMING
FOC_FAULT_PWM
FOC_FAULT_DRIVER
FOC_FAULT_OVERSPEED
FOC_FAULT_STALL
FOC_FAULT_TIMEOUT
```

故障状态不自动重启。清除故障后必须重新经过传感器检查和对齐流程。

### 8.3 回退方式

- FOC 计算异常时回退到 `SAFE_IDLE`，不自动回退到开环功率输出；
- 保留已经验证过的基线固件和开环测试固件；
- 每次改变相序、角度偏移、采样比例或 PI 参数，都保存版本号和测试记录；
- 不在未限流条件下通过提高调制量来“尝试解决”失步。

| `foc_pi.c/.h` | PI、限幅和抗积分饱和 |
| `foc_svpwm.c/.h` | 电压矢量到三相 PWM compare |
| `foc_controller.c/.h` | 单次 FOC 控制计算和输出 |
| `foc_state.c/.h` | 对齐、电流环、停止和故障状态机 |
| `foc_params.h` 或参数表 | 极对数、零位、采样比例和限制值 |
| `foc_diag.c/.h` | 参数、角度、电流和故障遥测 |

模块实现必须通过现有 `motor_pwm`、`motor_drv`、`motor_adc`、`mt6701` 和 `board_config` 接口访问硬件，不直接复制底层 HAL 操作。

## 10. 参数与单位约定

所有 FOC 模块必须在接口或参数表中明确单位：

| 参数 | 建议单位 | 备注 |
| :--- | :--- | :--- |
| 机械角度 | 14 bit 原始值或明确的弧度/度 | MT6701 原始满量程 16384 |
| 电角度 | 统一的定点角度或弧度 | 必须明确跨零规则 |
| 电流 | A | 不允许将 ADC 原始码当作安培 |
| 电压 | V | 必须明确母线电压是否可用 |
| 速度 | rad/s、RPM 或电角频率 | 模块间不能混用 |
| 控制周期 | us 或明确的 tick | PI 参数依赖该值 |
| PWM compare | timer ticks | 必须限制在 `0..ARR` |

当前图片参数只作为初始参考：极对数 7、相电阻/绕组电阻 2.3/5.1 ohm、相电感/绕组电感 0.86/2.8 mH、磁链 0.0035 Wb。电阻和电感的测量定义在进入参数整定前必须统一。

## 11. 实验记录要求

每次 FOC 实验至少记录：

- 固件版本和参数版本；
- V3P 实际供电电压和电源限流值；
- 电机三相接线顺序；
- MT6701 方向和电角度偏移；
- ADC 零偏、采样比例和限幅；
- PWM 频率与控制周期；
- `Id`、`Iq`、电流限值和电压限值；
- 启动、停止、故障状态和故障码；
- 示波器、电源、电机声音、振动和温升现象。

实验结论必须写成“通过、失败、待确认”之一，不能只记录“电机转了”或“没有报错”。

## 13. 阶段完成定义

本项目将“基线完成”“FOC 就绪”和“基础 FOC 完成”分开记录：

### 13.1 基线完成

- 工程可构建、下载和回退；
- 默认安全态、PWM、使能、ADC 原始采样和 MT6701 通信可用；
- 低风险空载开环和停止/故障路径已验证。

### 13.2 FOC 就绪

- `FOC-PRE` 的相序/方向/零位、采样标定、时序和实时性检查完成；
- 电流、电压、速度和故障参数具有明确单位和版本；
- 母线保护缺口已经明确，并落实外部限流和停止条件。

### 13.3 基础 FOC 完成

- 数学模块通过固定测试向量；
- 低电压、限流、空载条件下电流闭环稳定；
- 失能、停止、编码器故障、采样故障和超时均能安全停机；
- 所有测试均可回退到已结档的基线固件。

速度环和位置环属于基础 FOC 之后的扩展阶段，不作为基础 FOC 完成的强制条件。

## 14. 下一步执行顺序

```text
冻结基线版本
  -> FOC-PRE：相序、方向、零位、采样和实时性准备
  -> 编写并离线验证 FOC 数学模块
  -> 接入角度和电流链路
  -> 低电压小电流电流闭环
  -> 速度闭环
  -> 位置闭环
```
