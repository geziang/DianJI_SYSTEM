## 1. 目标、范围与非目标

本规范的目标是建立一条可重复、可回退、可审计的参数获取路径，使系统仅在参数前提已经验证时进入下一层控制。系统先使用静态辨识得到的安全初值建立受限 FOC 实验平台，再用运行数据形成更准确的候选参数；候选参数只在安全停止点验证、提交和冻结，不在电机运行中直接改变控制器。

本规范覆盖：

- 电流采样零偏、比例、方向、有效范围和采样时序；
- 电机相电阻 `R`、相电感 `L` 的受控辨识（首轮主序列）；磁链 `lambda` 为 L3 可选项，不在首轮主序列（见 9.2）；
- 电流限制和 PI 参数的来源与派生关系；
- 编码器方向、极对数验证和电角零位偏移；
- 普通上电校验、受控辨识、参数保存与失效后的行为；
- 静态初值、动态候选参数、正式冻结参数之间的切换规则；
- 各试验的安全边界、通过标准和实验记录要求。

本规范不替代：

- V3P 板内功率器件、栅极驱动、死区、保护或热设计的厂家验证；
- 最终关节机械系统的负载、减速器、热模型和位置软限位设计；
- 额定工况、高速性能、无感观测器性能或产品级故障覆盖的认证。

“自动辨识”在本文中指由固件按受控步骤执行和记录的实验，不代表允许在每次普通上电时无监督地驱动电机。

本文中的“动态辨识”也不表示电机一边运行、一边直接改写电流环或编码器参数。运行中只允许采集和评估候选参数；只有在 `SAFE_IDLE` 或另一个明确的安全切换点，候选参数才允许替换正式参数。

### 1.1 测试固件与正常固件

当前 F103 工程按测试固件运行：上电自动进入 `TEST_BOOT`，但始终保持 `PWM=0`、`MOTOR_EN=0`。它不要求已有参数包、Flash 持久化、已标定传感器或产品级 ADC 放行标志；这些条件正是本次试验要建立的结果。

测试固件仅在每一个有功率阶段收到操作者的 `p` 命令后，才按已打印的电压、电流和时间上限短时使能。`x` 在任意阶段立即失能，`?` 打印状态，`r` 重启试验，动态候选结果在停机后用 `a` 应用或用 `d` 丢弃。外部低压限流、空载和无机械干涉由操作者在 `p` 前确认。

正常 FOC 固件仍应使用参数包、采样认证和传感器标定作为启动门禁。不得把测试固件的临时假设参数当作正常运行参数。

### 1.2 半自动与全自动标定模式

受控标定支持两种运行模式，二者复用同一套标定 step 函数，区别只在步骤之间是否保留人工门：

- **半自动模式（默认，首轮强制）**：每个 step 内部自动完成激励、收敛判断、采样统计和 go/no-go 判定；但进入下一个**有功率** step 前必须回到 `POWER_ARMED`，由操作者用 `p` 显式放行。自动判据只决定“本步是否通过”，不替代带电确认。
- **全自动模式（run-all，受限开放）**：在低压外部限流、空载、安全联锁已验证的前提下连续执行整条序列，仅在任一 step 判 no-go、超时或触发安全边界时停机。该模式必须在半自动模式已稳定跑通、故障停机路径已验证后才允许开放，且仍受全局电流/电压/时间硬限制约束。

任何模式下，自动判据失败都必须失能、锁存故障码并保留原始数据；不得通过提高调制量或扩大电流范围来“凑过”判据。

### 1.3 本平台首轮非目标（剪枝边界）

结合当前平台条件（表贴式 2804，`Ld≈Lq`；MT6701 绝对编码器；F103 无 FPU；单台固定配置；无 VBUS ADC），下列能力**不属于首轮标定目标**，不得为其在主标定序列中增加步骤或前置依赖：

- `Ld/Lq` 双电感、凸极辨识、MTPA、弱磁控制；
- 高频注入（HFI）对齐、无传感器启动与无感观测器；
- 增量编码器 index search、霍尔相位学习；
- 编码器偏心/高次误差查表补偿；
- 在线参数自适应、温度模型、惯量辨识与速度/位置环自整定；
- 运行时自动换相序（本平台相序由物理接线和 `wiring_revision` 固定，软件只做一致性验证，见 6.4）。

（r2）磁链 `lambda` **移出 S0–S8 首轮主序列、归为 L3 可选**：电流环与 Iq 转矩控制、编码器方向/极对数/零位对齐都不需要磁链；仅在未来做无感观测、转矩常数换算、速度前馈或弱磁时才需要。第 4 章“R/L 是磁链前置”的依赖关系与 9.2 方法保留，供 L3 阶段使用，首轮不执行、不阻塞参数冻结。

## 2. 当前平台与强制安全边界

| 项目 | 当前事实或约束 | 对辨识流程的要求 |
| :--- | :--- | :--- |
| MCU | STM32F103C8T6，72 MHz，无 FPU | 先测量实际控制周期；不得默认 20 kHz 浮点闭环一定满足实时性。 |
| 功率级 | DengFOC V3P/V3Pro，M0 三 PWM 输入 | MCU 只产生三 PWM；互补驱动和死区由商品板处理。 |
| 供电 | V3P 供电不得超过 10 V | 只使用低压外部限流电源，从更低电压和更小电流开始。 |
| 电流采样 | M0 两路 ADC 原始值，当前未完成标定 | 未通过采样标定前，原始 ADC 只能用于观察和停机，不得作为安培或精确限流依据。 |
| 母线电压 | 当前 F103 未接入 VBUS ADC | 磁链辨识只能使用外部实测母线电压作为初始依据；不得宣称有软件母线保护。 |
| 编码器 | MT6701，I2C2，当前为阻塞式读取 | 可用于慢速辨识；正式电流环必须使用缓存角度，不能每个控制周期阻塞读取 I2C。 |
| 故障输入 | 当前无统一 MCU 硬件故障输入 | 所有有功率辨识均须人工发起；外部限流和人工观察是必要保护层。 |

任意辨识状态下，出现下列现象必须立刻执行 `MOTOR_EN=0`，随后 PWM compare 清零并停止 PWM：ADC 满量程或失效、采样超时、编码器连续失败、电源电流异常、失控转动、剧烈振动、异响、快速温升、停止无效，或供电超过 10 V。

### 2.1 实时性与算力分工原则

F103 为 72 MHz、无 FPU，标定算法复杂度必须按实时/非实时路径分工，不得把统计与拟合塞进电流环中断：

- **快路径（与 PWM 同频的电流环中断）**：只执行电流环单步计算、按指令输出，并把所需样本（电流、电压指令、编码器原始角、周期号）写入定长环形缓冲；不得在其中执行阻塞 I2C、串口打印、线性拟合、三角函数统计或多次迭代。
- **慢路径（主循环状态机）或停机后**：执行收敛判断、均值/方差/中位数、线性拟合、`atan2` 圆周均值、方向与极对数估计、候选参数组装等重计算。这些计算不占实时预算，允许使用浮点。
- 控制周期 `Ts` 必须由定时器配置这一个事实源派生，电流环 PI、阶跃判据和 L 的 `dI/dt` 时间基准共用同一 `Ts`，不得在多处硬编码不同周期。

## 3. 参数分类、状态与生命周期

参数必须被区分为硬件事实、辨识结果、派生配置和运行时状态。不同类别不得混用，也不得以“默认值”代替未完成的证据。

| 类别 | 参数示例 | 来源 | 生命周期 |
| :--- | :--- | :--- | :--- |
| 硬件固定参数 | ADC 参考电压、ADC 满量程、分流电阻、放大器增益候选、PWM 周期、PWM 通道映射 | 原理图、板级实测、硬件适配 | 换板、换接线或修订硬件配置时复核。 |
| 启动校准参数 | 两路 ADC 零偏、零偏噪声、传感器连通状态 | 驱动失能、PWM 为零时的本次上电采样 | 每次普通启动刷新，不作为长期替代比例标定。 |
| 受控辨识结果 | 电流比例、采样方向、`R`、`L`、磁链、编码器方向、极对数、零位偏移 | 受控实验和原始数据 | 绑定电机、驱动板、接线和参数版本；条件改变时失效。 |
| 派生控制参数 | `Kp`、`Ki`、电流/电压/调制限制、观测器增益 | 固定参数和辨识结果计算 | 任何上游参数变化后重新计算并验证。 |
| 运行时状态 | 当前角度缓存、故障码、样本周期号、积分器 | 控制任务 | 不写入参数包；故障或停止后清除。 |

当前电机资料中的极对数 7、电阻、电感和磁链只可作为待验证初值，不能自动升格为已辨识结果。

### 3.1 参数状态

每个长期参数还必须带有状态，软件不得只按“是否有数值”决定是否可用。

| 状态 | 含义 | 是否允许用于控制 |
| :--- | :--- | :--- |
| `NOMINAL` | 来自原理图、资料或人工输入的候选值，未验证。 | 仅允许作为静态检查或受限试验的初始参考。 |
| `STATIC_VALIDATED` | 静态或低能量试验已通过的安全初值。 | 允许用于受限 FOC 实验模式。 |
| `DYNAMIC_CANDIDATE` | 根据受限运行数据得到的候选值。 | 不允许直接替换正在使用的控制参数。 |
| `COMMITTED` | 已在安全停止点通过验证并写入参数包。 | 允许在下一次受限启动时加载。 |
| `FROZEN` | 已完成启动和运行验证的正式参数。 | 允许用于正常运行。 |
| `INVALID` | 硬件、接线、版本或验证条件变化后失效。 | 禁止用于功率控制。 |

### 3.2 活动参数与候选参数

运行时必须逻辑上分离两套参数：

```text
active_parameters
  当前正在驱动电机的参数；在一次运行期间冻结。

candidate_parameters
  静态或动态辨识新得到的参数、残差、样本数和置信度；运行中只写这里。
```

动态辨识的结果必须经过样本充分性、离散度、边界和一致性检查。通过后，在电机停止、PWM 停止、`MOTOR_EN=0` 的安全点执行一次提交事务：先写入并校验新参数包，再将其作为下次运行的 `active_parameters`。提交失败时必须继续保留旧的冻结参数。

## 4. 参数依赖与放行关系

参数辨识遵守原则：后续试验若需要相信某个测量值，必须先完成产生该测量值的前提。

```text
硬件事实：ADC/分流/放大器/PWM/相线映射
  -> ADC 零偏与样本质量
  -> 电流符号 / 采样通道对应 / 相序一致性自动判定（见 6.4）
  -> 可信 Ia / Ib / Ic
  -> 临时、受限的强制角度电流控制
  -> 相电阻 R
  -> 相电感 L、可选 Ld-Lq
  -> 电流 PI 与动态限制
  -> 编码器 direction / pole_pairs / electrical_offset
  （旁路 · L3 可选：磁链 lambda，依赖 R/L 与母线电压证据，不在首轮主链，见 9.2）
  -> 编码器反馈的正式 FOC 电流环
  -> 速度环和位置环
```

`R` 和 `L` 是磁链辨识的前置条件。相电压关系为：

```text
V_phase = R * I + L * dI/dt + Back_EMF
lambda 约等于 Back_EMF / electrical_speed
```

若未知 `R` 和 `L`，电阻压降和电感压降会被误认为反电动势，尤其在低速或动态过程中会显著污染 `lambda`。因此磁链不能在 R/L 之前作为正式结果保存。

编码器辨识位于可信电流控制之后：临时控制器用 `theta_forced` 产生已知定子磁场，随后编码器才可测出该物理参考对应的机械角度。编码器并不是临时电流环的前置条件。

参数在系统中的生命周期如下：

```text
硬件事实 + 静态辨识
  -> STATIC_VALIDATED 初值
  -> 受限 FOC 运行
  -> 动态数据采集
  -> DYNAMIC_CANDIDATE
  -> 停机验证和提交
  -> COMMITTED / FROZEN 正式参数
  -> 普通启动加载并再次验证
```

## 5. 三条独立流程

### 5.1 普通启动验证

普通启动不主动扫角、不测 R/L、不测磁链，也不自动使电机产生对齐动作。

```text
BOOT_SAFE
  -> PARAMETER_CHECK
  -> ADC_ZERO_REFRESH
  -> SENSOR_CHECK
  -> READY

任一检查失败
  -> CALIBRATION_REQUIRED 或 FAULT
```

具体规则：

1. 上电首先保持 `MOTOR_EN=0`、PWM compare 为 0、M1 无主动输出。
2. 读取长期参数包，校验格式版本、CRC、硬件 ID、电机 ID 和接线版本。
3. 在 PWM 停止且驱动失能状态下，采集并计算当前 ADC 零偏与噪声。
4. 检查 MT6701 连通性、原始角度范围、读取失败次数和已保存参数的合理性。
5. 仅在全部通过时进入 `READY`。`READY` 仅表示允许接受后续受限控制命令，不表示可绕过电流、速度或故障限制。
6. 缺少参数包、CRC 失败、硬件不匹配或零偏不合格时进入 `CALIBRATION_REQUIRED`；该状态禁止功率输出。

### 5.2 受控参数辨识

受控辨识只能由显式命令发起，并要求操作者确认低压、外部限流、空载、无机械干涉和可立即断电。

```text
IDENT_PRECHECK
  -> CURRENT_ZERO_AND_QUALITY
  -> TEMP_FORCED_ANGLE_CURRENT_CONTROL
  -> R_IDENTIFICATION
  -> L_IDENTIFICATION
  -> DERIVE_AND_VALIDATE_CURRENT_PI
  -> STATIC_PARAMETER_VALIDATION
  -> LIMITED_FOC_READY
```

本流程的输出是 `STATIC_VALIDATED` 初值，目标是建立小电流、低电压、低速的实验平台，而不是直接得到最终参数。任何子步骤失败均不得继续后续步骤；应失能、锁存故障或回到 `CALIBRATION_REQUIRED`，并保留原始数据和失败原因。

### 5.2.1 当前测试固件交互流程

当前实现采用下列交互式自动序列。除 `POWER_ARMED` 外，其余有功率状态均有固定时间上限，完成后先失能再打印结果：

```text
TEST_BOOT
  -> ADC 零偏和噪声检查
  -> POWER_ARMED --p-->
  -> TEST_ALIGN
  -> POWER_ARMED --p-->
  -> R_IDENTIFICATION
  -> POWER_ARMED --p-->
  -> L_IDENTIFICATION
  -> POWER_ARMED --p-->
  -> CURRENT_VALIDATE
  -> POWER_ARMED --p-->
  -> SENSOR_CALIBRATION
  -> POWER_ARMED --p-->
  -> LOW_SPEED_CAPTURE
  -> CANDIDATE_REVIEW --a/d/r-->
  -> TEST_BOOT 或 SAFE_IDLE
```

串口日志必须至少输出 `[TEST]`、`[SAFE]`、`[LIMIT]`、`[ACTION]`、`[POWER]`、`[RESULT]`、`[CANDIDATE]` 和 `[FAULT]`。`[LIMIT]` 中的母线电压是测试配置假设值，不是软件实测值；当前硬件仍无 VBUS ADC。

#### 统一判据规则（半自动标定）

除 `S0` 不上电外，`S1`–`S7` 为有功率 step。每个有功率 step 必须同时定义四件事，禁止以固定延时到点直接取值代替收敛判断：

1. **收敛条件**：被测量进入容差带并连续保持 `K` 个控制周期后，才开始统计采样；
2. **超时上限**：原固定时间降级为保护性超时，到时仍未收敛即判 no-go，而不是到时直接取值；
3. **小样本统计**：样本数 `N=4~8`，采用去极值均值或中位数，并记录离散度（标准差或四分位距）；
4. **量化 go/no-go**：每步必须自动产出“通过/失败”，失败即失能、锁存故障码并保留原始数据。

慢路径负责上述统计与判定，快路径只负责激励输出和样本缓存（见 2.1）。

#### 半自动标定主序列 S0–S8

### 5.3 动态辨识、提交与冻结

动态辨识只能在已通过静态前提的受限 FOC 模式下进行。其目的不是运行中自动调参，而是利用真实 PWM、电流、速度和温度条件改进模型。

```text
LIMITED_FOC_RUN
  -> DYNAMIC_DATA_CAPTURE
  -> ESTIMATE_CANDIDATE_PARAMETERS
  -> CANDIDATE_QUALITY_CHECK
  -> SAFE_STOP
  -> COMMIT_OR_DISCARD
  -> VALIDATE_COMMITTED_PARAMETERS
  -> FROZEN_NORMAL_PARAMETERS 或 CALIBRATION_REQUIRED
```

运行期间只允许更新 `candidate_parameters`。停止后，候选参数必须至少满足样本数足够、统计离散度合格、未发生饱和/超时/故障、与现有参数的差异未超出安全范围等条件，才允许提交。提交后的参数先在受限模式复验；复验通过后才标记为 `FROZEN`。

## 6. 电流采样与 ADC 标定

### 6.1 零偏和样本质量

零偏仅在确认无真实相电流时采集。当前 F103 启动实现要求驱动失能、PWM 停止，并为每路连续采集 64 点；该窗口同时保存原始逐点数据，便于复盘实际波形。正式同步采样建立后，运行零偏仍只能在不产生持续转矩且采样条件已验证的安全状态刷新。

单个异常尖峰不能直接决定整组窗口失败，因此质量计算分为两层：

1. **原始保护层**：保留原始均值、min、max、p2p；原始 min/max 接近 ADC 轨时立即判 `NEAR_RAIL`，原始窗口完全不变化时判 `FLATLINE`。这些检查不允许被后续过滤掩盖。
2. **稳健统计层**：对 64 点求中位数和 MAD，使用 `limit=max(12 code, ceil(4.5×MAD))`；仅当 `abs(sample-median)>limit` 时把该点标为孤立尖峰。剔除尖峰后的有效样本均值作为本次运行零偏，过滤后有效样本 p2p 继续使用原有 `32 code` 噪声门限。每路最多允许 8 个尖峰且至少保留 56 个有效点；否则判 `NOISY`。

本次修改不改变采样次数、采样时序或 `32 code` 数值，也不在实时电流环中执行排序/MAD。它只解决“少量孤立峰值把整体 p2p 拉大”的误判；跨多次窗口的零偏漂移跟踪（例如 EMA）暂不加入，避免把尚未测量的长期漂移假设固化为启动门限。

通过条件至少包括：

- 原始 ADC 未接近满量程或零码；
- 原始窗口不长时间卡死；
- 异常点数量和有效点数量满足上限/下限；
- 过滤后有效样本 p2p 不超过 32 code；
- 过滤后零偏已写入本次运行时配置，并保留原始统计用于诊断。

### 6.2 电流比例和方向

两相电流换算的通用形式为：

```text
I_phase = (raw - zero_raw)
          * Vref / ADC_full_scale
          / (Rshunt * amplifier_gain)
          * phase_sign
```

其中要区分三类量：

- **器件固定增益（可直接定档）**：V3P 采用固定增益电流检测放大器 INA240A2（50 V/V，增益误差 ≤0.20%、零漂移）与已知 0.01Ω 分流电阻，`Rshunt`、`amplifier_gain` 属于板级设计常量，经原理图与 datasheet 核对后直接定档，1 个 ADC code = `Vref/4095/(Rshunt*gain)` ≈ 1.612mA，不再按"候选/未验证"对待；零电流电平仍以 S0 实测运行零偏为准。
- **必须实测的量**：`phase_sign`（采样极性）与采样通道/相序自洽，只能由 S1a 开环注入判定，不能假设。
- **外部证据（可选复核）**：已知小电流、外部电流表或电流探头用于提高置信度、核对器件容差，属可选 D2 复核项，不再是建立首个电流环的前置门禁。

第三相按 `Ic = -Ia - Ib` 重构。三相和仅可作为一致性检查，不可代替比例和方向的外部证据。

### 6.3 同步采样与有效窗口

进入 R/L 辨识或电流环前，必须将 ADC 从主循环阻塞式读取升级为与 PWM 周期关联的采样流程：

```text
PWM 周期标记
  -> 已确认的稳定采样窗口
  -> ADC 两通道转换
  -> DMA 双缓冲或等效无阻塞缓存
  -> 带周期号、时间戳和有效位的电流样本
```

V3P 使用两相采样，采样有效性会随调制扇区和占空比改变。首轮必须通过示波器确认实际 PWM、V3P 外部行为和 ADC 采样窗口；在策略成熟前，限制调制范围并在无有效窗口时标记 `sample_invalid`，而不是使用陈旧或不可信样本。

### 6.4 电流符号、采样通道与相序一致性自动判定

本步在最小能量下自动确定两相电流符号、采样通道与 PWM 输出通道的对应关系，并验证三相一致性；**只做判定与验证，不做运行时自动换相序**。

**控制律准入（关键顺序）**：电流符号/通道尚未验证时，**禁止**用 `Id` 电流闭环来做本步——闭环本身要用到待验证的 `phase_sign`，符号反了会形成正反馈，电流在收敛前就发散，永远到不了判定环节（控制层循环论证）。因此本步唯一合法激励是**绕过 PI 的开环电压注入**（控制器的 `VOLTAGE` 模式，仍受 max_voltage 矢量限幅），判据全部建立在原始 ADC raw 上，不经过任何待标定符号。

激励：`theta_forced=0`、`Vq=0`，对 `Vd` 做**双极性电压爬坡扫描**（固定单档电压在本项目信噪比不足：0.09V 理论仅 ~24code、小于零偏 p2p 噪声带）。零矢量基线后，电压从 0.05V 起按 0.03V/档爬升，每档 = 3ms 缓升 + 5ms 建立（不采）+ 35ms 采集均值；**以实测 raw（电流）进目标带为正向停止主闸门**，回零衰减 15ms 后反向扫相同档数；电压天花板 `VEND=min(硬件限流0.15A×Rmin, 软件矢量限幅0.5V)×0.9≈0.31V`，仅在采样反馈失效时兜底，到顶仍不进带即 no-go，不得加压硬凑。此时定子磁动势沿 α（A）轴，物理上正/负各点落在同一条过零直线 `du=ku·Vd+b`、`dv=kv·Vd`，理论 `kv/ku=-1/2`。判定规则（对正/负点做一阶最小二乘）：

- **线性与有效点数**：正/负各 ≥3 点，合并拟合 `r2≥0.98`、斜率非零，否则是噪声堆出的假线性，no-go。
- **激励足够（进目标带）**：扫描中最大 `|du|` 必须达到目标带下沿（=Imax×65%≈40code，高于零偏 p2p 噪声）；到 VEND 仍达不到判 R 偏大或增益偏小，no-go。
- **通道符号**：由合并拟合**斜率符号**确定 `phase_sign_u/v`（比单点稳）；正/负方向斜率必须同号（带符号坐标里即物理响应正/负反相，双极性），否则 no-go，不得猜测。
- **正负对称**：正/负斜率幅值不对称度反映死区/零漂/非线性，应低于容差（0.25）；拟合截距 `Voff=|b/ku|` 即死区/管压降等效电压，记录但本版不补偿。
- **通道对应**：用整条线**斜率比** `kv/ku≈-1/2`（容差带内），比单点 `dv/du` 抗噪。整体反接时两斜率同时反号、比值仍 -1/2，故比值只判通道自洽，正负由符号单独给出；比值落在 +1/-2/杂乱即通道错位。注意 `Ic=-Ia-Ib` 是重构定义，`|Ia+Ib+Ic|≈0` 是恒等式、不是独立证据，真正查通道/增益的是斜率比。
- **增益量级 sanity**：`ku[code/V]×a_per_raw[A/code]=1/R`，粗 R 应落在标称 R 的 0.5~2 倍窗（粗值，精确 R 归 S2），用于交叉发现增益/分流电阻/采样异常。
- **过流/撞轨约束**：任一档实测电流达 Imax（≈62code）立即停止加压；raw 离任一 ADC 轨小于 100code（零偏非对称，两侧都查）立即 no-go 降电压重来。

S1a 通过后写入 `sign_u/v`、置 `direction_verified`（与标准增益 `scale_verified` 共同使能 `closed_loop_allowed`），短暂停功率再以 `CURRENT` 模式重启，进入 S1b 用 `Id=0.04A` 小电流环自证：Id 平稳收敛、`Iq≈0`、无振荡与正反馈，才算符号/通道真正可信并 arm S2。

相序策略：固件只判定“当前物理相序是否与约定正方向自洽”。若不自洽，日志报出需要交换的相线（或等价的方向处理建议），由操作者断电改线并递增 `wiring_revision` 使旧参数包失效；固件不提供运行时自动换相，也不在运行中改写 `phase_map`。本步必须记录：最终符号、通道对应、三相和残差、电流档位与样本数。

## 7. 临时强制角度电流控制

临时控制器的目的不是性能，而是构造一个安全、可重复的实验平台。它不使用编码器反馈，而使用软件生成的 `theta_forced`。

```text
theta_forced
  -> Park/反 Park 的临时参考
  -> 小 Id 目标、Iq=0
  -> 受限 PWM 输出
```

临时配置必须具有：小电流限制、低调制限制、保守的初始 `Kp/Ki`、控制周期超时保护、ADC 饱和保护和手动停止路径。临时 PI 参数只能用于建立实验能力，不能作为正式调参结论。

在可信电流环尚未建立前（符号/通道未验证、`closed_loop_allowed=0`），**只允许**使用短时、小幅、限幅的开环 `Vd`、`Vq=0` 做静态对齐和采样方向观察，且应采用双极性小步长爬坡注入（以实测电流进带为主闸门、设 VEND 兜底）以同时验证方向单调性；该方式绕过 PI，不应被称为 `Id` 控制。只有 S1a 置位方向验证后，才允许建立真正的 `Id` 电流闭环（S1b）。

## 8. R、L 与 PI 参数

### 8.1 相电阻 R

在受限电流、转子静止或稳定对齐条件下，施加固定小电流并等待电流稳定。记录外部实测或可信估算的相电压和稳态电流，按一致的相量定义计算：

```text
R = V_steady / I_steady
```

首轮应在不少于 3 个、均远低于额定的受控电流档重复稳态测量，以电流为横轴、稳态相电压为纵轴做一阶线性拟合，取斜率为 R、截距用于发现逆变器等效偏置；单档 `V/I` 仅作为该工作点的交叉校验。各档必须在收敛后采样并统计离散度，拟合优度或离散度不达标时不得用平均值冒充结果。R 必须与资料标称处于同一量级（sanity check），偏差过大时优先回查采样符号、比例、接触电阻以及相电阻/线电阻口径，而不是直接采信。

R 的测量必须记录电流、保持时间、温度、供电电压、调制量和电压来源。电机温升会改变 R，首轮结果只适用于当前温度范围。

### 8.2 相电感 L 与可选 Ld/Lq

在已知 R 的前提下施加受限短电压脉冲，记录同步电流响应：

```text
L 约等于 (V - R * I) / (dI/dt)
```

该试验依赖可信时间基准、同步电流样本和可追溯的相电压。当前无母线电压 ADC 时，外部电源电压只能作为近似输入；所得 L 应标记为初始估计，直至补齐母线测量或更可靠的电压观测。

为降低两点差分对噪声的敏感性，应在阶跃窗口内等间隔取多个有效样本，逐点计算 `(V - R*I)/(dI/dt)`，取中位数作为 L，并用标准差或四分位距评估离散度；只有两个样本时结果必须标记为低置信。表贴式 PMSM 只辨识一个 L，不进行 `Ld/Lq` 分离。

凸极特性、`Ld-Lq`、MTPA 和 HFI 不属于首轮强制目标。只有在基础 L 测量稳定后才允许扩展。

### 8.3 PI 参数派生和验证

对于期望电流环时间常数 `Tc`，可采用保守初值：

```text
Kp = L / Tc
Ki = R / Tc
```

`Tc` 必须明显大于实际采样、计算和 PWM 更新链路的延迟。PI 参数还必须与输出电压限幅、积分限幅和实际控制周期一致。参数计算完成后，以小阶跃电流目标验证超调、稳态误差、振荡、停止响应和限流行为；未通过则降低带宽或回查采样和模型数据。

阶跃自检必须给出可计算判据并自动判定，而不是仅靠人工看波形：①稳态误差（保持段 `|Id-Id*|/Id*` 均值）低于预设带宽；②建立时间（进入并保持在稳态误差带内的时间）不超过设计值；③振荡计数（稳态带外反复穿越次数）为零或低于阈值；④全过程无 ADC/调制饱和、无样本超时。任一不满足即判 no-go，按“增大 `Tc` 降低带宽 → 回查采样窗口 → 回查 R/L”的顺序处理。

静态 R/L 结果通常是冷机初值。动态运行可以通过可信数据形成新的 `R`、`L` 或模型残差候选值，但不得在运行中立刻改写 `Kp/Ki`。应先在停止后使用候选 R/L 派生候选 PI，再按参数提交流程验证。

## 9. 电流能力与磁链

### 9.1 电流能力

`Imax` 不得只由 `sqrt(P_allow / R)` 自动得出。该公式仅反映给定铜耗模型下的电阻发热关系；当前平台还缺少完整热模型、母线采样和 MCU 硬件故障输入。

首轮允许值必须取以下边界中的最小值：电机资料持续电流、V3P 可确认能力、外部电源限流、采样有效范围、当前实验安全限制。每次提高限制都需要新的测试证据，且不得越过已有条件。

### 9.2 磁链 lambda（L3 可选，不在 S0–S8 首轮主序列）

> r2 定位：本节方法保留备查，但首轮电流环级标定（S0–S8）不执行磁链步骤，不把 lambda 作为电流环或编码器对齐的前置，也不阻塞参数冻结；仅在进入无感、转矩常数或速度前馈等 L3 能力时回到本节。

磁链试验只能在 R/L 已知、临时电流环已稳定且低风险开环转动可控后进行。通过受控电角速度旋转，记录电压、电流、电角速度，并估算：

```text
Back_EMF = V_phase - R * I - L * dI/dt
lambda 约等于 Back_EMF / electrical_speed
```

当前 F103/V3P 没有母线电压 ADC，因此首轮磁链值应标为“外部母线实测参与的初始估计”，不作为高精度自动辨识结果，也不作为产品级无感观测器参数的唯一依据。动态磁链结果在首轮仅保存为候选和证据，不得在线覆盖控制器或观测器参数。

## 10. 编码器参数辨识

编码器辨识只在临时强制角度电流控制和电流限制已经验证后执行。此时应使用小 `Id`、`Iq=0` 使转子停在由 `theta_forced` 定义的定子磁场参考上。

对于表贴式 PMSM，稳态转矩近似与 `Iq` 成正比。`Iq=0` 不提供持续旋转转矩，`Id` 建立定向磁场，使转子寻找稳定对齐位置。若电流环不可用，则只能使用低幅 `Vd` 对齐，重复性较差。

### 10.1 方向与极对数验证

缓慢单向变化 `theta_forced`，记录展开后的编码器机械角：

```text
encoder_direction = sign(d theta_mechanical / d theta_forced)
pole_pairs 约等于 abs(d theta_forced / d theta_mechanical)
```

电机资料值 7 作为候选值。试验用于验证其是否与实际比例一致，不应在样本不足、打滑或未完成足够扫描时盲目推断任意整数。

半自动标定按上式自动给出结论：以足够慢的单向扫描覆盖整数个电周期，对展开的 `theta_forced` 与机械角做线性拟合，斜率符号即 `encoder_direction`；斜率幅值取最接近的整数作为 `pole_pairs`，仅当拟合值与候选整数的相对差小于预设容差时才判通过。若判定方向与当前配置相反，允许固件自动翻转 `encoder_direction` 并按新方向重算 offset，且必须在日志中显式记录该翻转；极对数与候选值不一致时不得自动改写，应判 no-go 并回查极对数配置、打滑与扫描范围。

### 10.2 电角零位 offset

对多个已知 `theta_forced` 正向和反向扫描。每个稳定点读取 MT6701，计算未经 offset 修正的电角：

```text
theta_uncorrected = wrap(direction * pole_pairs * 2pi * encoder_raw / 16384)
offset_sample = wrap_signed(theta_uncorrected - theta_forced)
```

offset 必须使用圆周均值，而不是普通算术均值：

```text
offset = atan2(sum(sin(offset_sample)), sum(cos(offset_sample)))
```

运行阶段使用：

```text
theta_electrical = wrap(theta_uncorrected - electrical_offset)
```

必须记录正扫与反扫 offset 差、圆周残差和圆周集中度。若重复性或残差不满足预设阈值，则不得保存 offset，必须回查相序、采样方向、机械摩擦、对齐电流和编码器链路。

执行编排：①以小 `Id` 将转子锁定在 `theta_forced=0`，收敛后读取一个 offset 样本后释放；②重新对齐，重复 `N` 次（建议 `N≥4`，并包含正向、反向接近对齐点）；③对 `N` 个 `offset_sample` 用圆周均值合并，并计算圆周标准差与正/反向均值差。只有圆周标准差、正反差都低于阈值时才保存 offset；超差时按“齿槽定位转矩 → 对齐电流不足 → 采样方向 → 机械阻力”的顺序回查。禁止用单次对齐值直接作为最终 offset。

编码器方向、极对数和零位偏移属于安装与机械绑定参数，通常应在受控辨识后冻结。正常运行可记录编码器残差用于健康检查；残差持续异常时应标记参数可疑并要求重新标定，禁止在运行中自动重写 `electrical_offset`，以免掩盖机械松动、传感器滑移或相序错误。

### 10.3 低速编码器闭环交叉验证

offset、方向、极对数确定后，必须用编码器反馈电角度（而非 `theta_forced`）做一次低速闭环，作为传感器链与电流链的联合交叉验证：

- 以小 `Id`、受控小 `Iq`（或等效缓慢电角速度）运行固定时长，记录 `Id`、`Iq`、编码器电角度与指令方向；
- 通过判据：`Id` 接近 0 且平稳、`Iq` 无异常增大、电角度随指令方向单调连续（无回跳/失步）、无 ADC/调制饱和与样本超时；
- 现象反查：周期性卡顿（每机械周约 `pole_pairs` 次）优先怀疑 offset；转向相反优先怀疑 `encoder_direction`；无法平滑定向优先怀疑相序或采样通道（回到 6.4）。

本步是方向、极对数、offset、相序能否共同自洽的最终自动判据；未通过不得进入候选提交。

## 11. 参数包、硬件绑定与失效规则

辨识成功后，只将通过验证的长期参数写入非易失存储。参数包至少包含：

```text
format_version
hardware_id
motor_id
wiring_revision
parameter_revision
crc

current_gain / current_sign / current_offset_reference
R / L / lambda / measurement_conditions
pole_pairs / encoder_direction / electrical_offset
Kp / Ki / current_limit / voltage_limit
calibration_timestamp / evidence_id
parameter_state / validation_conditions
```

每次启动生成的 ADC 零偏属于运行时数据，可覆盖上一次零偏；比例、方向、R/L、磁链、相序和编码器参数必须保留其证据版本。参数包必须同时能表示 `active_parameters` 的冻结版本与尚未提交的 `candidate_parameters`；候选参数可写入诊断记录，但不能覆盖最后一个可回退的冻结参数包。

下列事件必须使相关参数失效并要求重新辨识：换电机、换编码器、改变 U/V/W 接线、换 V3P 或转接板、改变电流采样硬件、升级导致参数语义变化的固件版本、CRC 失败，或重复验证失败。

## 12. 验收门槛、故障与实验记录

每个辨识步骤必须产生“通过、失败、待确认”之一，禁止只记录“电机转了”或“没有报错”。下一步骤只能读取已通过的上游参数。

建议的门槛关系如下：

| 当前步骤 | 必须已通过 | 成功输出 | 未通过行为 |
| :--- | :--- | :--- | :--- |
| ADC 零偏 | 硬件安全态 | 本次零偏和噪声 | 禁止功率输出。 |
| 电流比例/方向 | 零偏、外部电流证据 | 可信 Ia/Ib/Ic | 禁止 R/L 和电流环。 |
| 电流符号/相序一致性 | 零偏质量、微能量矢量 | sign_u/v、通道对应、三相和残差 | 禁止 R/L 与电流环。 |
| PWM/ADC 同步 | 电流样本有效 | 带周期号的样本 | 禁止动态辨识。 |
| 临时电流环 | 采样、保护、强制角度 | 小电流可控能力 | 禁止编码器自动对齐。 |
| 电流环阶跃自检 | R/L、派生 PI | 建立时间/静差/振荡判据 | 降低带宽或回查模型。 |
| R/L | 临时环、时间基准 | R/L 初值（多点统计） | 保持临时 PI。 |
| 磁链（L3 可选，非主序列） | R/L、受控旋转、母线电压证据 | lambda 初始估计 | 首轮不执行；不阻塞电流环级参数冻结。 |
| 编码器 | 强制角度稳定 | direction、pole_pairs、offset | 禁止传感器闭环。 |
| 低速闭环交叉验证 | 编码器参数、可用电流环 | 自洽判据（Id≈0/单调跟随/无失步） | 禁止候选提交。 |
| 动态候选 | 受限 FOC、可信运行数据 | candidate_parameters 与置信度 | 保留旧参数，不改变控制器。 |
| 参数提交 | 候选质量、SAFE_IDLE、CRC | COMMITTED 参数包 | 丢弃候选，保留旧冻结参数。 |
| 全链路 | 已提交参数的受限复验 | FROZEN 正式参数 | 回到 CALIBRATION_REQUIRED。 |

### 12.1 动态参数权限

| 参数 | 可在运行中采集候选 | 可在运行中生效 | 提交规则 |
| :--- | :--- | :--- | :--- |
| ADC 零偏 | 仅电机 OFF 时 | 否 | 在 OFF 状态刷新本次运行零偏。 |
| 相电阻 `R` | 是 | 首轮否 | 停机后重新派生并验证 PI。 |
| 相电感 `L` | 是，首轮谨慎 | 否 | 停机后验证并提交。 |
| 磁链 `lambda`（L3） | 首轮不采集 | 否 | 移出主序列；未来需要时补母线电压证据后再评估。 |
| 编码器 offset | 只记录残差 | 否 | 仅显式重标定时更新。 |
| PI 参数 | 可由候选 R/L 派生 | 否 | 仅停机后整体切换。 |
| 电流上限 | 可采集热与饱和证据 | 只允许降低 | 提高限制必须受控试验后提交。 |
| 相序、极对数 | 否 | 否 | 仅人工受控辨识更新。 |

每次实验至少记录：固件版本、参数包版本、硬件/电机/接线 ID、V3P 实际供电和限流、示波器或电流表测量点、原始 ADC 与物理量、试验指令、时间和温度、停止原因、通过标准和结论。

## 13. 当前实施路线

当前首要任务不是直接测 R/L 或进入编码器闭环，而是完成电流采样可信化。实施顺序同时体现“静态初值 -> 受限运行 -> 动态候选 -> 停机冻结”的参数生命周期。

```text
P0  参数状态、参数包、启动门禁和回退框架
P1  静态 ADC 零偏、原始/物理电流遥测、样本质量与停机
P2  PWM 触发 ADC、无阻塞缓存、运行条件零偏、采样窗口和控制周期验证
P3  静态安全初值：零偏质量、电流符号/通道/相序一致性自动判定、比例确认、强制角度下的小电流临时环
P4  静态 R/L（多点统计）、保守 PI 与电流阶跃自检、编码器方向/极对数自动校验与电角零位多点标定
P5  低风险 FOC 运行、低速编码器闭环交叉验证、数据记录与动态候选参数估计
P6  SAFE_IDLE 参数提交、受限复验、冻结和回退
P7  冻结参数下的正式电流环和低速验证；后续再扩展速度/位置环
```

首轮不在 P5 安排磁链步骤（r2 移出主序列）。磁链可信度还受当前无母线电压采样限制；若未来将磁链用于高精度无感功能或产品级参数，必须增加母线电压测量或建立等效的可追溯电压观测方案。

本规范完成后，FOC 开发、平台适配和试验记录均应以本文件的参数依赖与放行门槛为准；未关闭的前置问题不得通过提高调制量或扩大试验范围来绕过。
