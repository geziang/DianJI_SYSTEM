# 闭环运行开发需求：从参数固化到速度闭环（SPEC-RUN）

> 文档定位：L3 规格（合同/验收标准）。本文件把"标定测试固件之后做什么"定义为一组可分阶段验收的工程需求，上接 `SPEC-FOC`（FOC-0..6 总路线）与 `SPEC-CAL`（S0–S8 标定规格），下游由 L5 详细设计分册承接。本文件只规定做什么、什么算通过，不规定逐行实现。
>
> 状态：**已对齐（r1）**——R1/R2 于 2026-09-13 上板验收通过（证据：`06_验证与实验记录/标定报告/20260913_S0-S7_全序列_R自学习三靴固化链.md`、调试日志经验8/9）；R3–R5 待实施。
>
> 锚定上游：SPEC-FOC、SPEC-CAL、ARC-02、DD-01、DD-02、DD-05；决策 D4（Flash 不开、RAM only）由本文件 R2 正式申请解禁。
>
> 当前平台：STM32F103C8T6 + DengFOC V3P/V3Pro + 2804 电机（7 极对）+ MT6701；首轮仅 M0、电机空载。
>
> 不可突破的物理约束：V3P 供电 **≤10 V（12 V 烧毁驱动板，禁止）**；测试电流硬上限 1 A；外部限流电源供电，台电源 CC ≥ 1.2 A。

## 1. 文档目标与范围

### 1.1 要解决的问题

当前固件（`F103-identification-test-0.4`）已能完成 S1a→S5 的静态标定，但存在三个断点，导致"标定结果"无法变成"可持续运行的电机"：

1. **S7 低速捕获不产出候选参数包**：实测日志出现 `dynamic R outside 50% safety window; discarded`，进而 `apply rejected: no approved candidate`，整条流程没有终点产品；
2. **参数只活在本次上电**：所有标定结果 `this boot only`，掉电丢失（决策 D4 的 RAM only 状态）；
3. **没有运行态**：固件是标定测试状态机，阶段结束自动断电，不存在"让电机持续受控旋转"的模式与指令通道；速度环代码为零。

### 1.2 本文件范围

| 需求包 | 内容 | 对应上游 | 本轮深度 |
| --- | --- | --- | --- |
| R1 | S7 候选产出收口（含相电阻 R 的纯软件自学习） | SPEC-CAL S2/S7、批次 C | **必选，写细** |
| R2 | 参数 Flash 固化（64 KB 保守设计、双页 A/B） | 解禁决策 D4 | **必选，写细** |
| R3 | 持续电流闭环运行态（FOC-4）+ 指令抽象 hook | SPEC-FOC FOC-4 | **必选，写细** |
| R4 | 速度闭环（FOC-5） | SPEC-FOC FOC-5 | **本次写细** |
| R5 | 位置闭环（FOC-6） | SPEC-FOC FOC-6 | **仅占位**，不展开 |

不在本轮范围：M1 通道、无感控制、磁链辨识（沿用决策 D1，降为可选）、额定性能/高精度伺服、CAN 等具体总线协议实现、产品级保护全集。

### 1.3 术语速览（本项目语境）

| 术语 | 含义 |
| --- | --- |
| 电流闭环（内环） | d/q 轴电流经 PI 输出电压指令；对应 `foc_runtime` 的 `FOC_CONTROL_CURRENT` 模式 |
| 电压开环 | 跳过 PI 直接给 Vd/Vq；对应 `FOC_CONTROL_VOLTAGE`，仅测试模式可用，S1a/PHASE_SEQ 用 |
| 速度闭环（外环） | 速度误差经 PI 输出 iq 给定，内环仍是电流环；当前**零代码** |
| forced angle | 标定态由外部把电角度喂给 runtime（对齐/开环探测时用固定角，S7 时喂编码器实测角） |
| 参数包 candidate/active | candidate=本次标定候选、待确认；active=已确认生效。见 `motor_parameter_package_t` |
| 小信号区/工程窗口 | 本项目复盘结论：相电流 <0.1 A 时死区/管压降/接触电阻/零偏噪声主导，测量不可信；工程窗口 0.2–0.6 A |
| 门禁（gate） | 进入某状态/使能功率前必须全部满足的条件集合 |

控制层级与当前实现状态：

```text
位置环 P（R5，未开工）
   └─► 速度环 PI（R4，零代码）─► iq_ref
          └─► 电流环 PI（已实现且已上功率级验证：S1b/S4/S7）─► Vd/Vq
                 └─► Clarke/Park/反变换/SVPWM（已实现）─► PWM(10kHz)
角度供给：MT6701 raw ─► 方向×极对×offset ─► 电角度（已实现，S5 ok）
```

### 2.2 两条必须继承的工程约束

1. **算力约束**：M3 无 FPU，20 kHz 软浮点 FOC 曾饿死主循环（见调试日志《S1电流环卡死排查与算力降载》），现电流环 10 kHz。任何新增外环（速度估计、速度 PI）必须先报 CPU/栈/Flash 预算，禁止默认按 10 kHz 跑外环。当前体量基线：Code ≈ 49 KB，ZI-data ≈ 5.6 KB，启动栈 1 KB。
2. **小信号陷阱**：在 <0.1 A 档位，固定压降（死区+管压降+接触电阻，量级 0.15–0.35 V）与零偏噪声吃掉有效激励，相序、R、L 都曾因此误判；工程窗口为 0.2–0.6 A，同时不得滑向磁饱和/积热的大信号区。**S7 当前工作点 0.03 A 正落在小信号区，是本次失败的首要机理（见 2.3）。**

### 2.3 本次 S7 失败的机理定位（R1 的出发点）

S7 的动态电阻按 `动态R = mean(Vq / Iq)` 累计（见 `control_loop_create_candidate` 与 LOW_SPEED_CAPTURE 分支），命中条件仅为 `Iq > TEST_MIN_CURRENT_A(0.010 A)`，候选窗为静态 R 的 0.5–1.5 倍。当前：

- S7 目标 `CALIB_S7_ID_TARGET_A = CALIB_S7_IQ_DRIVE_A = 0.03 A`（源文件中标注【待整定】）；
- 以 S2 实测 R≈3.44 Ω 估算，阻性压降 Iq·R ≈ 0.10 V，而固定压降 0.15–0.35 V 占比超过阻性分量 → `Vq/Iq` 被显著抬高，必然穿出 `1.5×3.44 ≈ 5.16 Ω` 上界；
- 丢弃日志**未打印实测动态 R 与窗边界**，现场无法判读，只能盲调。

因此 R1 的主方向是"把工作点移出小信号区 + 让统计与诊断配得上结论"，而非放宽安全窗。

## 3. R1：S7 候选产出收口（批次 C）

目标：连续可重复地产出通过质量门的 DYNAMIC_CANDIDATE 参数包，且不依赖任何外部仪表。

### FR-1.1 S7 工作点移出小信号区【必选】

- 将 `CALIB_S7_ID_TARGET_A` 调整到 0.1 A 量级（提供磁场阻尼与稳定工作点），`CALIB_S7_IQ_DRIVE_A` 调整到 0.15–0.2 A 区间；精确值上板整定，整定过程写入 L6 调试记录。任何取值仍受 `TEST_MAX_CURRENT_A=1 A`、`TEST_MAX_VOLTAGE_V=5.5 V` 硬限。
- 累计门限 `TEST_MIN_CURRENT_A` 必须与新工作点联动复核，禁止"目标 0.2 A、门限 0.01 A"这种形同虚设的门槛。
- **验收**：
  1. 连续 3 次独立上电跑 S7，均产出 candidate（出现 `[NEXT] a=apply ...`）；
  2. 动态 R 落入 S2 静态 R 的 0.5–1.5 倍窗内，3 次离散度（中值绝对偏差/中值）≤ 15%；
  3. 旋转平稳、无失步异响，母线 ≤10 V、相电流不越 1 A。
- **验收结论（2026-09-13）**：三靴独立上电均产出候选并 apply（rev=1→3）；dyn_R=2.868/2.934/2.758 Ω 全落当靴 S2 窗，MAD/中值 2.3%≤15%；全程无失步/越限。证据：标定报告 20260913。

### FR-1.2 动态 R 估计稳健性与可诊断性【必选】

- 剔除 S7 建立段样本（转速/电流未稳前不计入），稳态样本改用**截尾均值或中位数**，不用全样本均值；
- candidate 被丢弃时，日志必须打印：实测动态 R、样本数、窗上下界、静态 R 基准值；
- 样本数为零/不足时区分明确状态码与提示，不得与"超窗丢弃"混为一谈；
- 统计逻辑做成零 HAL 纯函数，进 `tests/pc` 单测（建立段剔除、截尾、空样本保护）。
- **验收**：PC 单测通过；上板丢弃场景下日志可直接读出超界方向与幅度。
- 涉及符号：`control_loop_create_candidate`、LOW_SPEED_CAPTURE 状态分支、`calib_stats`/`calib_capture`。

### FR-1.3 相序置信度门禁【必选】

- 现状为 6 排列打分取 best，+90°验证 inconclusive 时"保留 best、留给 S7 裁决"。需求：
  1. 明确相序未被验证时进入 S7 的条件（允许进入但必须在候选包/日志标注"相序未验证"，且该候选不得直接进入 R2 的永久固化）；
  2. 相序错误必须可被下游否决：S7 出现电流方向/力矩方向矛盾特征时，禁止产出 candidate 并回到 PHASE_SEQ；
  3. 提升 verify 的可读性：打印验证时的 iq、期望符号与判定结果。
- **验收**：人为交换两相接线时，流程在 PHASE_SEQ 或 S7 被拦下并给出重标提示，不得产出候选。
- 涉及符号：PHASE_SEQ 状态分支、`calib_sequence` 相序判据。

### FR-1.4 S3 电感时间分辨率【可选】

- τ=L/R≈0.24 ms，对 10 kHz（0.1 ms/拍）上升沿仅 2–3 拍，是两轮 L 偏差 65% 的根因。两条路线二选一：①阶跃期间提高采样率；②改整段指数拟合。完成前维持标称 0.86 mH 回退（现状行为不变）。
- **验收（若做）**：两轮独立上电 L 偏差 <25%、IQR 比达现有门限；不做则在 SPEC-CAL 与 DD-01 写明“维持标称、由电流环 PI 补偿误差”的结论。
- **处置（2026-09-13，决策 D7）**：选“不做”路线，维持标称 0.86 mH 回退——实测 iqr_ratio 4.33/2.36（第 2/3 轮）均越限回退，行为与设计一致；“维持标称、由 PI 补偿”结论已回写 SPEC-CAL（S3 行）与 DD-01（S3 行/落地状态）。

### FR-1.5 相电阻 R 的纯软件自学习/自裁决【必选，替代外部测量】

**不安排任何外部仪表测量动作。** 用"强信号测量 + 跨启动统计 + 双源交叉 + 偏离护栏"在固件内完成 R 的裁决与更新：

1. **单次可信门**：S2 三档（0.2/0.4/0.6 A）V-I 最小二乘结果必须 r²、|Voff|、样本数同时达阈值才采信；
2. **跨启动重复门**：保存最近 3 次独立上电的可信 S2 R，中值相对偏差 ≤10%（阈值待整定）才允许形成"学习值 learned_R"；否则维持现值并告警；
3. **双源交叉门**：S7 动态 R 与**本次 S2 实测 R**比对（不再以编译期标称 2.3 Ω 为基准），偏差 ≤25% 才共同采信；S7 的候选窗基准同步改为 S2 实测值；
4. **失控护栏**：learned_R 相对编译期兜底标称（2.3 Ω）设硬偏离上限（初定 2 倍，待整定），越界只记录、不采纳，要求人工介入；`c=clear` 可清除学习值回到兜底；
5. **产出与联动**：learned_R 写入参数包 v2（见附录 A）并随 R2 固化；每次上电用生效 R 重算电流环 ki（沿用 `foc_identification_derive_current_pi` 路径与 `TEST_PI_TIME_CONSTANT_S`），R→L→PI 的误差传递链改为"测量值经统计门后驱动"。
- **验收**：
  1. 不接任何外部仪表，连续 3 次上电 learned_R 收敛并复现（预期落在 3.4–3.6 Ω 区间，以实测为准）；
  2. 注入一组离群 S2 结果（单测构造）时被重复门/护栏拦截，不更新 learned_R；
  3. 清学习值后正确回兜底标称；
  4. 跨启动存储读取与统计为零 HAL 纯函数并具备 PC 单测。
- **验收结论（2026-09-13）**：①达成——history=[3.4410, 3.6107, 3.4644]，learned_R=**3.464 Ω** 落预期带 3.4–3.6、MAD/中值 0.68%≤10%（`flags=0x03`），rev=3 上电注入复现 `learned_R=yes(3.464 rev=1)`；双源交叉三靴 16.6%/18.7%/20.4%≤25%。②③④为代码级验收（R1 实施随模块交付，本轮上板未重演）。证据：标定报告 20260913。

### FR-1.6 已知交互遗留收尾【必选】

1. ENCODER_DIR 等待提示中的非 ASCII 内容全部改为英文，与全工程日志一致；等待手转的 15 s 内每约 1.5 s 输出一次进度（已等待时长、累计 mech_delta、阈值 0.30 rad）；
2. 全序列 DONE 后再按 p，输出明确完成提示（identification complete: a=apply / r=restart），不再只回裸 rejected；
3. 全程保持阶段结束自动断电、`x=stop` 与故障优先的既有行为。
- **验收**：串口输出全 ASCII、无静默等待段；DONE 态提示语义正确。

## 4. R2：参数 Flash 固化（解禁决策 D4）

目标：apply 后参数跨掉电保持，上电自动加载并校验，损坏可回退；写入过程绝不动功率。

### 现状（已存在、直接复用，不重写）

参数包结构、CRC32（`motor_parameter_store_calculate_crc`）、五道校验（版本/硬件ID/电机ID/接线版本/范围/状态，见 `motor_parameter_store_validate`）、stage→commit 两阶段、状态码文本。缺失的仅为 Flash 后端与上电影子加载。

### FR-2.1 存储区布局：64 KB 保守设计、双页 A/B【必选】

- F103C8T6 一律按 **64 KB Flash、1 KB/页**设计（不假设拆机片为 128 KB）；
- 修改 scatter（`MDK-ARM/.../*.sct`，当前 `LR_IROM1 0x08000000 0x00010000`）：代码区收缩到 0x08000000–0x0800F7FF（大小 0xF800=62 KB），末两页固定为参数页：
  - 页 A：`0x0800F800`；页 B：`0x0800FC00`；
- map 文件必须能证明代码段与两参数页无重叠；以当前 Code≈49 KB 计余 13 KB，若未来代码逼近 62 KB 需在风险表预警；
- 编译期静态断言：单份参数包（含头部与保留字段）≤ 1 KB。

### FR-2.2 Flash 擦写驱动【必选】

- 流程：解锁→擦除非活跃页→半字编程→上锁→**读回逐字比对**；任一步失败返回明确状态码（扩展 `motor_parameter_store_status_t`）；
- 仅允许在 SAFE_IDLE 且 `motor_drv_disable`+PWM 强制零输出之后擦写；写 Flash 期间控制环路不得运行（F1 擦写会 stalls 内核，禁止边控边写）；
- HAL FLASH 模块已在 `stm32f1xx_hal_conf.h` 使能，直接使用，不另造寄存器序列。
- **验收**：写入全程电机输出为零；人为制造读回不一致时返回错误且不破坏旧副本。

### FR-2.3 双副本择优与掉电安全【必选】

- 每页一个完整包：头部 magic、format_version、parameter_revision（单调递增序号）、载荷、CRC；
- 上电择优：两页都过 CRC 时取序号新者；一页 CRC 损坏自动选另一页；两页皆坏→CALIBRATION_REQUIRED；
- 写入时序：擦"非活跃页"→写新包→读回校验通过后才把新页标记为活跃，旧页保留为回滚副本；**任意时刻掉电，至少一页完整可用**；
- 选择/裁决逻辑零 HAL，进 PC 单测（双新、一坏、序号回退、皆坏四用例）。
- 涉及符号：`motor_parameter_store_commit_candidate`、`motor_parameter_store_load`。

### FR-2.4 上电影子加载与校验闭环【必选】

- `motor_parameter_store_init/load` 从上电影子（Flash 拷贝到 RAM）取包，沿用现有五道校验；失败路径与 `safety_manager` PARAMETER_CHECK→CALIBRATION_REQUIRED 接通；
- 加载成功后把参数灌入控制参数集（R、L、PI、符号、方向、offset、限值），并打印参数来源（页 A/B、revision、关键值）；
- **验收**：写入→复位→参数逐项一致且状态正确；故意破坏 CRC 后上电安全回退到要求标定，不死机、不进 FAULT 死锁；hardware_id/motor_id/wiring_revision 不匹配时拒绝加载。

### FR-2.5 命令链贯通与语义定义【必选】

- `a=apply`：candidate stage→commit→写非活跃页→读回→切活跃，成功日志区分"已固化到 Flash"与异常原因；替换现有 `flash persistence unavailable` 提示；
- `c=clear`：定义为 invalidate 学习值/活动包并擦除两参数页（同样要求 SAFE_IDLE），清除后等同未标定；
- `d=discard`：仅丢弃本次 candidate，不动 Flash；
- RAM 行为（本次启动生效）与 Flash 行为（永久生效）在日志措辞上可区分。
- **验收**：apply/clear/discard 三命令语义符合上表；掉电复现一致。

### FR-2.6 可测性【必选】

CRC、双页择优、版本/ID 校验、状态迁移全部抽为零 HAL 纯函数；`tests/pc` 新增对应单测并随模块交付编译命令。

## 5. R3：持续电流闭环运行态（对应 FOC-4）

原则：**电流环已经过功率级验证，不重写**；本包新增的是"能持续运行、受控进出、故障兜底"的运行外壳。

- **构建形态（2026-09-13 拍板）**：同工程双 Target——`F103-run` 运行固件（排除标定全家源文件，app_run 骨架入口，ROM 29820B、余量 33.7KB）＋测试固件 target（标定全序列，VJ 判决工具回归，ROM 62352B、余量 1136B）。参数包为两态合同、scatter/参数页布局一致、每次交付双 target 同 rebuild 0E/0W。设计细节见 DD-06 §2.1。

### FR-3.1 运行状态机补全【必选】

- 在 `safety_manager` 现有 BOOT_SAFE→PARAMETER_CHECK→ADC_ZERO_REFRESH→SENSOR_CHECK→READY 链上，补实现 LIMITED_FOC_READY / LIMITED_FOC_RUN / SAFE_STOP 的真实迁移条件与动作；实现当前恒返回 0 的 `safety_manager_is_limited_power_allowed`；
- 标定测试态（TEST_BOOT 系）与运行态共享安全底座但入口不同，状态进入/退出/故障动作显式化（对齐 SPEC-FOC §5.6/§5.7 与 DD-05）。
- **验收**：状态迁移评审通过；缺任一准入门时 READY→RUN 不可达。
- **骨架验收（2026-09-13）**：app_run BOOT→READY→ENABLED→FAULT 状态机上板走通；`safety_manager_is_limited_power_allowed` 完整实现与 SAFE_STOP 归 R3 正式迭代。

### FR-3.2 运行准入门禁【必选】

进入 LIMITED_FOC_RUN 必须同时满足：存在 COMMITTED/FROZEN 且校验通过的参数包（R2 之后）、ADC 零偏新鲜、MT6701 在线、首轮母线 ≤10 V、无锁存故障。任一不满足，使能请求被拒绝并打印具体原因。
**验收**：逐条制造不满足条件，均被拒并有可读原因。
- **骨架验收（2026-09-13）**：包/零偏/编码器三门上板生效——无包→NEED_CAL、零偏非 OK 拒绝 BOOT→READY、使能中编码器丢失→FAULT 断使能不自动重启（两轮实战）；母线/锁存故障门归 R3 正式迭代。

### FR-3.3 运行态角度供给与电流控制【必选】

- 运行态不再使用标定态的外部 forced angle 改角方式，改为编码器连续出角：MT6701 raw→`foc_rotor_model_convert`→电角度，连续送入 `foc_runtime`（CURRENT 模式），保证跨零连续；
- 提供 id/iq 目标通道（首轮 id=0，iq 由指令给定），经现有限幅与 PI；目标变化做斜率限制，禁止阶跃大给定；
- 控制周期沿用 10 kHz 单一时间基准 `BOARD_CONFIG_CURRENT_LOOP_PERIOD_S`。
- **验收（对齐 FOC-4 四条）**：id/iq 能跟踪小目标且无持续振荡；电流限幅有效；编码器异常/ADC 异常/停止命令在约定拍数内关输出；低速旋转方向与指令一致。
- **骨架验收（2026-09-13）**：**FOC-4 四条全部通过**（零流 ±0.02A；±0.5A 限幅含手动加载；encoder lost 断使能；双向 ~400rpm）。已知限界：1ms poll 喂角 @293rad/s 电角速 → id 漂移 ≈iq*·sin(14°)（理论 0.12A vs 实测 0.1~0.2A 吻合）、~400rpm 电压饱和天花板（空载 EMF 顶 5.5V 限，符合"不追标称转速"边界）。证据：`06_验证与实验记录/标定报告/20260913_FOC-4_运行态骨架验收.md`。

### FR-3.4 运行故障链【必选】

ADC 饱和/失效、编码器丢失或角度跳变、控制周期超时、过流：先拉低 MOTOR_EN、再 PWM 强制零，锁存故障码，**不自动重启**；故障清除后必须重走完整准入门禁。沿用 SPEC-FOC §8 立即停止条件。
**验收**：逐类故障注入测试，均在约定拍数内关断且状态为 FAULT，清除后不会自行转起来。

### FR-3.5 运行遥测【必选】

定频输出 id/iq、vd/vq、电角度、估计转速（R4 前可先输出角度差分值）、状态与控制模式；复用 `foc_runtime_set_output_observer` 钩子风格，零注册时零开销。
**验收**：上位机可完整观测一次"使能→给流→转动→停止"过程，丢帧率满足记录要求。

### FR-3.6 指令通道抽象 hook（只留接口，不实现总线）【必选】

- 应用层定义**运行指令接口**：启停、运行模式切换、id/iq（R4 后加速度）目标、急停、状态回读；
- 后端以注册式函数指针接入，风格对齐 output observer：当前**唯一实现为 ASCII 串口后端**；CAN/其它总线只预留注册位与接口说明，**不写实现、不引依赖**；
- 约束：FOC 运行态只依赖抽象接口，禁止直接 include/调用具体通道，确保后续加总线不动控制内核。
- **验收**：ASCII 全指令可跑通；代码审查确认运行态无具体通道耦合；未注册后端时安全拒绝启动。

## 6. R4：速度闭环（对应 FOC-5，本次写细）

前置：R3 电流运行态稳定并通过 FOC-4 验收。首轮空载、低速，不追电机标称转速。

### FR-4.1 速度估计器【必选】

- 以 MT6701 角度为输入，定时窗口差分估计机械角速度，明确选型：极低速用窗口拉长（类 T 法）、较高转速用固定周期差分（类 M 法），写清切换策略与跨零/方向处理；
- 滤波只允许引入可量化的相位延迟，并在设计阶段评估其对环稳定裕度的影响；
- 估计器为零 HAL 纯函数（输入角度序列+时间戳，输出速度与有效标志），进 PC 单测：匀速、加减速、跨零、反向、抖动抑制。
- 涉及符号：`encoder_cache`、`foc_angle_math`（新增估计模块放 `foc_*` 代码簇）。

### FR-4.2 速度环 PI【必选】

- 外环周期独立于 10 kHz 电流内环，建议 1 kHz 量级；**先实测新增运算的 CPU 占用再定周期**（承接 2.2 算力约束），禁止软浮点重计算压垮主循环；
- 速度 PI 输出 iq_ref，带抗积分饱和与输出限幅；投入/切除时积分无扰切换；
- 角度/速度换算、PI 纯函数部分进 PC 单测。

### FR-4.3 限幅链【必选】

速度限 → 加速度限（目标斜率）→ 电流限逐级收窄；速度环任何输出路径不得绕过电流限幅与 SVPWM 饱和限幅；方向切换经加速度斜坡过零，禁止直接反打。
**验收**：构造超速目标/突变目标，内部给定被逐级钳住，电流不越 1 A。

### FR-4.4 速度级保护【必选】

失速（持续给速而转速不动且 iq 顶限）、超速（实测超过软件速度上限）、编码器方向矛盾：进入保护并按 FR-3.4 停机锁存。阈值首轮保守、可配置。
**验收**：台架模拟失速/超速均可靠保护。

### FR-4.5 速度环验收指标【必选，阈值首轮流化后回填规格】

速度阶跃无失控、无持续振荡；稳态误差带、超调量、调节时间、最低平稳转速四项给出首轮数值（> 【待填写】上板整定后回填）；速度估计结果与手动定速转动的角度积分一致；正反两方向均满足。
