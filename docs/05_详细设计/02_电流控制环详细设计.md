# 02 · 电流控制环详细设计

> 状态：M1 部分对齐（Ts 单一源/output 三相回填/observer 已落地）｜ 对应代码：`Core/Src/foc_runtime.c`、`foc_controller.c`、`foc_pi.c`、`foc_transform.c`、`foc_svpwm.c`、`foc_current_model.c`
> 最后对齐：2026-09-07 M1 ｜ 上游规格：SPEC-FOC（FOC-1/FOC-4）、SPEC-CAL 第 7/8 章

## 1. 职责与边界

- 一句话职责：在 20kHz 采样节拍下完成 三相→Clarke→Park→双 PI→反 Park→SVPWM 的电流闭环单步计算并输出三相 PWM compare。
- 负责：dq 电流调节、电压限幅与矢量圆限制、积分抗饱和、强制角度/编码器角度两种角度来源。
- **明确不做**：不做速度/位置外环（见 §11 预留）；不直接操作 ADC/PWM 外设（由 DD-03 与板级驱动提供）；不做参数辨识统计（归 DD-01）。
- 上游：DD-03 提供同步电流样本、DD-04 提供电角度；下游：`motor_pwm_set_raw` 输出 compare。

## 2. 架构位置

```mermaid
flowchart LR
  DMA[ADC DMA 完成回调] --> RT[foc_runtime_on_current_sample]
  RT --> CM[current_model: raw→A]
  CM --> TR[Clarke/Park] --> PI[Id/Iq 双 PI]
  PI --> IPK[反 Park] --> SVPWM[SVPWM] --> PWM[motor_pwm_set_raw]
```

快路径：上述链路全部运行在 ADC DMA 完成回调上下文，频率 20kHz；慢路径只通过 `foc_runtime_get_last_output()` 读最近一拍结果。

## 3. 文件清单

| 文件 | 角色 |
| --- | --- |
| `foc_runtime.c/.h` | 快路径编排、运行状态、test_mode 门禁、forced angle、保存 last_output |
| `foc_controller.c/.h` | 单步控制：变换+PI+限幅+SVPWM，纯计算 |
| `foc_pi.c/.h` | PI：显式积分限幅+输出限幅+条件积分抗饱和、reset |

| `foc_svpwm.c/.h` | αβ 电压→三相 compare（依赖 bus_voltage 归一化、pwm_period_ticks） |
| `foc_current_model.c/.h` | raw→三相电流（zero/gain/sign，calibrated=0 拒绝输出） |

## 4. 关键数据结构

| 结构/字段 | 单位 | 范围 | 写入者 | 读取者 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `foc_control_input_t` | A/rad/s | — | runtime | controller | 三相电流、电角度、目标、周期 |
| `foc_control_output_t.measured_current_a` | A | — | controller | 慢路径/标定 | dq 实测；**规划补 `phase_current_a` 回填三相** |
| `foc_control_output_t.voltage_command_v` | V | ≤max_voltage | controller | 慢路径/S2·S3 | PI 输出 |
| `foc_pi_state_t.integrator` | V | 积分限幅内 | PI | PI | reset 清零 |

> M1 已在 `foc_control_output_t` 增 `foc_three_phase_t phase_current_a`（单位 A），由 `foc_controller_step` 末尾从 input 回填（纯拷贝，算法不变），供标定窗口采集；其余字段不变。

## 5. 关键流程与状态机

- runtime 状态：STOPPED→READY（configure 校验 calibrated/bus/limit/period）→RUNNING（start，需闭环门禁或 test_mode）→FAULT；
- 坏样本（valid=0/saturated/timeout）直接 `foc_runtime_fail`；
- 角度两来源：标定用 `set_forced_angle`（含 `advance_forced_angle` 慢扫），闭环用编码器电角度。

## 6. 关键机制与取舍

- **抗饱和**：PI 先钳积分项，输出超限且误差仍朝超限方向时条件积分（不继续累积），见 `foc_pi_update`；阶跃/重新对齐前必须 `foc_controller_reset` 清积分。
- **电压双重限幅**：先各轴钳 max_voltage，再对矢量模做圆限制，防单轴/合成超限。
- **test_mode 旁路**：`closed_loop_allowed` 未达标时，仅标定测试固件可经 `foc_runtime_set_test_mode(1)` 临时放行，正常固件不得开启。
- **bus_voltage 是 SVPWM 归一化分母**：无 VBUS ADC，现用假设值，其误差会等比传导到输出电压与 R/L 辨识，必须用外部电源实测值填入。

## 7. 对外接口契约

| 函数 | 前置 | 后置 | 上下文 |
| --- | --- | --- | --- |
| `foc_runtime_configure(const foc_parameter_set_t*)` | calibrated=1、bus/limit/period 合法 | READY | 主循环 |
| `foc_runtime_start()` | READY 且（门禁或 test_mode） | RUNNING | 主循环 |
| `foc_runtime_on_current_sample(sample)` | RUNNING | 单步闭环+写 PWM | **20kHz 中断** |
| `foc_runtime_set_forced_angle/advance_forced_angle` | RUNNING | 更新电角度 | 主循环 |
| `foc_controller_reset()` | — | 双 PI 积分清零 | 主循环 |

> M1 已实现观察钩子：`typedef void (*foc_runtime_output_observer_fn)(const foc_control_output_t*, uint32_t pwm_cycle)` 与 `foc_runtime_set_output_observer()`，在 PWM 更新成功后于快路径回调；标定侧注册 `calib_capture_push` 的适配即可，算法内核不感知标定存在，注销传 0。
