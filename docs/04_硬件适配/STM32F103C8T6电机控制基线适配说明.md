# STM32F103C8T6 电机控制基线适配说明

> 文档定位：本文件定义 STM32F103C8T6 核心板 + STM32_V3P 转接板作为电机控制软件平台的一个硬件适配实例。  
> 平台关系：F103 只是 `HardwareAdapter`，不改变“通用电机控制软件平台”的总体架构。  
> 资料来源：`STM32F103C8T6原理图.pdf`、`STM32转接板原理图.pdf`。  
> 当前目标：先完成 CubeMX 引脚配置、静态诊断、PWM/ADC/I2C/USART 基线，不直接进入功率闭环。

---

## 1. 适配结论

当前转接板已经把 F103 核心板的关键引脚连接到 V3P 接口信号，可以作为首轮主控 MCU 使用。

本适配实例支持：

- M0 三相 PWM 输出。
- M0 两相电流采样。
- M0 编码器 I2C 接口。
- 电机驱动使能脚。
- USART1 调试串口。
- SWD 下载调试。
- HSE 8 MHz 外部晶振。

当前资料不能单独确认：

- `MOTOR_EN` 拉低后的 10 V 栅极电源和功率级失能响应。
- FD6287T 三 PWM 共享 `HINx/LINx#` 的输入/输出时序、固定死区和最小脉宽适配性。
- `M0_OUT1_CS` / `M0_OUT2_CS` 的零点、比例、方向和有效范围。
- 是否有母线电压 `VBUS` / `POWER_ADC` 接入 F103。
- M1 未使用通道在硬件侧是否有默认安全态。

因此，本文件允许进行 CubeMX 配置和无功率输出验证；正式接 V3P 上电前，仍需驱动板原理图或实测记录确认功率级细节。

## 3. MCU 能力边界

STM32F103C8T6 可以用于首轮学习和基线验证，但它不是高性能电机控制 MCU。设计时必须接受以下边界：

| 能力 | 当前适配 | 边界说明 |
| :--- | :------- | :------- |
| 主频 | 72 MHz | 当前用于基线和低速空载实验；FOC 后续再评估 |
| PWM | TIM2 CH1/CH2/CH3 | 普通定时器三相 PWM，不是高级电机控制定时器 |
| ADC | ADC1 IN8/IN9 | 两相电流采样；同步采样能力弱于 F407/G4/H7 |
| DMA/触发 | ADC1 -> DMA1 Channel1 | 已生成循环 DMA 配置；业务层以 DMA 完成中断取得每次软件触发的扫描结果 |
| 编码器接口 | I2C2 + MT6701 | 已用于基线诊断；高带宽闭环暂不作为目标 |
| 调试通信 | USART1 + CH340E | 可满足启动日志和静态诊断 |
| 母线采样 | 当前转接板未见明确接入 | 影响过压/欠压保护，需要补资料或改线 |

## 4. CubeMX 引脚配置表

### 4.0 连接器编号换算规则

STM32F103C8T6 核心板与 STM32_V3P 转接板是物理正向对插，但两份原理图里的 20Pin 连接器符号编号方向相反。因此复核信号时不能按 `P3-n = S1-n`、`P4-n = S2-n` 直接对应。

按当前两份原理图，复核时采用以下位置换算：

```text
P3-n -> S1-(21-n)
P4-n -> S2-(21-n)
```

也就是说：

```text
P3-1  -> S1-20
P3-2  -> S1-19
...
P3-20 -> S1-1

P4-1  -> S2-20
P4-2  -> S2-19
...
P4-20 -> S2-1
```

关键 M0 信号换算如下：

| MCU 引脚 | 核心板接口 | 换算 | 转接板接口 | 转接板信号 |
| :------- | :--------- | :--- | :--------- | :--------- |
| `PA0` | `P3-5` | `21 - 5 = 16` | `S1-16` | `M0_IN1` |
| `PA1` | `P3-6` | `21 - 6 = 15` | `S1-15` | `M0_IN2` |
| `PA2` | `P3-7` | `21 - 7 = 14` | `S1-14` | `M0_IN3` |
| `PB0` | `P3-13` | `21 - 13 = 8` | `S1-8` | `M0_OUT1_CS` |
| `PB1` | `P3-14` | `21 - 14 = 7` | `S1-7` | `M0_OUT2_CS` |
| `PB10` | `P3-15` | `21 - 15 = 6` | `S1-6` | `SCL_0` |
| `PB11` | `P3-16` | `21 - 16 = 5` | `S1-5` | `SDA_0` |
| `PA8` | `P4-16` | `21 - 16 = 5` | `S2-5` | `MOTOR_EN` |

例如 `PB0` 在核心板原理图中是 `P3-13`。如果错误地按同号查转接板，会看到 `S1-13 = M1_IN1`，这会得到错误结论。按实际对插位置换算后，`P3-13 -> S1-8`，对应的才是 `M0_OUT1_CS`。

正式上电前建议用万用表通断档抽查 `PA0 -> M0_IN1`、`PB0 -> M0_OUT1_CS`、`PB1 -> M0_OUT2_CS`、`PA8 -> MOTOR_EN`、`GND -> GND`，把图纸推断变成实物证据。

### 5.1 RCC / Clock

| 项目 | 建议值 |
| :--- | :----- |
| HSE | Crystal/Ceramic Resonator，8 MHz |
| LSE | 可选启用，32.768 kHz |
| PLL Source | HSE |
| PLL Mul | x9 |
| SYSCLK | 72 MHz |
| AHB | 72 MHz |
| APB1 | 36 MHz |
| APB2 | 72 MHz |
| ADC Prescaler | PCLK2 / 6 = 12 MHz |

说明：

- F103 的 ADC 时钟不应超过器件限制。
- 首轮不启用 FreeRTOS。
- `SYS` 调试选择 `Serial Wire`，释放不需要的 JTAG 引脚。

### 5.2 TIM2 PWM

| 项目 | 建议配置 |
| :--- | :------- |
| Timer | `TIM2` |
| Clock Source | Internal Clock |
| Channel | CH1 / CH2 / CH3 |
| Mode | PWM Generation CHx |
| Counter Mode | Up |
| Prescaler | `0` |
| Counter Period | `3599` |
| PWM 频率 | 约 20 kHz，72 MHz / 3600 |
| Pulse | `0` |
| Polarity | High |
| Fast Mode | Disable |

说明：

- 当前配置是首轮验证用的 3PWM 输出。FD6287T 将每一路共享输入转换为互补 `HO/LO` 栅极驱动，并提供约 `100~300 ns` 固定死区；F103 不生成六路互补 PWM，也不配置软件死区。
- `Clock Source` 必须选择 `Internal Clock`；保持 `Disable` 时 TIM2 不计数，无法产生 PWM。
- TIM2 不是高级定时器，没有 TIM1/TIM8 那种完整电机控制特性。
- `CCR=0` 或停止 PWM 不等价于上下管全关；停止/故障路径必须使用 `MOTOR_EN=低` 关闭 BL9342 的 10 V 栅极驱动电源。
- 仍需实测 FD6287T 的 `HOx-VSx`、`LOx-COM` 死区、3.3 V 输入裕量、最小脉宽和自举供电边界。

### 5.3 ADC1

| 项目 | 建议配置 |
| :--- | :------- |
| ADC | `ADC1` |
| Scan Conversion Mode | Enable |
| Continuous Conversion Mode | 首轮 Disable |
| External Trigger | Software Start |
| Data Alignment | Right |
| Number of Conversion | 2 |
| Rank 1 | `ADC1_IN8` / PB0 / `M0_OUT1_CS` |
| Rank 2 | `ADC1_IN9` / PB1 / `M0_OUT2_CS` |
| Sampling Time | 先选较长采样时间，后续按源阻抗和噪声优化 |

说明：

- 首轮目标是确认 ADC 通道连通性、零点、噪声和饱和边界。
- `motor_adc.c` 使用 `HAL_ADC_Start_DMA` 发起 ADC 扫描，并以 DMA 完成回调确认两个 rank 已全部搬运；不再调用 `HAL_ADC_PollForConversion`。
- 保持软件触发和非连续转换：每次读取只采集一组两通道结果，并在复制结果后停止 DMA。循环模式保留为 CubeMX 配置，当前不会让 ADC 自由连续采样。进入 FOC 前，应改为定时器触发，并结合控制周期设计采样窗口。
- 当前转接板未看到母线电压输入接到 ADC，母线保护暂不能闭合。

### 5.4 ADC1 DMA

| 项目 | 当前 CubeMX 配置 |
| :--- | :--------------- |
| DMA Request | `ADC1` |
| DMA Channel | `DMA1 Channel1` |
| Direction | Peripheral To Memory |
| Mode | Circular |
| Peripheral Increment | Disable |
| Memory Increment | Enable |
| Peripheral Data Width | Half Word |
| Memory Data Width | Half Word |
| DMA Priority | High |
| NVIC | `DMA1_Channel1_IRQn`，抢占优先级 0、子优先级 0 |

生成代码会在 `MX_DMA_Init()` 中开启 DMA1 时钟和中断，并在 ADC1 MSP 初始化中将 `hdma_adc1` 链接到 `hadc1`。`MX_DMA_Init()` 必须早于 `MX_ADC1_Init()` 调用，当前生成顺序正确。

采样缓存为两个 `uint16_t` 元素，顺序固定为 `Rank 1 (IN8)`、`Rank 2 (IN9)`。业务层通过 `HAL_ADC_Start_DMA(&hadc1, buffer, 2U)` 启动一次扫描，等待 DMA 完成回调后复制缓存并调用 `HAL_ADC_Stop_DMA()`；不要将 `HAL_ADC_PollForConversion()` 与 DMA 方式混用。

DMA1 Channel1 已被 ADC1 占用。当前不为 I2C2 或 USART1 预配置 DMA：I2C2 与 USART1 的 DMA 映射会争用 DMA1 Channel4/5，且当前编码器读取和日志吞吐量不足以抵消 DMA 管理成本。

## 6. 与 F407 适配的主要差异

| 项目 | F407 旧方案 | F103 当前方案 | 影响 |
| :--- | :---------- | :------------ | :--- |
| 主频 | 168 MHz | 72 MHz | 控制周期和日志预算更紧 |
| PWM 定时器 | TIM8 高级定时器 | TIM2 普通定时器 | 死区、刹车、同步能力下降 |
| ADC | ADC1/ADC2/ADC3 分开 | ADC1 扫描两通道 | 同步采样和母线采样能力下降 |
| 母线采样 | PC2 / ADC3 候选 | 当前未见接入 | 过压/欠压保护缺口 |
| 编码器 I2C | I2C1 PB6/PB7 | I2C2 PB10/PB11 | 驱动适配需改接口 |
| 调试串口 | USART1 PA9/PA10 | USART1 PA9/PA10 | 基本一致 |
| 使能脚 | PD7 | PA8 | GPIO 适配需改 |

结论：

- F103 足够做当前低风险基线、静态诊断、PWM 验证和低速开环。
- F103 不应直接承诺高性能闭环或最终工业关节性能。
- 平台代码应通过适配层迁移，不应把 F103 引脚写死到控制算法里。

## 7. 首轮验证顺序

### BL0：可构建

目标：

- CubeMX 生成工程。
- Keil 或目标工具链可编译。
- 固件能下载。

通过标准：

- 0 error。
- 版本日志或 LED 心跳可识别。

### BL1：安全启动

目标：

- 上电默认不使能功率输出。
- TIM2 三相 compare 初始为 0。
- M1 未使用通道保持低或安全态。

通过标准：

- `PA8` 处于预期安全电平。
- `PA0/PA1/PA2` 无异常 PWM。
- `PA3/PA6/PA7` 不输出有效 M1 PWM。

### BL2：静态采样

目标：

- 读取 PB0/PB1 原始 ADC。
- 读取 I2C2 编码器。
- 输出 USART1 诊断日志。

通过标准：

- ADC 原始值稳定，未接入或零电流时不满量程。
- 编码器角度可读，手转连续。
- 串口日志稳定。

### BL3：PWM 与使能接口（条件通过）

目标：

- 示波器确认 TIM2 三路共享 PWM 以及 FD6287T 的互补 `HO/LO` 输出和固定死区。
- 验证 `MOTOR_EN` 高电平使能、低电平关闭，以及 10 V 栅极电源和 FD6287T 输出的失能响应。

通过标准：

- PWM 频率约 20 kHz。
- 三路占空比可控。
- 失能后功率级无有效输出。
- 当前阶段默认接口按资料成立；若后续空载开环出现异常，再回查三 PWM 共享逻辑、固定死区和失能响应。

### BL4：低速空载开环

当前固件已提供一条仅用于首轮空载验证的开环链路。软件生成预设电角度，经 SVPWM 转换为 TIM2 三相 compare；MT6701 只用于通信与角度变化监视，不参与闭环校正。

```text
串口 s 命令
  -> OPEN_LOOP_READY：检查 ADC/MT6701，启动 PWM
  -> ALIGN：5% 调制量、固定电角度、300 ms
  -> OPEN_LOOP_RUN：10% 调制量，电角频率从 5 Hz 爬升到 20 Hz
  -> 3 s 超时故障，或显式 x 停止进入安全停止
```

2804 为 7 极对电机，因此 20 Hz 电角频率约为 2.86 Hz 机械频率，即约 171 RPM。当前只记录相序、转向和低速启动现象，作为后续 `FOC-PRE` 参数整定输入；不代表电流环、速度环或位置环已经成立。

串口命令为：

| 命令 | 动作 | 约束 |
| :--- | :--- | :--- |
| `s` 或 `S` | 请求一次低速开环 | 仅 `SAFE_IDLE` 可接受 |
| `x` 或 `X` | 请求停止 | 进入失能、PWM 清零和停止路径 |
| `c` 或 `C` | 清除锁存故障 | 仅 `FAULT` 可接受，清除后回到 `SAFE_IDLE` |
| `?` | 输出状态与故障码 | 不改变控制状态 |

开环期间，ADC 读取失败、任一路 ADC 接近满量程、MT6701 连续两次读取失败或 3 s 运行超时均进入 `FAULT`；故障状态不会自动重启。

## 8. 需要补充的驱动板资料

以下内容作为后续回溯和 FOC 运行前准备/参数整定项记录。它们不属于当前基线缺陷，当前基线和空载开环不等待这些项目全部关闭：

| 待确认项 | 为什么必须确认 |
| :------- | :------------- |
| `MOTOR_EN` 失能响应 | 开环异常或停止无效时回溯；拉低后功率级仍可动作必须立即断电 |
| FD6287T 三 PWM 共享输入 | 开环异常时回溯 `M0_INx` 同时接 `HINx/LINx#` 的时序和电平 |
| FD6287T 固定死区 | 当前不单独验收；开环异常时回溯 `100~300 ns` 死区适配性 |
| 电流采样比例和偏置 | 决定 ADC 原始值能否换算电流 |
| 电流采样方向 | 决定 FOC 电流方向和保护判断 |
| 母线电压是否有引出 | 决定欠压/过压保护是否可实现 |
| M1 通道默认态 | 首轮不用 M1，必须保证它不会误动作 |
| 功率级故障输出 | 决定软件能否检测硬件过流/过温等故障 |

## 9. 推荐代码适配点

在代码层面，应把 F103 相关信息集中到平台适配层：

- `board_config_get_motor_pwm_timer()` 返回 `htim2`。
- `board_config_get_phase_u_adc()` / `phase_v_adc()` 绑定 ADC1 的不同 rank 或采样函数。
- `board_config_get_encoder_i2c()` 返回 `hi2c2`。
- `board_config_get_debug_uart()` 返回 `huart1`。
- `BOARD_CONFIG_MOTOR_EN_GPIO_PORT` 改为 `GPIOA`。
- `BOARD_CONFIG_MOTOR_EN_PIN` 改为 `GPIO_PIN_8`。
- `BOARD_CONFIG_PWM_PERIOD_TICKS` 改为 `3599U`。

注意：

- 当前只是文档适配建议，代码修改按已确认的需求执行。
- 如果后续改为 TIM1 或增加互补 PWM，需要重新生成 CubeMX 配置表。

## 10. 当前结论

STM32F103C8T6 + STM32_V3P 转接板可以作为新的首轮主控适配平台，用于：

- 学习和验证平台化代码模型。
- 完成 BL0-BL2 基线，并按条件通过处理 BL3 接口边界。
- 验证 M0 PWM、ADC、I2C、USART 和使能链路。
- 为后续低速空载开环和实验型 FOC 准备软件基础。

但它仍然存在几个必须正视的限制：

- 母线电压采样暂未看到明确接入。
- TIM2 不是高级电机控制定时器。
- ADC 同步采样能力有限。
- 功率级细节仍需 V3P 原理图或实测确认。

因此，F103 当前定位为单电机、空载、低性能要求的基线与控制实验平台，不等同于最终工业关节主控方案。
