# V3P 驱动板软件适配与黑盒验收说明

> 文档定位：本文件定义 DengFOC V3Pro 4.0 商品驱动板作为电机控制软件平台 `PowerStage` 的接口使用方法、启动停止约束和黑盒验收流程。默认板内功率器件、栅极驱动、保护、自举和 PCB 已由厂家完成设计；本文不替代厂家资料，也不承担板内电路的设计、选型或维修。
>
> 资料来源：`C:/Users/21153/Desktop/FOC模拟/V3P驱动板最新版原理图.pdf`，图纸标题 `DengFOC V3pro`，版本 `V3Pro_4.0`，日期 `2025-02-19`。
>
> 当前配套 MCU 适配：`STM32F103C8T6_BASE`。首轮只启用 M0，目标是完成基线、空载低速开环和问题分诊；FOC 后续再按实时性和采样条件进入。

---

## 1. 适配结论与边界

V3Pro 4.0 是一块双通道 BLDC/PMSM 商品驱动板。软件把它当作黑盒功率模块使用：只关心 MCU 输入、传感器输出和电机外部响应，不深入拆分或验证板内 FD6287T、MOSFET、自举、栅极电阻、PCB 布局、散热和保护参数。

当前 F103 适配实例具备以下软件接口：

- M0 三相 PWM：`M0_IN1`、`M0_IN2`、`M0_IN3`。
- M0 两路原始电流采样：`M0_OUT1_CS`、`M0_OUT2_CS`。
- M0 编码器 I2C：`SCL_0`、`SDA_0`。
- 功率级使能网络：`MOTOR_EN`。
- M1 三相输入安全钳位：`M1_IN1`、`M1_IN2`、`M1_IN3`。

软件侧需要确认的是商品板的外部行为：

- MCU 三路 PWM 和 `MOTOR_EN` 是否按接口契约被接受；
- 电机能否在低压、限流和低速条件下受控启动、运行和停止；
- 编码器和原始 ADC 是否连通、变化趋势是否合理；
- 复位、失能、异常电流、异常振动和异常温升是否触发停止。

若外部行为异常，软件只负责把问题分到 MCU/固件、转接接口、V3P 商品板、电机、编码器或采样链路等类别，详细板内原因交由厂家检查。

## 2. 软件可见的模块边界

```text
MCU PWM + MOTOR_EN
        -> V3P 商品驱动板
        -> 三相电机

V3P 原始电流输出 -> MCU ADC
V3P 编码器接口   <-> MCU I2C
```

软件默认 V3P 已完成板内功率桥、栅极驱动、供电、自举和保护设计。F103 基线只使用 M0；M1 在上电、复位和诊断阶段保持无主动控制信号。

## 3. 使用条件与安全边界

| 项目 | 软件使用约束 |
| :--- | :--- |
| 供电 | V3P 电源最大 10 V，12 V 会烧毁驱动板；必须使用不超过 10 V 的限流电源，先完成无电机/低能量验证，再进行低速开环。 |
| 共地 | MCU 与 V3P 按商品板接口建立可靠信号参考地。 |
| `MOTOR_EN` | 高电平使能，低电平关闭；软件停止和故障路径必须使用低电平失能。 |
| PWM | 只输出三路 M0 PWM；不生成六路互补 PWM，不在软件中重复实现死区。 |
| M1 | 当前不使用，保持低电平和无主动 PWM。 |
| 复位/异常 | 上电、复位、下载和通信异常时保持软件安全态；发现电机失控、电流异常或温升异常立即失能。 |

厂家商品板的内部电源、栅极驱动和保护细节不在本项目内重新验证。软件验收关注的是：给定接口信号后，板卡和电机是否出现符合预期的外部现象。出现不符合预期的现象时，停止测试并形成厂家问题记录。

## 4. MCU 接口契约

### 4.1 M0 主通道

| 驱动板网络 | F103 引脚 | CubeMX 绑定 | 方向 | 基线用途 | 当前状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `M0_IN1` | `PA0` | `TIM2_CH1` | MCU -> V3P | 三 PWM 共享 HIN1/LIN1# | 互补逻辑/固定死区由 FD6287T 提供；波形待 BL3 实测 |
| `M0_IN2` | `PA1` | `TIM2_CH2` | MCU -> V3P | 三 PWM 共享 HIN2/LIN2# | 互补逻辑/固定死区由 FD6287T 提供；波形待 BL3 实测 |
| `M0_IN3` | `PA2` | `TIM2_CH3` | MCU -> V3P | 三 PWM 共享 HIN3/LIN3# | 互补逻辑/固定死区由 FD6287T 提供；波形待 BL3 实测 |
| `MOTOR_EN` | `PA8` | GPIO output | MCU -> V3P | BL9342 栅极电源使能 | 高电平使能、低电平关闭；响应待 BL3 实测 |
| `M0_OUT1_CS` | `PB0` | `ADC1_IN8` | V3P -> MCU | 相电流原始采样 1 | 可读原始值，未标定 |
| `M0_OUT2_CS` | `PB1` | `ADC1_IN9` | V3P -> MCU | 相电流原始采样 2 | 可读原始值，未标定 |
| `SCL_0` | `PB10` | `I2C2_SCL` | bidirectional | M0 编码器时钟 | 100 kHz 起步，电平待测 |
| `SDA_0` | `PB11` | `I2C2_SDA` | bidirectional | MT6701 编码器数据 | MT6701 基线读取已验证 |

### 4.2 M1 未使用通道

| 驱动板网络 | F103 引脚 | 基线配置 | 要求 |
| :--- | :--- | :--- | :--- |
| `M1_IN1` | `PA3` | GPIO output, low | 上电和复位后确认没有有效 PWM。 |
| `M1_IN2` | `PA6` | GPIO output, low | 上电和复位后确认没有有效 PWM。 |
| `M1_IN3` | `PA7` | GPIO output, low | 上电和复位后确认没有有效 PWM。 |
| `M1_OUT1_CS` | `PA4` | 未启用 | 后续使用时重新建立 ADC 映射和标定。 |
| `M1_OUT2_CS` | `PA5` | 未启用 | 后续使用时重新建立 ADC 映射和标定。 |
| `SCL_1/SDA_1` | `PB6/PB7` | 未启用 | 保持无误驱动；后续扩展时确认电平与上拉。 |

`POWER_ADC` 在 V3P 原理图中存在，但没有通过当前 F103 转接与 CubeMX 映射到 ADC 输入。因此 F103 固件必须将其标识为不可用，而不是报告为 0 V。

## 5. PWM、栅极驱动与使能

### 5.1 当前软件配置

F103 使用 TIM2 CH1/CH2/CH3 输出三路边沿对齐 PWM：72 MHz 时钟、ARR=3599、约 20 kHz。启动基线要求为：

```text
TIM2 CCR1 = CCR2 = CCR3 = 0
PWM 通道未启动
MOTOR_EN 写入软件约定的安全电平
M1_IN1/2/3 = low
```

### 5.1.1 `MOTOR_EN` 使能链路

最新版原理图中，`MOTOR_EN` 接入 10 V 栅极驱动电源的 `BL9342 EN`。因此当前接口契约为：

```text
PA8 = high (3.3 V) -> BL9342 EN 有效 -> 10 V 栅极电源建立 -> FD6287T 可工作
PA8 = low          -> BL9342 EN 关闭 -> 10 V 栅极电源停止建立
```

原理图中的约 10 kOhm 下拉用于在 MCU 复位/高阻阶段保持默认关闭。这里的软件验收只确认 `MOTOR_EN` 高低电平对应的外部使能/失能现象，不测量或校核板内 10 V 电源、FD6287T 和自举节点参数。

### 5.1.2 三 PWM 商品板使用方式

最新版原理图确认每一路 `M0_INx` 由 V3P 商品板内部转换为对应的上下桥驱动。软件只使用三路 PWM，不生成六路互补 PWM，也不在 MCU 中重复实现死区。

软件侧只需要验证以下现象：

- 三路 PWM 配置后，电机能够在受限条件下响应调制；
- 改变调制量时，电机转速/声音/电流趋势符合预期；
- 低速 SVPWM 开环能够启动且不出现失控、异常振动或快速发热；
- `MOTOR_EN=低` 后电机停止，且没有持续异常电流。

`CCR=0` 或停止 PWM 不作为独立的功率级全关断依据；停止和故障路径使用 `MOTOR_EN=低`。启动时保持 `MOTOR_EN=低`，准备好 PWM 后再按测试流程使能；停止时先失能，再停止 PWM。

### 5.2 软件黑盒验收

不要求软件人员拆板或测量 FD6287T 内部节点。按以下顺序进行外部验证：

1. 无电机、低压限流上电，确认 `MOTOR_EN` 默认低电平，M1 无主动输出。
2. 检查三路 PWM 配置和串口诊断，保持调制量在低风险范围。
3. 在受控条件下运行低速 SVPWM 开环，观察启动、转向、声音、振动、电流趋势和温升。
4. 改变调制量，确认电机响应连续，没有突发失控或异常电流。
5. 拉低 `MOTOR_EN`，确认电机停止；若停止失效，立即断电并归类为接口或商品板问题。
6. 重复编码器手转、ADC 原始采样和复位/通信异常测试。

验收结论只记录外部现象和问题类别，不直接判断 FD6287T、MOSFET、自举或 PCB 内部元件损坏。

## 6. 电流与母线采样

### 6.1 相电流采样

M0 提供两路原始电流采样：`M0_OUT1_CS`、`M0_OUT2_CS`。软件基线先验证 ADC 连通性、静止零点和电机运行时的变化趋势，不重新计算或设计板内采样电路。

**采样链路与标准增益（已对原理图 + TI datasheet 确认，2026-09）**：两路均为低边分流电阻 + 固定增益电流检测放大器 INA240A2PWR（U6/U7），分流电阻 R15/R16 = 0.01Ω。INA240A2 为固定 50 V/V 增益（A1=20/A2=50/A3=100/A4=200，本板为 A2），增益误差 ≤0.20%、零漂移、双向、增强 PWM 抑制；因此传递系数为 `0.01Ω × 50 = 0.5 V/A`。结合 3.3V/4095 ADC：

```text
1 ADC code = 3.3 / 4095 / (0.01 × 50) ≈ 1.612 mA
I_phase[A] = (raw - zero_raw) × 1.612e-3 × phase_sign
```

原理图见 `../assets/V3P_M0_电流采样_INA240A2.png`（VS=3V3，IN+/IN- 接 M0_OUTx_P/N，OUT=M0_OUTx_CS）。该增益作为**板级设计常量直接定档**（`scale_verified` 在零偏质量 OK 后置位），不再按"候选增益"对待；仍需 S1a 实测的只有采样极性 `phase_sign` 与通道自洽，外部电流表校为可选复核。备注：图中 REF1/REF2 接地符号与实测零偏 raw 非中点（U≈730~870、V≈1360~1500）的完整偏置网络仍列为 open 项核对，但不改变增益结论；零电流电平以 S0 实测运行零偏为准。

快速验证阶段允许使用原始 ADC 值做异常观察：接近满量程、完全不变化或与电机现象明显矛盾时停止测试并记录。未完成 S1a 极性判定前，原始值不能直接用于电流闭环，也不能单独宣称具备软件过流保护。电流环准入 = 标准增益已定（scale）且 S1a 方向已验证（direction）。

### 6.2 母线电压采样

V3P 商品板虽然提供 `POWER_ADC` 网络，但当前 F103 没有接入该信号。因此软件报告 `POWER_ADC=unavailable`，快速验证使用外部电源设定和限流条件，不伪造母线电压，也不依据不存在的母线数据做保护决策。

## 7. 编码器、故障与诊断

### 7.1 编码器

V3P 提供两组 I2C 网络：M0 的 `SCL_0/SDA_0` 和 M1 的 `SCL_1/SDA_1`。当前 F103 使用 I2C2 访问 M0 的 MT6701。MT6701 已作为本项目唯一当前编码器型号，现有基线程序已完成基本连通性和角度读取验证。

### 7.2 故障输入

当前原理图及 F103 适配没有定义一条可供 F103 读取的统一 `FAULT` 输入接口。功率测试前必须确认是否存在栅极驱动欠压、过流、过温或其他硬件故障输出，以及它们是否被导出到 MCU。

在故障输入未闭合前，软件必须保持低风险基线定位，不能宣称具有快速硬件保护或自动故障恢复能力。

### 7.3 串口诊断最低输出

静态诊断至少应持续输出：固件版本、适配 ID、软件状态、`MOTOR_EN` 软件状态、PWM compare、两路 ADC 原始值、编码器原始角度与读取状态、`POWER_ADC=unavailable`。

## 8. 分阶段验收

| 级别 | 目标 | 通过证据 | 禁止项 |
| :--- | :--- | :--- | :--- |
| BL0 | MCU 自检 | 可构建、可下载、串口日志、PWM/ADC/I2C/GPIO 初始化正常 | 不接功率输出。 |
| BL1 | 默认安全态 | `MOTOR_EN` 默认低、M1 无主动输出、PWM 未主动运行 | 不接电机或不使能功率级。 |
| BL2 | 传感器与采样连通 | 编码器手转角度连续、ADC 原始值可读且不满量程 | 不把原始 ADC 当作精确电流保护。 |
| BL3 | V3P 黑盒接口边界 | 当前按条件通过；开环异常时回溯三路 PWM、`MOTOR_EN` 和功率级响应 | 不在未限流条件下运行。 |
| BL4 | 低速 SVPWM 开环 | 电机有受控动作响应、停止有效、调制响应可观察且无异常振动/温升；转向作为 FOC-PRE 的整定输入记录 | 不直接进入高速或闭环。 |
| BL5 | 停止与问题分诊 | `MOTOR_EN` 停止有效、异常现象有日志和归属类别 | 不在异常未归类时继续加大功率。 |

任何阶段的立即停止条件：输入电流异常、ADC 接近满量程、`MOTOR_EN` 失能无效、编码器连续超时、M1 出现有效输出、电机失控转动、异常振动、异响或快速温升。

### 8.1 快速问题分诊

| 外部现象 | 软件侧初步判断 | 后续处理 |
| :--- | :--- | :--- |
| MCU 端没有 PWM | 定时器、GPIO、固件配置或下载问题 | 软件排查 |
| MCU PWM 正常但 V3P 无响应 | 使能、转接接口或商品板响应问题 | 软件确认接口后交厂家 |
| 电机抖动、异响或电流快速升高 | 相序、SVPWM 参数、接线、负载或功率板问题 | 先降低功率，再区分软件/厂家 |
| 编码器无响应或角度跳变 | I2C、地址、接线或传感器问题 | 交传感器/厂家检查 |
| ADC 满量程或完全不变化 | 采样接线、商品板采样链路或 ADC 配置问题 | 软件确认通道后交厂家 |
| `MOTOR_EN` 拉低后仍持续动作 | 使能链路或商品板失能异常 | 立即断电并交厂家 |
| 低速可转、高速异常 | 算法参数、采样时序、传感器或功率板边界问题 | 软件与厂家联合分诊 |

快速验证只输出 `PASS`、`FAIL`、`CONDITIONAL` 或“建议厂家检查”，不直接断言 FD6287T、MOSFET、自举或 PCB 内部器件损坏。

## 9. F103 代码映射与待办

`STM32F103C8T6_BASE/Core/Inc/board_config.h` 是当前软件绑定层，应只保存 MCU 引脚、外设和软件安全策略等可追溯事实：

- `BOARD_CONFIG_POWER_STAGE_ID` 标识 V3P 硬件版本。
- `BOARD_CONFIG_PHASE_CURRENT_CALIBRATED=0` 表示不能输出电流物理量。
- `BOARD_CONFIG_POWER_ADC_PRESENT_ON_V3P=1` 且 `BOARD_CONFIG_VBUS_ADC_AVAILABLE=0` 区分“板上有网络”和“MCU 当前不可读”。
- 三 PWM 由 V3P 商品板内部完成互补驱动，F103 不生成六路互补 PWM 或软件死区。
- `MOTOR_EN` 逻辑极性已确认高有效；当前按接口契约使用，开环异常时回溯停止效果。

软件参数和测试结论必须附带固件版本、V3P 版本、供电条件和外部现象记录；板内元件结论交由厂家维护。
