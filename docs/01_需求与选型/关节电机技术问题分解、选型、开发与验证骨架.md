# 电机控制平台技术问题分解、选型、开发与验证骨架

> 原文件名保留为 `关节电机技术问题分解、选型、开发与验证骨架.md`。  
> 新定位：以电机控制平台为中心，关节电机只是重要应用场景之一。  
> 写作原则：以技术问题、接口契约、验证证据为主，减少管理流程和重复填表。

---

## 1. 核心问题

本项目首先要回答的不是“这块板能不能带这个电机转”，而是：

**如何建立一套可迁移、可验证、可扩展的 BLDC/PMSM 电机控制软件平台。**

当前小电机台架的作用是提供第一套参考硬件，用于验证：

- 软件模型是否能正确抽象电机控制系统。
- 硬件适配层是否能隔离 MCU、功率级、电机和传感器差异。
- 分阶段验证方法是否能把风险从静态测量推进到闭环控制。
- 参数、故障、诊断和测试证据是否能沉淀为长期资产。

## 3. 平台与应用边界

### 3.1 平台负责

- 电机控制状态机。
- 功率输出安全边界。
- PWM/SVPWM 输出链路。
- 电流、电压、位置反馈抽象。
- FOC 和控制环入口。
- 参数、标定、故障、诊断。
- 硬件能力契约和适配接口。
- 分阶段验证方法。

### 3.2 硬件适配负责

- MCU 外设实例绑定。
- ADC/TIM/DMA/IRQ/GPIO/UART/I2C/SPI/CAN 初始化。
- 采样比例、偏置、极性、滤波。
- PWM 计数周期、死区、极性、刹车。
- 功率级使能、故障输入、电平约定。
- 传感器协议、方向、零位和异常映射。

### 3.3 关节应用负责

- 输出侧减速比和方向。
- 机械限位、软限位和回零。
- 位置/速度/力矩模式语义。
- 抱闸、STO、急停等产品级安全链。
- 多关节同步和中央控制协议。
- 应用工况、负载谱、热边界和寿命要求。

## 4. 硬件能力选型

### 4.1 MCU

MCU 选型不应只看型号，而应看能力契约。

必须确认：

- 主频和 FPU 能否满足控制周期。
- 是否有适合电机控制的高级定时器。
- PWM 是否支持中心对齐、互补输出、死区、刹车。
- ADC 是否支持足够采样率、通道数和触发方式。
- DMA/中断是否能降低实时路径抖动。
- 是否有足够通信接口承载调试和产品协议。
- 复位、下载、异常中断期间输出是否保持安全。

当前 STM32F103 是首轮参考适配平台，不是平台唯一目标。后续 STM32F407/G4/H7 或其他 MCU 可以成为新的适配平台。

### 4.2 功率级

功率级选型必须确认：

- 母线电压范围和浪涌边界。
- 连续电流、峰值电流、峰值持续时间和散热条件。
- 栅极驱动逻辑、PWM 输入要求和死区要求。
- 电流采样拓扑：低边、相线、母线、一相/两相/三相。
- 采样电阻、放大器、偏置、线性范围和带宽。
- 硬件保护：过流、欠压、过温、故障输出、刹车。
- 默认安全态和失能响应时间。

当前 V3P/V3Pro 是低成本验证功率级，不代表最终工业功率级。

### 4.3 电机

电机接入平台时必须确认：

- 电机类型：BLDC/PMSM，是否适合 FOC。
- 极对数、相序、方向。
- Rs、Ls、磁链或 KV 换算。
- 连续/峰值电流和热边界。
- 机械惯量、负载范围、速度范围。
- 绝缘、温升、安装和散热条件。

2804 只用于当前单电机、空载、低风险台架验证，不关闭最终关节选型问题。图片给出的初始参数为：12N14P、7 极对、7.4~20 V（电机资料标称）、1 A 持续电流上限、KV 约 220 RPM/V、绕组电阻 5.1 ohm、相电阻 2.3 ohm、绕组电感 2.8 mH、相电感 0.86 mH、磁链 0.0035 Wb。当前 V3P 驱动板电源不得超过 10 V，12 V 会烧毁驱动板；实验应从更低电压和限流条件开始。电阻定义和采样比例后续补充。

### 4.4 位置反馈

位置反馈选型必须确认：

- 协议：I2C、SPI、ABI、Hall、Resolver、无感估算。
- 分辨率、更新率、延迟和抖动。
- 方向、零位、跨零点和错误状态。
- 抗干扰和线缆长度。
- 与控制环带宽是否匹配。

当前采用 MT6701，现有基线程序已完成基本连通性和角度读取验证。进入高速闭环前仍需评估 I2C 延迟，但这不阻塞当前基线和空载开环。

## 5. 关键技术问题

### 5.1 PWM 与 SVPWM

需要回答：

- PWM 频率如何选择。
- 中心对齐还是边沿对齐。
- 死区由 MCU 还是功率级负责。
- 三相 duty 的有效范围。
- SVPWM 输出如何限幅。
- 失能时三相输出应是什么状态。
- PWM 更新点与 ADC 采样点如何同步。

必须验证：

- 上电默认无危险脉冲。
- 启动和停止无异常毛刺。
- 频率、占空比、极性和死区与设计一致。
- 失能延迟满足风险边界。

### 5.2 电流采样

需要回答：

- 采样几相电流。
- 采样点位于 PWM 周期哪个位置。
- 零偏如何测量和温漂如何处理。
- 比例、极性、线性区如何标定。
- ADC 满量程对应多大电流。
- 噪声是否满足电流环要求。
- 采样失败或饱和如何进入故障。

当前阶段允许先读原始 ADC。进入 FOC 前必须建立物理量换算和同步采样。

### 5.3 母线电压

需要回答：

- 分压比和 ADC 满量程。
- 过压、欠压阈值来源。
- 回生导致母线抬升时如何处理。
- 母线采样需要多快。
- 母线异常是否禁止使能或触发停止。

### 5.4 转子位置

需要回答：

- 机械角到电角度如何换算。
- 极对数如何确认。
- 传感器方向和电机相序如何匹配。
- 零位如何标定。
- 编码器跳变、丢帧、无磁场、超时如何处理。
- 传感器延迟是否限制控制带宽。

### 5.5 FOC 与控制环

建议逐级建立：

1. 开环电角度扫描。
2. 相序、方向、极对数确认。
3. 电角度零位对齐。
4. Clarke/Park 变换。
5. 电流环 PI。
6. SVPWM 输出。
7. 速度环。
8. 位置环。

每一级都必须有限幅、超时和停止条件。

## 6. 状态机与安全边界

推荐状态：

```text
BOOT
  -> SAFE_IDLE
  -> STATIC_DIAG
  -> PWM_TEST
  -> OPEN_LOOP_TEST
  -> ALIGN
  -> CLOSED_LOOP
  -> STOPPING
  -> SAFE_IDLE

任意状态 -> FAULT
```

功率输出使能必须同时满足：

- 当前状态允许输出。
- 参数有效。
- 母线电压有效。
- 电流采样有效。
- 位置反馈满足当前控制模式要求。
- 没有锁存故障。
- PWM 已处于可控状态。
- 命令未超时。
- 外部安全条件允许。

任何一个条件失效，都必须进入受控停止或故障失能。

## 7. 参数与标定问题

参数不是简单配置值，而是控制系统的一部分。

| 参数组 | 示例 | 来源 |
| :----- | :--- | :--- |
| 硬件适配 | ADC 比例、使能极性、PWM 周期、死区 | 原理图 + 实测 |
| 电机模型 | 极对数、Rs、Ls、磁链、限流 | 数据手册 + 辨识 |
| 传感器 | 方向、零位、分辨率、延迟 | 实测 + 标定 |
| 控制环 | Kp、Ki、限幅、带宽 | 计算 + 试验 |
| 应用 | 减速比、软限位、最大速度、最大力矩 | 机械系统 + 工况 |
| 保护 | 过流、过压、欠压、过温、跟随误差 | 硬件边界 + 试验 |

每个参数必须有单位、范围、来源、适用硬件和版本。无法说明来源的参数不能作为保护阈值或发布参数。

## 8. 通信与接口

平台最低接口应支持：

- 查询版本。
- 查询状态。
- 查询故障。
- 查询关键采样值。
- 设置受限测试模式。
- 触发停止。
- 清除满足恢复条件的故障。

关节应用接口再扩展：

- 位置目标。
- 速度目标。
- 力矩/电流目标。
- 模式切换。
- 时间戳或周期号。
- 目标有效期。
- 限幅反馈。
- 多轴同步信息。

通信异常必须定义：

- 超时后动作。
- 重复帧处理。
- 乱序处理。
- 版本不兼容处理。
- 上位机或控制器重启后的目标清空策略。

## 9. 当前参考平台 A 的技术问题

当前平台需要关闭的问题：

| ID | 问题 | 证据 |
| :-- | :--- | :--- |
| A-HW | 实物版本、丝印、接线和供电是否与资料一致 | 照片、通断、原理图对照 |
| A-PWR | V3P 上电、默认态、反灌和使能极性是否安全 | 万用表、示波器、限流电源 |
| A-PWM | TIM2 到 V3P 三相输入的频率、极性、失能是否正确 | 开环异常时回溯；当前按条件通过 |
| A-ADC | 两相电流原始值和零点、比例、噪声是否可信 | 原始 ADC + 后续标定 |
| A-ENC | MT6701 的角度、方向、跨零、异常状态是否明确 | 基线日志；当前基本连通性已验证 |
| A-MOT | 2804 的极对数、相序、电阻、电感和限流边界是否确认 | 测量和受限试验 |
| A-RUN | 低风险开环转动是否可重复 | 固件、参数、日志、视频/波形 |

这些问题关闭后，只能说明参考平台 A 成立，不等于其他平台成立。

## 10. 验证路线

| 阶段 | 测试重点 | 禁止事项 |
| :--- | :------- | :------- |
| BL0 | 编译、下载、版本 | 不连接功率输出 |
| BL1 | 默认安全态、日志、复位 | 不使能驱动 |
| BL2 | ADC、母线、编码器静态链路 | 不主动转动 |
| BL3 | PWM、使能、失能、死区 | 不闭环 |
| BL4 | 受限开环动作和停止边界 | 不长时间运行 |
| FOC-PRE | 相序/方向/零位、采样标定和实时性准备 | 不直接进入高速/高负载 |
| BL5 | FOC、电流环、限流 | 不进入高速/高负载 |
| BL6 | 速度/位置基础 | 不越过已验证边界 |

BL4 只验收平台能否在受限条件下动作并可靠停止。相序、MT6701 方向、电角度零位、采样比例和控制周期等属于后续 `FOC-PRE` 的参数整定与运行准备，不作为基线失败条件。

测试记录必须包含：

- 硬件版本。
- 固件版本。
- 参数版本。
- 接线和供电条件。
- 仪器和测量点。
- 原始数据。
- 通过标准。
- 失败路径。
- 结论和限制。

## 11. 故障注入

至少设计以下故障注入：

- 电流采样开路、短路、饱和。
- 母线过压、欠压。
- 编码器断线、无磁场、跳变、超时。
- 命令超时。
- 参数 CRC 错误或版本不匹配。
- PWM 输出异常。
- 使能脚极性错误或硬件故障输入。
- 堵转、超速、跟随误差。
- 电机或驱动过温。

每个故障都要验证：

- 是否能检测。
- 检测时间。
- 本地动作。
- 上报内容。
- 是否锁存。
- 恢复条件。

## 12. 技术关闭标准

一个技术问题可以关闭，必须满足：

- 问题边界清楚。
- 输入数据来源明确。
- 关键假设写清。
- 有计算、测量或试验证据。
- 结论绑定硬件、固件、参数和测试条件。
- 知道哪些结论可以迁移，哪些不能迁移。
- 失败和异常路径有处理。

一个平台适配可以关闭，必须满足：

- 硬件能力契约全部回答。
- 安全启动和失能路径通过。
- PWM、ADC、传感器和功率级链路通过。
- 参数和标定可追溯。
- 至少完成对应 BL 级别的验收。

一个关节应用可以关闭，必须在平台适配之外额外证明：

- 机械限位和方向正确。
- 减速比和输出侧单位正确。
- 模式切换无冲击。
- 热、负载和故障边界满足应用工况。
- 与上位机或中央控制器接口一致。

## 13. 当前项目建议路线

1. 先确认平台架构文档，统一“软件平台 + 硬件适配”的思想。
2. 保持当前代码的安全启动和静态诊断能力。
3. 把 F103/V3P/2804/MT6701 作为 `platform_f103_v3p_a` 适配实例。
4. 完成 BL0-BL2，不依赖功率输出。
5. BL3 当前按条件通过处理；开环异常时回查 PWM、使能和失能链路。
6. 完成 BL4，低风险开环。
7. FOC、电流环和闭环暂缓，待基线和空载开环稳定后再进入。
8. 当更换硬件时，只新增适配记录和重做硬件相关验证，不重写平台思想。
