## 5. 结果与判定（分步判）

| 判据 | 实测 | 阈值/预期 | 通过? |
| --- | --- | --- | --- |
| 步骤顺序 | DIR 在 PHASE_SEQ 前 | 方案 A | 是 |
| 物理 CCW → dir | +1（+0.3102 rad） | 与 CW 轮反号 | 是 |
| verify 终态相序 | perm4（best5 经一次镜像） | 与 perm5/dir−1 物理等价 | 是 |
| S5 零位 | 4.920627，std=0，fr=0 | std≤0.05、fr≤0.08 | 是 |
| 电机实际转动 | 是（转向跟随本轮标定正方向，与 CW 轮相反） | 应转动 | 是 |
| S7 电流收敛 | id 均值≈0.28（目标0.10）、iq −0.030~+0.086（目标0.18） | id≈0.10、iq≈0.18 | **否** |
| S7 dyn_R | 8.3485Ω（2.25×base） | [1.858,5.573] | **否（软拒绝，无失控）** |

- **结论**：S0–S5 + 方向/相序链**通过**；S7 **未通过**（dyn_R 超窗），无鸣叫、无复位、电机可转动。
- 输出参数（RAM only）：encoder_direction=+1、phase_map=perm4(a->2,b->0,c->1)、encoder_offset=4.920627 rad、R=3.7154Ω（trusted）、L 回退标称 0.86mH。

### 两轮等价性证明（方案 A 鲁棒性的核心证据）

| 量 | CW 轮 | CCW 轮 | 等价关系 |
| --- | --- | --- | --- |
| dir | −1 | +1 | 反号 |
| phase_map | perm5 (2,1,0) | perm4 (2,0,1) | 镜像对 idx^1（B/C 互换） |
| offset | 1.324209 | 4.920627 | 2π−4.920627=1.36256，与 1.324209 残差 0.038rad（S5 残差级） |
| 物理结果 | 转动 | 反向转动 | 同一物理校准的两种等价表达 |

结论：方案 A 后，手转方向只改变表达形式、不改变校准正确性——修改前"相序结论随手转方向变"的路径依赖已消除。
