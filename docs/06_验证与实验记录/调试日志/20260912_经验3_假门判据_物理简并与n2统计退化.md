## 0. 本篇只讲三条

1. **判据如果在两种候选假设下取值相同，它就是假门——物理上不携带待求量的信息。** 调门限、加滤波、多采样都救不了，只能换一个"候选可分"的观测量。
2. **统计判据会随样本数退化：n=2 时圆周 std ≈ fwd_rev/2，两道门坍缩成一道，"ok=1"的信息量比看起来少。**
3. **静态选优在简并条件下不可靠（best 跨天漂移）；真正稳定的是旋转手性这种携带信息的判据。**

## 2. 三条经验讲透

### 2.1 物理简并：判据在两种候选下取值相同 = 假门

θ=0 时 b、c 两相绕组等电位。镜像排列就是 B/C 输出互换，于是**正确排列与镜像排列在 θ=0 的三相读数逐字相同**——静态测量对"镜像变换"不变，数学上不含手性信息。这叫**物理简并（degeneracy）**：待求量（手性）无论取哪个值，观测量都一样，判据对它的偏导为 0、信息量为 0。

旧的 3ms Iq 瞬态判据想"不让转子动"再读电流，等于刻意停在简并点附近，信号又被噪声淹没（±0.03A vs 门限 0.15A，低 5 倍），结论恒 inconclusive 是必然，不是运气差。

**正确动作是换观测量维度，不是调门限。** 镜像排列唯一的物理区分量是**旋转手性**：让磁场真的推进一个 +90° 电角并保持 300ms 让转子就位，用编码器电角度增量 `Δelec=pp·dir·wrap(Δmech)` 判决——编码器是数字量，对电流噪声免疫，且"正确排列出净力矩、镜像排列力矩自抵消"，两种候选下 Δelec 符号相反，候选可分。三时期实测 Δelec 稳定在 −1.5~−1.6，再没漂过。

> 一般化判据自检：写下两个竞争假设 H0/H1，问"我这个观测量在 H0 和 H1 下会不会不同？"——若不会，无论它测得多准都是假门，先换物理量再谈精度。这与经验1 的"方程秩"是同一件事的两面：简并观测量就是系数为 0、不增加秩的方程。

### 2.2 统计退化：n=2 时两道门坍缩成一道

S5 正反各对齐一次，n=2，两次读数之间只剩**一个间隔 Δ=fwd_rev**。圆周 std 的精确式是 `std=√(−2·ln cos(Δ/2))`，小角度下 `ln cos x≈−x²/2`，于是：

```
std ≈ Δ/2 = fwd_rev/2        // n=2 时两个统计量被同一个 Δ 锁死
```

也就是说"std 门"和"fwd_rev 门"在 n=2 下不是两个独立证据，是**同一个量的两种写法**。看着是双保险，实际是一道门；其中一个超差，另一个必然贴着门限走。五轮数据全部命中（[A]）：

| 轮次 | fwd_rev | fwd_rev/2 | 实测 std |
| --- | --- | --- | --- |
| 22:17 | 0.0307 | 0.01535 | 0.0153 ✓ |
| 对照 CCW | 0.0027 | 0.00135 | 0.0013 ✓ |
| 对照 CW boot2 | 0.0955 | 0.04775 | 0.0478 ✓ |
| 方案A后 CW | 0.0107 | 0.00535 | 0.0054 ✓ |
| 方案A后 CCW | 0.0000 | 0 | 0.0000 ✓ |

**教训**：用复合统计量当多重判据前，先算它们在当前 n 下是否独立。样本太少导致"多个判据"退化时，要么显式报告 n 并降低证据权重，要么加采样点把独立性补回来（本案已列 backlog：S5 增加对齐次数或显式报告 n）。

### 2.3 静态选优不可靠，稳定的是携带信息的判据

硬件全程冻结（接线没动），静态 best 却跨时期漂移：0910 选 perm1、22:17 选 perm1（pass=2）、0912 选 perm4/perm5（pass=6），连"几组通过"都在变。原因正是 §2.1：简并点上的分数被零偏、温升、测量侧改动等次要因素推着走，**它本来就没有分辨正确答案的能力**，漂移是结构性的、不是噪声偶发。

对比之下，旋转手性 verify 的 Δelec 在同样这些轮次里始终 −1.5~−1.6。结论：
- **选优/打分类判据只有在观测量对候选可分时才有资格做裁决**；简并条件下它最多做粗筛，最终裁决必须交给携带信息的物理量；
- 当一个"最优值"在重复实验里不稳定，先怀疑判据本身（假门），而不是怀疑硬件漂了。

## 4. 一句话带走 + 迁移用法

**一句话：判据先过"候选可分性"这一关——物理简并下测再准也是假门；统计判据先查当前 n 下是否还独立。**

迁移 checklist：
1. 设计任何 pass/fail 判据前，先列 H0/H1，确认观测量在两者下取值不同；相同就是假门，换物理量而非调阈值；
2. 用多个统计量做"多重保险"前，写出它们在实际样本数下的关系，确认彼此独立；n 太小导致退化就显式报告、降权或补样本；
3. 一个选优结果重复实验不稳，先查判据是否站在简并点上，再怀疑硬件；
4. 优先用"数字量/积分量/旋转量"这类对噪声不敏感、且候选可分的物理量做最终裁决。
