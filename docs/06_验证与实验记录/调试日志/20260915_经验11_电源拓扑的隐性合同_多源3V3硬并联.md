# 经验11 · 电源拓扑的隐性合同：多源 3V3 硬并联

> 专题：编码器之乱的系统级终审（2026-09-15，续经验10）——"拔掉 ST-Link 就好"背后的原理图必然性
> 状态：**结案**。控制变量判决（拔 ST-Link→链路复原）+ 两份原理图电源网络对齐（V3pro_4.0 驱动板 + STM32_V3P 转接板）互证
> 姊妹篇：经验10（多子系统公共源与拔线判决——本篇是其根因的下钻：公共源具体是哪张网、为什么裸）

## 0. 本篇只讲两条

1. **多块板拼系统时存在一份"隐性电源合同"：每张电源网上允许多少个源、有没有隔离/选择器件——这份合同图纸上不会写"禁止"，但物理上会用噪声与倒灌执行违约罚则。**
2. **调试器是电源系统的隐形参与者**：供电型探针的 3.3V 脚接上自供电目标 = 两个毫欧级电压源硬并联——症状会出现在离它最远的子系统（本例：编码器 I2C），让你在错误的地方查三天。

## 1. 判决链回顾（三步定音）

| 步 | 实验 | 结果 |
| --- | --- | --- |
| 1 | 换新编码器 | boot 零偏秒过（旧编码器拖轨病愈），但使能后仍 `encoder lost` + **假转速 −2000rpm**（10V 母线下物理不可能 → 判定 I2C 位错误） |
| 2 | **拔 ST-Link（控制变量）** | 编码器回归正常，正反转全程稳 |
| 3 | 原理图电源网络对齐 | 找到拓扑必然性（下节）——拔 ST-Link 不是巧合，是移除了并联源 |

## 2. 拓扑事实（两份原理图走读结论）

```
驱动板 U14 LDO(XC6210) ──3V3 母线（H8↔E1 排线）── 转接板 ──S1/S2── 核心板 LDO
                                              └──（若接线）── ST-Link 棒载 LDO
   ↑ 母线全导线直连：无二极管/磁珠/0Ω 选择点（D16 只保护 ESP32 座这一支）
   ↑ 母线负载：INA240 REF1/REF2（电流采样参考！）、FD6287 逻辑侧、STM32 VREF+、CH340E、编码器
```

三个要点：

1. **三个 LDO 可以硬并联在同一张铜皮上**（驱动板 U14 / 核心板 / ST-Link 棒），标称同为 3.3V、实际 ±2% 各异——电压最高者独占供电，其余被倒灌（XC6210 的体二极管反向给 5V 网充电、工作点错乱）；
2. **这张网就是电流采样的参考**——污染不经过任何衰减直接进 FOC 电流环零点（解释零偏劣化/采样毛刺）；
3. **设计者不是不知道**——D16 给 ESP32 座做了单向防倒灌，说明"要防并联"是意识到的；但对外的 H8/H7 裸着，**保护做了局部、漏了系统**。

## 3. 症状全解释（终版机理表）

| 症状 | 机理 |
| --- | --- |
| I2C 位错误/假转速 −2000rpm | PWM 开关 → 地弹/轨扰动 → 母线纹波（含 ST-Link USB 侧数字纹波）→ SDA/SCL 电平参考被扰动 → 位翻转 → 角度野值 → 滑窗差分累出假转速 |
| `encoder lost`（新旧编码器同病） | 同上恶化成连续读失败；ST-Link 的 USB 地还构成第二条地回路 |
| 零偏 10/10 挂（仅旧编码器） | 旧编码器芯片损坏额外拖轨（经验10 判决维持）——两病叠加期 |
| 使能后几秒才死/间歇性 | 并联源互灌量随 PWM 负载/USB 活动浮动，临界抖动 |

## 4. 接线规矩（实验室铁律）

| 情形 | 判定 |
| --- | --- |
| VIN 上电 + ST-Link 只接 **SWDIO/SWCLK/GND** 三根 | ✅ 推荐工况 |
| VIN 上电 + 供电型棒的 3.3V 也接 | ❌ 硬并联（本篇病因） |
| 仅 ST-Link 3.3V 供电烧录（VIN 断） | ⚠️ 单源可临时用，勿使能电机、勿久留（U14 输出被反向驱动非设计工况） |
| 核心板 USB 与转接板 Type-C 同插 | ❌ 5V 网另一处隐藏并联 |

配套两条（原理图顺带发现）：**H7 是裸电源排针**——日后从它外接电源同样是并联入口；转接板 Type-C 的 **CC1/CC2 无 5.1k 下拉**——C-to-C 线可能协商不出 5V，用 A-to-C。

## 5. 30 秒自检法（任何"多板+调试器"台面通用）

1. 画出每张电源网（5V/3V3），标出**所有源**（每块板的 LDO、USB、调试器）与**所有隔离器件**——找不到选择点的就是并联点；
2. 万用表电流档串进调试器 3.3V 线：持续 >10mA（任何方向）= 正在互灌；
3. 示波器 AC 10mV/格探 3V3，对比使能前后纹波——污染直观可见；
4. 判探针类型：探针只插 USB 不接目标，量 3.3V 脚——能稳定输出带载的就是供电型（多数山寨 V2 棒）；正版 VTREF 是高阻检测，可接不并联。

## 6. 预测-实测回填

| 预测 | 实测 | 判定 |
| --- | --- | --- |
| （2026-09-14）"编码器拖轨是全部根因" | 换新后链路病仍在 | **错**——是并发病；系统拓扑（并联源）才是链路病的使能条件。经验10 已补勘误块 |
| 假转速=位错误幻觉 | 拔 ST-Link 后故障消失，但假转速仍在（−2000rpm 形态平滑单调）→ **部分对、机理修正**：位错误解释掉线，解释不了平滑假转速——后判为磁环标度问题（多极磁环嫌疑，见 §7 注） | **修正** |
| 三根线接法下 ST-Link 在场无复发 | 2026-09-15 复测：三线在场，零流+双向阶梯全场 **零 encoder lost** | **对** |
| ST-Link 为供电型（3.3V=LDO 输出，可独立给目标供电） | owner 实测确认：本实验室棒**可直接单独给单片机供电烧录**（2026-09-15） | **对**——硬并联机理坐实，全案闭环 |

> §7 注（2026-09-15 追加）：链路治愈后假转速（−2000rpm@0.25A）仍在且随电流平滑变化——10V 母线物理不可能，判定为**编码器标度问题**：新模块疑似配多极磁环（角度=机械角×N，N=4 时 −2000/4=−500rpm 恰落电压饱和天花板，全数据点自洽）。判决实验：轴做记号手转一整圈，`i` 读 raw——变化 16384=单极对；4×16384=多极实锤。解决：换单极对（径向充磁）磁铁，或在 `foc_mechanical_raw_to_rad` 处 ÷N 软件补偿（临时）。
> 【勘误 2026-09-15 晚】上述多极磁环假说**否决**：换新编码器后的全序列重标定（rev=4）中，PHASE_SEQ verify 实测 dmech=0.2209 rad，与 +90° 电角阶跃 ÷7pp 的理论值 0.2244 rad 误差 2%——**编码器标度 1:1 标定级确认**（多极磁环会读 0.898 rad 并导致 verify 失败）。−2000rpm 的剩余嫌疑人改为**母线电压假设失效**：固件 `vbus_adc=unavailable`、`assumed_bus=10V` 为写死假设，若台电源实际电压更高则"假转速"实为真转速。教训：**遥测里的"单位换算"与"上限判断"都建立在假设值上时，先验证假设值本身**。

## 7. 迁移用法（含 Arduino UNO 旧事）

- **Arduino UNO 记忆对上了**：正牌 UNO 有电源路径管理（运放+PMOS 比较 USB 5V 与 VIN 自动二选一）——山寨板常省略成并联，"串口与电源同插出异常"即本族轻症。判别法同 §5；
- 任何"核心板+扩展板+调试器+USB 串口"的组合，开工第一天先画**电源源点图**——五分钟防三天的病；
- 症状在 A 子系统、根因在 B 子系统时，先查它们**共享的物理量**（电源网/地/时钟），再查各自的代码。

## 8. 一句话带走

**多板系统开工第一图不是接线图，是"电源源点图"——每张网上有几个源、有没有选择器件；调试器的 3.3V 是源不是参考，接上去的瞬间它就成了你系统的一部分，而账单会寄到离它最远的那个子系统。**
