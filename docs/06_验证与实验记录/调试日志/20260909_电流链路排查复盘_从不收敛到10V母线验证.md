# 调试复盘 · 电流链路：从闭环不收敛到 10V 母线验证打通

> 状态：**阶段闭环**（功率+采样链路已证实打通；相序/采样符号未标定，转入三角度相序探针）
> 日期：2026-09-09　主线固件：F103-identification-test-0.4（突破固件 hex=123515B，Code=41160 / ZI=5636，0E/0W）
> 硬件：STM32F103C8T6 + DengFOC V3Pro4.0（仅 M0 通道）+ 2804 PMSM(pp=7, R≈2.3Ω, L≈0.86mH) + MT6701
> 关联：SPEC-CAL S1 ↔ DD-01 标定序列 ↔ DD-02 电流控制环 ↔ DD-03 电流采样 ↔ HW-DRV；过程细节见同目录 `20260908_S1电流环卡死排查与算力降载.md` §11~§12
> 类型：跨多轮的**决策复盘**——一条"电流到底有没有真正受控"的主线，记录每个假设怎么提出、被什么事实证伪、最后靠什么实验一锤定音。

## 0. 结论速览（TL;DR）

整条主线经历三个阶段，两次"看起来是软件问题、最后被实验改写结论"：

1. **闭环鸣叫不收敛** → 先怀疑无 FPU 的 M3 算力不足，做降载三改；降载后主循环恢复但电流仍发散，真正根因是**采样符号(sign)未标定就先建电流环（控制层循环论证）**。
2. **改为开环爬坡后，6V 上板 du 对电压零响应** → 走查软件链路无旁路、读原理图逐项排除，提出供电/栅驱/标度等假设；**没有在纸面继续空转，而是直接升到 10V 标度对齐 + 手动对齐保持(HOLD)做判决性实验**。
3. **10V HOLD 一分钟出结果**：raw 电流稳定离开噪声带、手转有阻尼，**一次性证实整条"功率管→栅驱→MOS→in-line 采样→ADC"链路是通的**，同时实锤真正缺的是**相序/采样符号标定**（θ=0 两相电流同号且幅度倒置）。

> 一句话：**讨论十次不如动手一次**——在安全兜底（CC 限流、低压、空载、可随时 x）下，一个一分钟的判决性实验，裁决了争论多轮的算力、软件旁路、低边采样窗口、MOS 损坏等一堆假设。

## 2. 决策时间线（假设 → 事实验证 → 结论 → 下一步决定）

### 阶段 0　闭环鸣叫：先怀疑算力，降载后证伪，定位"循环论证"

- **现象**：发 `p` 进 S1 后先是串口卡死；加使能里程碑/ISR 心跳/HardFault 直写三类插桩，定位为 20kHz 快路径软浮点在无 FPU 的 M3 上占满 CPU、主循环被饿死。
- **动作（降载三改）**：同角度 sin/cos 只算一次（4→2 次 trig）；电流环 20kHz→10kHz（TIM2/TIM3 ARR 3599→7199，Ts 单一源联动）；关闭 DMA 半传输(HT)空中断。
- **事实验证**：Rebuild 0E/0W；上板 `enter` 每 100ms +≈1005，自证真实环频=10kHz、样本全有效——**算力问题闭环**。
- **但**：Id 目标 0.04A、实测仍 0.14~0.19A 抖动并鸣叫、SETTLE 超时。排除"PI 太猛"（Kp=0.086/Ki=230/Tc=10ms 偏温和）。
- **真正根因**：旧 S1 在**采样符号未验证**时先用默认 sign=+1 建电流环，sign 反则 SETTLE 正反馈发散，永远到不了"判符号"那一步——**控制层用了待证的量去闭环，属循环论证**（早期只在测量层防了，控制层没防）。
- **决定**：S1 拆两段——S1a **开环 raw 层**先定 sign/通道（不依赖闭环），写 sign、置 direction_verified 后，S1b 再建环自证。控制器新增 `VOLTAGE` 开环模式（跳过两 PI、直接给 Vd/Vq、仍矢量限幅），`foc_runtime_start` 按模式门禁：CURRENT 必须 closed_loop_allowed、VOLTAGE 仅 test_mode。

### 阶段 1　S1a 开环爬坡（方案 B）+ 上板前静态走查加固

- **演进**：固定 ±0.09V 上板信噪比不足（理论 ~24code < 零偏噪声，实测 7~13code 判 weak）→ 升级为**电压爬坡扫描 + V-I 最小二乘**：0.05V 起、0.03V/档、单向 ≤10 档、VEND=0.31V 兜底，档内 RAMP3/SETTLE5/COLLECT35ms、正负双向追平档数；`s1a_fit` 出斜率符号(sign)、斜率比 kv/ku(通道)、斜率反推粗 R、截距(死区 Voff)、六判据。
- **静态走查四加固（不接电先算）**：实算档位-code 表（1code=1.6117mA，R=2.3 时 0.05/0.08V 档仅 13.5/21.6code，小于零偏 p2p 噪声带）→ ①新增 `MIN_USABLE_RAW=30`，只把 |du|≥30code 的档纳入拟合（扫描表仍全量打印）；②fit 工作数组全 static 化削栈约 240B（启动栈仅 1KB）；③补 BASELINE 无样本的除零保护；④撞轨判据由档末瞬时值改档内均值。0E/0W，PC 单测同步（本机无 gcc，源码交付未实跑）。

### 阶段 2　6V 上板 du 零响应：软件走查 + 假设清单（关键岔路口）

- **现象**：20 档全打印，机制全对（未卡死/未撞轨/未硬过流），但 du 全在 ±12code、对 Vd 大小不单调、正负方向都不翻转，筛后有效点=0 → ku/kv/r2 全 0，判据**诚实判 NOGO**（没有降门限凑通过）。
- **软件走查**：逐行确认开环链路无旁路/清零——`set_voltage_target → input.mode=VOLTAGE → controller VOLTAGE 分支(clamp+矢量限幅) → forced θ=0 的 sin/cos 反 Park → SVPWM(按假设 bus) → motor_pwm_set_raw 写 CCR`。
- **列出的互斥假设**：①低边采样窗口太窄、TIM2/3 未锁相采不到；②死区/管压降吃掉小电压；③采样增益不对；④母线写死导致标度失真；⑤当次供电/接触/使能未建立；⑥栅驱 10V 轨未真正建立、MOS 不开关。
- **母线标度分析（实算）**：板上无 VBUS 采样、固件把 bus 写死，SVPWM 占空比按假设母线算；真实母线偏离时 **R_est = R真 ×（假设bus / 真实bus）**；VEND"采样失效也不过 0.15A"的兜底只在真实母线 ≤6.68V 成立；软件矢量限幅 0.5V 命令在 10V 时实际对应 362mA。

### 阶段 3　读 V3Pro_4.0 最新原理图：用硬件事实裁掉一批假设

高 DPI 裁剪放大原理图，得到决定性事实：

- **10V 硬件安全**：功率管 WSD4070DN 为 40V 级；输入反接保护齐纳 ZD1=BZT52C12S（12V 临界，对应"12V 严禁"）；TPS54302 buck(4.5~28V)→5V、XC6210 LDO→3.3V；`POWER_ADC=R73 100K/R74 10K=1/11` 分压（10V→0.91V，ADC 安全；硬件其实预留母线采样，固件未启用）。
- **采样拓扑是 in-line 相线串联 shunt（不是低边到地）**：R15/R16=0.01Ω 串在半桥相节点 `M0_OUTx_P` 与电机端子 `M0_OUTx_N` 之间，下管源极直接接 PGND，第三相无 shunt。→ 任意时刻都流过连续相电流，**直接排除假设①"低边采样窗口太窄"**。
- **INA240A2**：IN+=电机侧(N)、IN-=半桥侧(P)、REF1=REF2=接 3V3、固定增益 50、OUT→PB0/PB1；零电流本应 OUT≈3.3V/4095code，但实测零偏 U≈839(0.67V)/V≈1487(1.20V)，远低于 4095 且两路差 ~600code（独立疑点，疑功率未使能时相节点悬浮，待量静态电压）。
- **栅驱链**：FD6287T 的 VCC 来自 BL9342 boost 的 10V 轨、其 EN=MOTOR_EN。`sp:drv ok` 只代表软件拉高 EN，**不代表 10V 栅驱轨真建立**——若没建立则 6 个 MOS 全不开关，du 恒为噪声，列为头号物理测量点。

### 阶段 4　拍板：升 10V 标度对齐 + 手动对齐保持(HOLD)

- **决策**：不在纸面继续争论，直接做一个**一分钟、可安全回退的判决性实验**。用户拍板按其思路先升 10V、手转感受阻尼。
- **改动（0E/0W）**：①`TEST_BUS_VOLTAGE_V 6.0→10.0`，与真实母线**标度对齐**（命令电压=真实电压，VEND=0.31V→135mA、占空比偏移仅 3.1%，各限幅物理意义不变）；②新增编译期诊断开关 `CALIB_S1A_MANUAL_HOLD=1` 与子状态 `S1A_HOLD_ALIGN`：发 `p` 后锁 θ=0 **持续**注入 `HOLD_VOLTAGE=0.15V`，不跑爬坡/不判据/豁免总看门狗，每 500ms 打 `[HOLD] vd/Id/rawU/rawV`，按 `x`(request_stop→safe_disable)才停。FOC 算法内核零改动。

### 阶段 5　10V HOLD 上板：链路打通，同时实锤相序问题

- **电流离开噪声带**：S0 零偏 U=839/V=1487；HOLD 时 rawU≈913（Δ+74code≈**119mA**）、rawV≈1657（Δ+170code≈**274mA**），远超 ±12 噪声带；用户确认手转有阻尼、电流随转动变化——**电磁对齐真实建立**。
- **一次性证实**：功率级/栅驱/MOS/in-line 采样/ADC 整条链路正常，排除 MOS 损坏、软件旁路、低边窗口；6V 零响应不是算法死结。
- **同时实锤新问题（相序/sign 不自洽）**：θ=0 纯 d 轴物理期望 `(Ia,Ib)=(Id,−Id/2)`，即 ΔU:ΔV=**1:−0.5（反号、U 幅=2V）**；实测 +74:+170=**同号、V≈2.3×U**，与期望完全不符。固件 `[HOLD] Id≈0.11A` 用默认 sign(+1,+1) 与未校正通道合成，**相序定前数值不可信**；命令 0.15V 本应 65mA 而单通道 119mA（约 1.8 倍）也是相序/标度耦合。
- **决定**：下一步把单点 HOLD 扩成**静态三角度(0°/120°/240°)相序探针**，一次解出采样符号、通道↔相对应、三相旋转线序；编码器方向/极对数留批次 B 的 S6 慢扫。

## 4. 最终结论（已证实 / 推断分开）

### 已证实（有本次实测或原理图/实算支撑）

1. 降载后不存在算力瓶颈：环频稳定 10kHz、主循环与样本正常。
2. 功率+采样整条链路在 10V 下正常：电流出噪声带、有电磁阻尼，排除 MOS/栅驱硬损坏与"低边采样窗口"假设。
3. 采样是 in-line 串联 shunt（非低边），任意时刻连续可采；INA240A2 固定 50、0.5V/A 标准增益成立。
4. 10V 在板上硬件安全（40V 管、12V 齐纳门槛、电源轨齐全）。
5. 当前默认 sign(+1,+1)+恒等通道映射**错误**：θ=0 两相电流同号、幅度倒置，相序/采样符号确未标定。
6. `phase_map` 是写死(a→0,b→1,c→2)且全工程无消费点的**死字段**，软件当前无法靠它换相；S6（编码器方向/极对数辨识）只有工具函数、未实现。

### 推断（待后续实验裁决，不应当成结论）

1. 6V 爬坡 du 零响应的真正原因：更可能是**当次供电/接线/使能未真正建立**，或 **6V 时 BL9342 从 6V 升到 10V 供栅驱裕量偏软**；二者需"相序定后回 6V 用同法 HOLD 复测"区分。
2. INA240 REF=3V3 但零偏 U~839/V~1487（非 4095、两路差 600code）的偏置机理未解释，需万用表量 PB0/PB1 静态直流电压。
3. HOLD 静态电流波动偏大（Id 0.058~0.193）来源（PWM 纹波/对齐微振/齿槽）待三角度探针时一并观察。

## 5. 沉淀下来的可复用方法

1. **母线标度对齐原则**：无 VBUS 采样时，固件假设母线必须与真实母线一致，否则命令电压与拟合电流全部同比失真；正式标定前要么启用板载 POWER_ADC(1/11)实测母线，要么保证假设值=真实值。
2. **HOLD（手动对齐保持）作为功率链路自检手段**：锁角持续注入小电压、手转感受阻尼 + 看 raw 是否稳定偏移，是判断"功率到底有没有到相节点"最快的二分测试，比扫 20 档更直观。
3. **先开环 raw 定 sign，再建电流环**：任何闭环反馈的极性/通道必须先在不依赖该闭环的开环层确定，杜绝循环论证。
4. **静态三角度定相序**：单点 θ=0 有歧义，0°/120°/240° 三角度签名可唯一解出采样符号、通道映射、三相线序；编码器方向/极对数再用匀速慢扫(θe vs θm 拟合)定。
5. **判决性实验优先于枚举假设**：当一个实验能同时裁决多个互斥假设且成本/风险极低时，先做实验。

## 6. 经验教训

1. **讨论十次，不如动手一次——优先设计"判决性实验"。** 当一个实验成本极低（一分钟、可安全回退）、且能一次性裁决多个互斥假设时，不要在纸面假设里空转，直接做实验用事实二分。本次 10V HOLD 一次上电，同时排除了"算力不足、软件链路被旁路、低边采样窗口太窄、MOS/栅驱损坏"等争论多轮的方向。**大胆动手的前提是先把安全兜底做足**：CC 限流 0.15A、低压、空载、随时按 `x`——有兜底才敢大胆。
2. **written ≠ verified**：代码写了、链路"看起来对"、`sp:drv ok` 都不等于物理上真的通；只有实测电流/阻尼才算数。
3. **单点有歧义**：θ=0 一个注入点无法唯一确定相序/符号，必须多角度或旋转验证。
4. **用探针 / 原理图 / 实算代替猜，但实测定论优先级最高**：插桩定位、读原理图裁假设、calculator 实算门限；当它们和一次安全实验冲突时，以实验为准。
5. **反对降门限凑通过**：6V du 零响应时判据诚实地报 ku/kv/r2=0、NOGO，而不是放宽 R²/门限让它"假通过"——问题被保留下来才最终在 10V 被正确解释。
6. **母线/供电是第一检查项**：控制异常先确认"电从哪来、假设母线对不对、使能/栅驱轨建没建立、接线紧不紧"，再怀疑算法。
7. **强信号压噪优先，研发不是产品、别唯唯诺诺**：发现信号被噪声淹没（0.15V 净 18code < 噪声带），不要在弱信号里死磕滤波/平均，直接在"保证不坏"的前提下把激励推到硬件极限（拉到不触发 CC 的 0.30V，独大立刻到 47.5code，方向一次解出）。信号幅度先于信号处理，强信号本身就是最好的抗噪。红线靠硬件兜底：母线≤10V、CC=0.15A、空载、随时 `x`；这些是实验台激进参数，产品化必须收回。
8. **警惕"精度陷阱"：定性求对、定量求准，大概率对就先转起来**：低端硬件+粗糙接线物理上不具备高精度，S1a 这类步骤本质是方向问题（符号/通道是离散量），主方向落角/符号正确就适可而止，不为 −0.361 vs −0.5 的偏差卡死；精确量（死区 Voff、精确 R/L、对称度）交给后续 S2/S3 多档拟合。在硬件到不了的精度上用软件硬追，等于追噪声，最耗人也最容易栽坑。
