## 1. 现象（[A]，逐字回 txt）

S7 目标：`id=0.10A、iq=0.18A`，低速捕获约 2.46s（49 行 S7DBG）。方案 A 后两轮实测：

| 量 | 方案A后 CW（dir−1） | 方案A后 CCW（dir+1） | 目标 |
| --- | --- | --- | --- |
| id 范围 / 均值 | 0.23~0.39 / ≈0.31 | 0.22~0.35 / ≈0.28 | 0.10 |
| iq 范围 | −0.119 ~ +0.066（≈0，偏负） | −0.030 ~ +0.086（≈0） | **0.18** |
| vd 范围 | −0.29 ~ +0.17 | −0.24 ~ +0.16 | — |
| vq 范围 | 1.20 ~ 1.45 | 1.10 ~ 1.31 | — |
| dyn_R / base_R | 9.0172 / 3.8159 = **2.36×** | 8.3485 / 3.7154 = **2.25×** | 应落 base×[0.5,1.5] |
| dyn_R 窗 | [1.9080, 5.7239]，被拒 | [1.8577, 5.5730]，被拒 | — |
| 结局 | 电机转动、不发散、无复位；dyn_R 软拒绝进 CANDIDATE_REVIEW | 同左 | 应通过 |

**形态特征：稳定、不发散，但两轴电流"落错地方"**——id 偏大到约 0.3、iq 几乎为 0（本该 iq≈0.18 出力），vq 稳定在 1.3V 左右。两轮方向相反、终态功能等价（经验2），偏转形态却一致复现，说明它与手转方向无关、是一个固定的坐标系问题。

**足额性旁证**：`vq/R ≈ 1.3/3.8 ≈ 0.34A`，与实测电流矢量幅值 ≈0.31A 同量级——电压确实推出了足额电流，只是这份电流**几乎全落在（测量意义上的）d 轴**，没有落到出力的 q 轴。因此 dyn_R 超窗是 **iq≈0 的派生结果**（辨识电阻依赖 q 轴电压/电流关系），不是电阻本身坏了，也不是能量失控。

## 3. 已排除项 与 候选（候选全部 [C]，未证实）

**已排除（有依据）：**
- 整体相序/方向接反：两轮终态均满足功能不变量 `m·dir=e=−1`、电机按预期方向转动（经验2）；
- 硬失控/能量问题：电压矢量仅 1.3V、电流 ≈0.3A 在上限 1A 内、不发散不复位；
- L2 路径依赖：方案 A 后无 flipped、两轮终态结构自洽；
- 电阻本体异常：足额性旁证显示电流大小对，问题在"方向"不在"大小"，dyn_R 超标是派生现象。

**候选（[C]，彼此竞争，等待实验杀掉）：**
- **C1：SVPWM 输出电压角与 Park 反变换约定差 90°**（作用坐标系的 q 轴定义与测量坐标系差一个固定电角）；
- **C2：S5 锁定的"d 轴"实际是物理 q 轴**（零位对齐把出力轴当成了直轴，于是指令 iq 的电流在测量里表现为 id）；
- **C3：电流通道在连续旋转角下存在固定错位**（L3 修了通道置换，但可能还残留一个与角度相关的符号/象限约定不一致）。

> C1/C2/C3 都能解释"id 偏大、iq≈0、vq 稳定"，**仅凭日志无法区分**——这正是经验7 说的"同一份材料支持多个互斥解释时必须去物理世界"，不在文档里投票选一个。

## 4. 判决实验草案（开环两轴法，待执行）

思路：脱离闭环，直接在**开环电压模式**下分别只给 d 轴、只给 q 轴加小电压，用转子的**裸物理响应**区分"d 轴到底是不是吸定轴"（对应经验7 的最小物理实验四准则：冻结、唯一自由度、结果是可观察物理事实、候选预测相反）。

前置安全（硬约束）：V3P 供电 ≤10V（**严禁 12V**）、空载、电流上限 1A、手随时可按 `x` 停、电机输出仅在步骤内使能。

1. **切到开环 VOLTAGE 模式、电流环旁路、转子自由**（不锁闭环，避免控制器掩盖轴定义）；
2. **仅加小 Vd（Vq=0）**：
   - 若转子被**吸到某个固定角度后静止保持**（有保持力矩、不连续转）→ 该方向确为物理 d 轴（磁阻/磁场轴）；
   - 若转子**连续旋转** → 现在认定的 d 轴其实是 q 轴，坐实 C2；
3. **仅加小 Vq（Vd=0）**：
   - 物理 q 轴加压应产生**连续旋转**；若反而吸定静止 → d/q 定义互换（C2）或 SVPWM 与 Park 差 90°（C1）；
   - 记录转向与编码器角度变化方向，核对是否与 `dir、m·dir=e` 一致，顺带判 C3；
4. 两轴响应组合即可把 C1/C2/C3 区分开（吸定轴与旋转轴是否互换、转向是否与编码器约定一致）；
5. 全程小电压阶梯（从 0.3V 起），电流逼近 0.5A 即停，禁止一步给满。

**升级为 [A] 的条件**：观察到可重复的"Vd 吸定 / Vq 旋转"或其互换现象，并记录对应编码器角度与电流方向；在此之前 §3 候选保持 [C]，不得据其改代码。
