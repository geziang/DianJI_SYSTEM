## 为什么归档

本目录存放**已被更新认知整体取代、或已被拆分的过程文档**。这些文件的**事实性记录**（改了什么代码、当时打印了什么、实验跑了什么）仍然有效，但它们的**结论性叙事**已被根目录的 8 篇平级文档（经验1~7 + L4）修正、取代或拆分。为避免主检索路径上出现多个互相矛盾的版本，移入本目录；**原文一字未删**（含各自的勘误块、2026-09-13 最终结论块），历史可溯。

**权威结论在哪**：不在本目录，而在上级目录的 8 篇平级文档，索引见上级 `_说明.md`：

- 经验1 欠定方程与自动修正器追逐 / DIR 前置定序
- 经验2 功能不变量判等价（m·dir=e）
- 经验3 假门判据：物理简并与 n=2 统计退化
- 经验4 观测坐标系=作用坐标系 / 对称适配
- 经验5 输入选择旁路可疑路径 / 对照与归因分账
- 经验6 度量与证据纪律
- 经验7 神之一手：跳出绕圈、最小物理实验锁病灶
- 经验8 变量逻辑态定位：打印→门禁→变量→硬件资源一条直线（**L4 已结案**）

每份归档文件文头都有【最终结论 2026-09-13】块，精确点名本篇哪几句被覆盖。

## 阅读指引

- **新读者**：不要从这里入门。先读上级 `_说明.md` 的索引，按 8 篇平级文档阅读；想要完整来龙去脉再读本目录的母本《从绕圈到转起来》。

- 归档文件内部的相对链接（如 `../波形与数据/`）自归档起深了一层，按历史原文保留，未逐一改写；同目录文件互相引用仍然有效。
