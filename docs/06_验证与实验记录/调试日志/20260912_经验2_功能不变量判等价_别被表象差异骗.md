## 0. 本篇只讲两条

1. **判一个标定组合"对不对"，不要逐字段比，要算功能不变量。** 本案判据是 `m(perm)·dir = e`：镜像 + 方向反号，乘积不变、功能完全等价，表象差异由 offset 吸收。
2. **一旦先入为主写下"某组合是错的"，后续观察全会被这副眼镜染色（确认偏误）。** 本案两天里每个实测终态其实都功能自洽，"哪个组合才对"是个伪问题。

## 1. 这个坑怎么撞上的（最小背景，自包含）

相序有 6 个排列 perm0…perm5（`(a,b,c)` 分别输出到哪三个硬件通道）；编码器方向 `dir∈{+1,−1}`；编码器安装方向 `e`（物理顺时针时 raw 增减）是硬件属性，本机 `e=−1`；`m(p)` 是排列 p 的物理手性（奇/偶排列，见下）。

绕圈的两天里我们反复争论"perm1 还是 perm5 才对""CCW 轮那个组合是不是被 S5 洗白了"。直到引入功能不变量把**每一个实测终态**都验算一遍，才发现争论对象本身不成立。

## 2. 经验讲透

### 2.1 什么是功能不变量

先分清两层：
- **内部表示（representation）**：`(perm, dir, offset)` 这组字段，是"同一物理事实"的不同编码；
- **物理功能（function）**：给一个电流指令，电机产生确定方向的转矩——这才是我们真正要保证的东西。

**功能不变量，就是系统在一组"表示变换"下保持不变的那个量。** 表示可以随便换，只要不变量不变，物理功能就逐字相同。满足同一不变量的所有表示构成一个**等价类**，类内任意两个表示"功能等价"。

本案的表示变换有三种，对应三个自由度：
- 镜像（B/C 通道互换，排列下标 `^1`，镜像对是 (0,1)(2,3)(4,5)）；
- 方向反号 `dir→−dir`；
- 角度零点平移（offset 相差 2π 内的互补值）。

在这组变换下不变的量是：

```
m(perm) · dir = e        // 组合功能正确的充要判据
```

推导一句话：镜像翻转手性一次（m 变号），方向反号再翻一次（dir 变号），两者乘积 `m·dir` 不变。于是得到**镜像等价对**：

```
(perm, dir) ≡ (perm^1, −dir)       // 功能完全等价
```

再进一步，排列按奇偶分两类：奇排列 {perm1,perm2,perm5}、偶排列 {perm0,perm3,perm4}，同类内只差一个循环移位，由 S5 测出的 offset 吸收。之前反复纠结的"mapA 组"（a 相落到哪个通道），本质只是循环移位的另一种数法，**在功能层面纯属表象，不是分界线**。

> 类比：线性代数里同一个线性映射在不同基下的矩阵不同，但特征值/行列式不变——判两个矩阵"是不是同一个变换"要比相似不变量，不是逐元素比。工程上的 canonicalize（字符串 NFC、URL 归一化、`std::map` 按 key 语义而非地址比较）也是同一件事：**先归一化到规范形再比较**。物理里叫规范不变性：坐标随便选，物理量不变。

### 2.2 程序里怎么把"功能不变量"抽象出来（五步）

1. **识别表示自由度**：列出哪些字段只是同一事实的不同编码（本案：相序排列、方向符号、角度零点）。
2. **定义不变量函数或规范形**：写一个纯函数 `invariant(cfg)`（本案返回 `m(perm)·dir`），或 `canonicalize(cfg)` 把任意等价表示归一到一个代表元。
3. **判等价只在不变量/规范形上做**：`equivalent(a,b) ⇔ invariant(a)==invariant(b)`，**禁止逐字段比**——逐字段比会把等价类里的不同表示误判为"不一致/错误"。
4. **断言建在物理结果上**：单元测试和上板自检断言"两轮转向相同、转矩方向相同、offset 互补到 2π"，而不是断言"两轮 perm 相等"。
5. **边界处一次归一化 + 修正守恒**：进核心算法前先消掉表示自由度（经验1 的 DIR 前置本质就是先归一化 e）；任何"自动联动修正"执行前后必须保持不变量不变，否则就是在等价类之间乱跳（旧的 `best^=1` 联动正是犯了这条）。

### 2.3 好处

- **不被表象差异骗**：perm4/+1 和 perm5/−1 字段全不同，一算不变量就知道是同一回事；
- **判对错有唯一标准**：不用争"哪个排列对"，只看 `m·dir` 是否等于硬件真值 e；
- **重构有安全网**：改标定/重排步骤后跑不变量断言，破坏即 bug；
- **等价类内可自由选最方便的表示**（比如永远把 dir 归一到 +1 的规范形再存储）。

### 2.4 反面：确认偏误怎么让人把等价当错误

一旦提前写下"perm1 是错误组合"，后面所有观察都会被这副眼镜过滤：同一个 `(perm4,+1)`，在"错误组合被 S5 洗白"段落里被当成故障证据，在"两轮物理等价"验证表里又被当成正确证据——**同一份文档里自相矛盾而不自知**。解药就是 §2.2：对错不允许靠叙事判断，只能算不变量。

## 4. 一句话带走 + 迁移用法

**一句话：判对错算功能不变量，不要逐字段比内部表示；等价类内的差异不是错误。**

迁移到任何"多种内部表示对应同一功能"的系统（坐标变换、通道映射、字节序、单位制、左右手系……）：
1. 先写出"什么变、什么不变"，把不变量显式做成一个纯函数；
2. 所有一致性检查、测试断言、日志判读都走不变量；
3. 看到两份"看起来不一样"的结果，先算不变量再决定是不是冲突，别让第一印象定性；
4. 该不变量也应固化成固件运行期自检（本案列为 backlog 方案 C：perm×dir 交叉自检）。
