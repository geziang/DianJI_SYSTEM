## 4. 关键设计决策（本轮拍板）

1. **c=clear 方案 A（用户确认）**：FAULT 态 c= 清故障；非 FAULT 态 c= 清参数存储。分流在 app_baseline 命令层判 `control_loop_get_state()`，clear_storage 自带静默态白名单双重防护。
2. **"独立上电"语义**：R 学习的跨启动历史以"独立上电"为采样单位——`control_loop_s2_adopted` 为 per-boot latch，同一上电内多次 r=restart 只有首个可信 S2 进历史；`control_loop_init` 不清学习状态、`control_loop_request_identification_start`（r）也不清，只有掉电或 c=clear 才清。
3. **apply 顺序**：先 RAM 激活（无论 Flash 结果，本启动生效）→ verified 过门才 commit Flash → 成功打来源页/rev 并同步 loaded 镜像（后续 r=restart 的测试起点与 revision 链），失败打状态码文本并降级 RAM-only。
4. **revision 链**：候选 `parameter_revision = loaded.parameter_revision + 1`（上电有加载包）否则 1；learned_r_revision 独立递增（附录 A）。
5. **注入时序安全**：`control_loop_init` 在 `app_baseline_init`（同步初始化）内执行，`safety_manager_poll` 的注入在主循环首次轮询执行——注入晚于 init，`loaded_valid` 不会被覆盖。
6. **S7 判决出口内聚**：judge 函数内决定去留——正常路径→CANDIDATE_REVIEW（打印 [RESULT]/[RLEARN]/[NEXT]）；行程/力矩矛盾（`mech_delta × encoder_direction ≥ 0.30 rad`）→不产候选、回 TEST_READY、提示重跑 PHASE_SEQ。
7. **不重写已验证 FOC 内核**：本轮零改动 `foc_controller/foc_pi/foc_svpwm/foc_transform` 等算法内核；电流环 10kHz 不动。
