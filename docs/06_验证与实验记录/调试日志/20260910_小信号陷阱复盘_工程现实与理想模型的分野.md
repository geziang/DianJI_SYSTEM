## 0. 结论速览（TL;DR）

1. **小信号陷阱的本质不是"信号给小了"，而是用理想模型的确定性去对待工程系统的非理想性。** 纸面公式 `I=Vd/(1.5R)` 预测 0.3V 注入应有 87mA，实测却是 0——因为命令电压到绕组真实电压之间隔着死区、管压降、接触电阻和写死的母线标度，测量端还有零偏噪声。我们默认这些为零，对不上时不去物理层改前提，反而在算法层堆补丁。
2. **强信号压噪不是新信仰，而是"把工作点拉回工程窗口"的手段之一。** 信号尺度分三段：小信号区被固定损耗+加性噪声主导；中间是有效激励远高于噪声底、又远离磁饱和/发热的工程窗口；再往上大信号区会被磁饱和、I²R 积热、吸动转子、满幅削顶主导。**大信号同样会测错，不是越大越好。**
3. **信噪比在物理层建立，算法层只能守住、不能创造。** 当有效信号与噪声同量级，数据里本就没有可靠信息，滤波/统计/卡尔曼只能统计意义上微调，无法凭空恢复。提高激励是在源头增加信息量，是降维解决；在测量端打补丁是为被忽略的工程事实还技术债。
4. 本项目的工程窗口经物理核算落在 **0.2~0.6A（对应静止注入约 0.7~2.1V）**：是单拍噪声 σ≈13mA 的 15~46 倍，又低于 1A 额定与磁饱和区。钳位 5.5V/1A 是安全天花板，不是工作点。
5. 判据/阈值是工程裕量的显式表达，不是可随意松紧的旋钮。把稳态带放到 100% 等于判据作废；正确顺序是**先把工作点挪进窗口，再让判据回归物理严格度**，本次重构正是反向还债：判据全部从"放水值"收回到正常值。
6. **该方法论已经双轮上板实测闭环（§10）**：两轮独立上电，P3 幅值 336.6/333.0code（±1.1%）、S2 测出 R=3.45/3.56Ω（r2>0.999、拟合截距≈0）、S4 静差 0.10%/0.87%、相序两轮都选 perm1、手动判向 +1、S5 零位 ok；唯独 S3 电感两轮 0.79/1.31mH 跳变、照样回退标称——因为那是时间分辨率问题而非信噪比，恰好划出"强信号压噪"的适用边界。

> 一句话：**工程不是让理想公式成立，而是在"固定损耗、噪声、饱和、发热、安全"多重约束的交叠窗口里选工作点；脱离物理链路、默认元件理想、追求单一指标极致（无论极致地小还是极致地大），都是忽略工程。**

## 1. 引子：一个理想公式的失败

静止的 PMSM 不产生反电动势，在理想模型里就是一个纯电阻，d 轴注入电压与电流满足：

```
I_d = V_d / (1.5 · R) = V_d / 3.45        # R=2.3Ω，SVPWM 线/相等效系数 1.5
```

相序标定（PHASE_SEQ）第一次上板用 0.30V 注入，纸面预测：

```
0.30V / 3.45 = 87mA  →  远大于 ID_MIN=20mA，理应 6 个换相里正确相 id 明显为正
```

实测（小信号版日志）：

```
[PSEQ] perm0..perm5 全部 id≈0 iq≈0
[RESULT] phase-seq best=0 pass=0 id=0.0000 iq=0.0000 score=0.0000
[FAULT] phase-seq no permutation consistent (check wiring)
```

我们当时的第一反应是"电机相线断开/开路"，去查接线。**这个判断错了。** 后来只把注入从 0.30V 提到 1.5V（其余不动），同一个电机同一根线：

```
[RESULT] phase-seq best=1 pass=2 id=0.3423 iq=-0.0181 score=0.3242   # 一次通过
```

1.5V 出 342mA，直接证伪"断线"——线从头到尾都是好的。那 0.3V 时电流去哪了？答案是：**理想公式里那一串被默认等于 0 的东西，在 0.3V 这个尺度上吃掉了绝大部分命令电压。** 这正是本文要拆开的东西。

## 2. 工程视角：从"命令量"到"测量量"的完整非理想链路

理想模型里 `V_d` 一加，绕组两端就是 `V_d`，shunt 上就能无噪无偏地读到 `I_d`。工程上这中间每一环节都有非理想项，下面按本系统实测/原理图逐项列出误差预算（error budget）。

| 环节 | 理想模型假设 | 本系统工程现实 | 性质 |
| --- | --- | --- | --- |
| 母线标度 | 命令电压=真实电压 | 板上有 1/11 分压但**未接 MCU**，固件把母线写死 10V；SVPWM 按假设母线算占空比，真实母线偏差按比例换算成电压误差 | 系统性、随尺度等比 |
| 逆变器 | 零死区、零管压降 | FD6287T 死区 + WSD4070DN 双管导通压降 + 相线接插件接触电阻，折算一个**固定电压当量**（本系统粗估 0.15~0.35V，见 §6） | **固定量，小信号占比极大** |
| 绕组 | R、L 为常数 | R 随温度升高；L 随电流增大进入磁饱和而下降 | 非线性，**大信号才显现** |
| shunt | 无误差 | 0.01Ω ±1% in-line 串联，两相、第三相重构 | 小固定误差 |
| 运放 INA240A2 | 理想放大 G=50 | 有失调电压、噪声密度、带宽限制；零电流输出本应≈3.3V(4095code)，实测零偏落点 U≈805/V≈1450，**既不在理想中点、U/V 两路还不一致** | 固定偏置+噪声 |
| ADC | 无量化、无噪声、瞬时 | 12bit，1code≈1.612mA；零偏峰峰 p2p≈27~41code（44~66mA）、MAD≈4code、单拍 σ≈10~13mA | 加性噪声，**绝对值基本固定** |
| 算力 | 计算不占时间 | M3 无 FPU，浮点全软库（fmul≈25cyc、fdiv≈110cyc、sinf≈700cyc），10kHz 周期预算仅 ~7200cyc | 与信号无关的真实约束 |
| 机械 | 转子随给定即时跟随 | 有齿槽转矩、静摩擦；0.04A 的 q 轴力矩克服不了，开环慢扫 mech_delta=-0.0123rad≈-0.7°，根本没转 | **小力矩时主导** |

**关键观察**：这些非理想项不是一个量级的东西，它们在不同信号尺度上的**相对权重会反转**。理解这一点，是理解整个陷阱的钥匙（§6 展开）。

## 3. 理想模拟 vs 工程现实：一张对照表

| 维度 | 理想模型 / 仿真 | 本系统工程现实 | 忽略它的后果 |
| --- | --- | --- | --- |
| 电压传递 | 命令 Vd = 绕组电压 | 中间扣固定压降、按假设母线折算 | 小电压"加了等于没加" |
| 测量 | 无偏、无噪、无延迟 | 零偏漂移+p2p 噪声+I²C/ADC 延迟 | 信号与噪声同量级时不可判 |
| 元件参数 | R/L 常数、线性 | R 随温、L 随电流饱和 | 大电流下 R/L 辨识反而是错的 |
| 电源 | 零阻抗恒压、随取随有 | 有内阻、CC/CV 切换瞬态、母线未采样 | 阶跃瞬间电压塌陷 |
| 电流建立 | 按一阶理论即时收敛 | 死区畸变、齿槽静摩擦、采样窗口错位 | 小力矩转不动、小电流建立慢 |
| 判据 | 误差=0 才算对 | 必须按噪声底与物理裕量设"带" | 用 0 当目标则永远不通过 |
| 失败归因 | 参数错就是参数错 | 可能是链路任一物理环节 | 错把"激励不足"当"算法不好/硬件坏" |
| 计算 | 实数无限精度、零耗时 | 定点/软浮点、有限周期预算 | ISR 超时会真的卡死（与信号无关） |

理想模型不是没用——它是一阶近似、是设计起点；但**把一阶近似当成被测对象本身，在它和实测对不上时去改测量和算法而不是修正模型前提，就是"忽略工程"**。

## 4. 重新定义"小信号陷阱"

### 4.1 定义

> **小信号陷阱**：当激励的有效分量与链路固定损耗、测量噪声处于同一量级时，系统表现为"测不准、不收敛、时好时坏"；此时不去物理层提高有效激励，反而默认链路理想、把问题归到数据处理与判据上，持续叠加滤波、统计、放宽阈值等补偿，结果复杂度上升、判据失效、信心下降，更不敢加大激励，形成自我强化的死循环。

### 4.2 自我强化闭环

```
怕烧板/怕烧电机（把硬件当玻璃）
        │
        ▼
选用远低于额定的最小激励（0.3V / 0.04~0.06A）
        │
        ▼
有效激励被固定压降+噪声淹没（命令量≠物理量）
        │
        ▼
现象：测不到 / 不收敛 / OK-NOISY 抖动 / 结果不可复现
        │
        ▼
错误归因：算法不够强、数据不够干净、阈值太严、甚至"硬件坏了"
        │
        ▼
在测量/算法层打补丁：加滤波、加滑窗、MAD 去极值、采样翻倍、
判据一放再放（稳态带放到 100%）、调研卡尔曼/LMS
        │
        ▼
表面"通过"但判据已失去把关能力，且没验证大信号，更不敢动
        │
        └──────────────► 回到"继续用小信号"，循环加强
```

打破闭环的动作其实只有一个方向：**回到物理层，先确认有效激励相对噪声底和固定损耗是否足够大。**

### 4.3 为什么"放宽阈值"是借债不是解决

判据（稳态带、静差上限、spread 上限）本质是"当前信号尺度下，允许物理量偏离理想值多远"的工程裕量。小信号时噪声占目标的比例天然很大，要让流程"过"，只能把带放宽到比噪声还宽——本项目 S4 稳态带一度放到目标的 100%，意味着"电流在 0 到两倍目标之间晃都算稳定"，**判据从此对真故障也视而不见**。这不是修复，是用"不判"换"通过"，债迟早要还。

## 5. 我们的真实足迹：一份"还债清单"

下面按时间列出小信号期累积的补偿，以及它**本想对冲、其实应在物理层消除**的非理想项。材料来自本次连续多轮调试。

### 5.1 零偏/采样层补丁

| 补丁 | 小信号期做法 | 它实际在补偿什么 | 大信号后的归宿 |
| --- | --- | --- | --- |
| 零偏采样翻倍 | 64→128 点、失败重采≤4 轮、取最干净一轮 | 零偏 p2p 在 32code 门限两侧 OK/NOISY 抖动 | 保留（零偏是上电一次性测量，与运行信号大小无关，合理） |
| MAD 离群点过滤 | 中位数+MAD 识别孤立尖峰 | 偶发采样尖峰 | 保留（标准稳健统计，delta_zero 实测=0，无害） |
| 噪声门限 | 32→64code | 零偏噪声带超出门限导致 S0 拦截 | 与信号解耦，维持 |
| 拍均值 FR1~FR6 | ISR 只加法、主循环 consume、≤16 环形滑窗 | 单拍 σ≈13mA 直接喂判据导致逐拍掷硬币 | 机制保留，窗宽在大信号后从 4 收回标准 8 |

### 5.2 判据层补丁（S1a / S4）

| 参数 | 小信号期被放到 | 当时现象 | 大信号后收回到 |
| --- | --- | --- | --- |
| P3 U/V 幅值一致性 AMP_MATCH | 0.40 | 0.5V 时 U/V 幅值被噪声扰动，比例飘 | **0.20**（2V 实测比值稳定 0.89） |
| P3 ratio 容差 | 0.15 | soft=0x04 软警 ratio=-0.482 | **0.10**，并**删除 soft 软警位**（大信号恒 0x00 clean） |
| S4 稳态带比例 | 一路放到 **1.00** | 噪声带 ±22mA > 判稳带 ±7.2mA，settled 永不触发 | **0.15** |
| S4 稳态静差 | 放到 **0.50** | 小电流区死区占比大、静差大 | **0.15**（实测 4.28%） |
| S4 建立时限 | 放到 20·Tc | 小信号建立慢 69ms | **10·Tc**（实测 48ms≈5Tc） |
| S4 观测窗 | 拉到 25·Tc=250ms | 16 拍滑窗在窗内填不满 | 15·Tc=150ms，滑窗 4→**8** |
| S4 spread / exit | 0.60 / 0.50 / 连穿 4 拍 | 噪声频繁打出稳态带 | **0.30 / 0.20 / 2 拍** |

> 注意这张表的方向：**同一套判据，小信号时被迫"放开到作废"，大信号后才能"收紧到真把关"。** 判据严格度是被信号尺度倒逼的，不是可以独立调出来的。

### 5.3 调研过但最终没上的"重武器"

- 卡尔曼 / LMS 自适应滤波：对无 FPU 的 M3 太重，且自检阶段是恒角稳态，根本用不上——**典型的"想用更复杂算法救信噪比"**。
- 温度查表补偿：板上无 NTC/温度通道，不具备前提。
- 零矢量窗口偷采：需要特定开关矢量采样点，TIM3 固定触发不具备。
- PI 补偿静态零偏：PI 在电流环内、零偏门禁在环外，**环内控制器补偿不了环外门禁的噪声**，当时就被正确否决。

### 5.4 两次错误归因（诚实记录）

1. **"相序全 0 = 电机断线/开路"——错。** 这是用理想模型"有线就该有电流"推断的，忽略了 0.3V 有效激励不足；1.5V 一出电流即证伪。
2. **"S1b 卡死 = 数据/零漂问题"——只对了一半。** 早期确实在数据层找原因；但最后定位到 S1b 卡死的直接原因是**无 FPU 的 M3 上 CURRENT 模式软浮点 FOC 每拍算不完**：一拍约 4090cyc≈57µs，慢路径 90~110µs 越过 100µs 控制周期，ISR tail-chain 永不归还，SysTick 被压制、`HAL_GetTick` 冻结、UART 超时永不触发，表现为停在半截打印。这是一个**与信号大小无关的真实工程 bug**，靠 ISR 计算重构（256 点 Q15 三角表、fdiv→乘倒数、启动顺序重排、DMA 优先级、栈 1KB→2KB）解决。

> 第 2 点特别重要：**不能因为发现了小信号陷阱，就把所有早期问题都归为"信号小"。** 算力超预算、保护逻辑、状态机缺陷是独立于信号尺度的真问题，该修必须修（§9 再分层）。

## 6. 信号尺度三段窗口：为什么"大信号"也有边界

### 6.1 噪声是绝对的，信噪比是相对的

硬件噪声由模拟前端决定，其绝对值基本固定（σ≈13mA、零偏 p2p≈44~66mA），不随给定变化。于是：

```
目标 0.06A 时  σ/目标 = 13/60  ≈ 22%   # 噪声占两成多，判据只能放水
目标 0.30A 时  σ/目标 = 13/300 ≈ 4.3%  # 噪声一个零头，判据可以严格
目标 0.60A 时  σ/目标 = 13/600 ≈ 2.2%
```

信号放大 N 倍、噪声不变，SNR 提高 N 倍，所有"噪声病"同步缓解。这是强信号压噪的第一块物理基石。

### 6.2 固定电压损耗只在小尺度占比大（定量反推）

把 P3/相序的"命令电压—实测电流"两点列出来，用 `V有效 = I·3.45`、`V固定 ≈ V命令 − V有效` 反推：

| 命令 Vd | 理论 I=V/3.45 | 实测 I | 有效占比 | 反推固定压降 |
| --- | --- | --- | --- | --- |
| 0.30V | 87mA | ≈0（相序） | ~0 | 命令尚不足以越过固定区 |
| 0.50V | 145mA | 97mA（60.4code） | 0.67 | ≈0.16V |
| 1.50V | 435mA | 342mA（相序） | 0.79 | ≈0.32V |
| 2.00V | 580mA | 477mA（295.7code） | 0.82 | ≈0.36V |

> 反推值不是严格常数（含死区非线性、接触电阻随电流变化、母线写死标度误差），量级在 **0.15~0.35V**，仅作量级参考。但趋势决定性地清楚：**固定损耗是"减法"，命令电压越接近它，有效激励占比越低；0.3V 几乎全被吃掉，2V 时只占零头。** 这就是 0.3V 读到 0、2V 得到 5 倍幅值（60→296code）且 soft 告警消失的物理原因。

**双轮上板的反向印证——大信号区 V-I 拟合截距≈0。** S2 在 0.2/0.4/0.6A 三档做 V-I 最小二乘，两轮拟合截距 Voff=0.0607V / -0.0002V（≈0），即工程窗口内的 V-I 直线基本过原点，固定压降被"除"成了零头；两轮 R=3.4455/3.5551Ω、r2=0.9994/0.9996，复现偏差仅 3.2%。同一套硬件，固定损耗的绝对量并没有消失，变的只是它相对激励的占比：小信号区"吃掉全部"，工程窗口内"可忽略"。

### 6.3 三段尺度窗口（本系统标注）

```
电流
 ↑
 |                                        ╱ 大信号区（不可用）
 |                              饱和拐点 ╱  磁饱和→L/R 失真
 |                                     ╱   I²R 静止积热、转子吸动
 |                                    ╱    INA/ADC 近满幅削顶
 |          ┌───────────────────────┛
 |          │  工程窗口（可用）
 |          │  有效激励 ≫ 噪声底
 |  0.6A ───┘  且远离饱和/热/安全边界      ← S2 最高档
 |  0.3A ── S4/S5 阶跃/对齐
 |  0.2A ── S1b/S2 起步
 |  ~13mA×3 ≈ 40mA：高于此才算"出噪声带"
 |  ╳╳╳╳╳ 小信号区（陷阱）╳╳╳╳╳
 |  固定压降 0.15~0.35V + σ13mA 主导
 └──────────────────────────────────────────────→ 命令电压/电流
```

- **小信号区（陷阱区）**：有效激励与固定损耗、噪声同量级，测不准、判据只能放水、容易误判硬件坏。本项目 0.3V/0.04~0.06A 落在这里。
- **工程窗口（可用区）**：有效激励显著高于不确定度，又在线性、低热、安全侧。本项目核算为 **0.2~0.6A（静止注入约 0.7~2.1V）**。
- **大信号区（另一类不可用）**：电流继续增大，铁芯磁饱和使 L 下降、R 因饱和/温升偏离，**此时辨识出的 R/L 反而是错的**；静止无反电动势，I²R 热量集中在绕组；力矩突变会吸动转子；模拟前端接近输出摆幅/ADC 近满量程。**强信号压噪只对"加性噪声、固定损耗占比"有效，对非线性失真、饱和、温漂、系统误差无效甚至有害。**

> **还要分清"压得住的噪声"和"换了物理维度的问题"——S3 电感是现成反例。** S3 在 0.1→0.5A 的大信号阶跃下，两轮估出 L=0.794/1.307mH（相差 65%）、IQR 离散度 1.64/1.08 均超 0.25，照样不可用、回退标称。根因不是信噪比，而是**时间分辨率**：电气时间常数 τ=L/R≈0.24ms，而 10kHz 每拍 0.1ms，跳过 2 拍后上升沿只剩 2~3 个有效采样点，斜率中位数自然剧烈跳动。这类问题**再加大电流也无效**，只能靠提高采样率/整段指数拟合，或如本项目回退标称 0.86mH（两轮估计恰围绕标称分布）。这给"强信号压噪"划清了边界：它治加性噪声与固定损耗占比，不治时间分辨率、非线性和系统误差——所以它是方法，不是信仰。

### 6.4 为什么 5.5V 是天花板不是工作点

静止纯电阻下 `I=V/3.45`：3.45V 即达 1A 额定，5.5V→1.59A（超额定），10V→2.9A（约 3 倍额定，会烧）。5.5V 的真实身份是**电流环 PI 输出的软件饱和上限**，取值依据是 10V 母线 SVPWM 正弦调制线性上限 `10/√3≈5.77V`，留 0.27V 饱和裕量——它只在动态调节瞬间被短时触及，**绝不是静止注入档**。实际注入档全部按"电流落在工程窗口"反推。

## 7. "强信号"的正确定位：工程窗口怎么算出来

本次强信号重构的每一档都不是拍脑袋拉大，而是按两条边界夹出来的：

**下边界（压得住噪声与固定损耗）**：
- 电流至少为单拍噪声 σ 的 10 倍以上：13mA×10≈0.13A；
- 电压必须越过固定压降 0.15~0.35V 后还有富余。

**上边界（不进饱和/不发热/不超额定）**：
- 不超 1A 额定，留余量取 ≤0.6A；
- 静止短时注入（每档几十到几百 ms），瓦级铜耗可接受，但不持续；
- 远离磁饱和（2804 小电机在额定 1A 内基本线性，取 0.6A 更稳）。

夹出的各档（均在窗口内）：

| 步骤 | 激励 | 等效静止电流 | 相对 σ | 作用 |
| --- | --- | --- | --- | --- |
| S1a P3 | 2.0V | ≈0.48A | ~37× | 符号/通道，5 倍幅值、soft 清零 |
| 相序 | 1.5V | ≈0.34A | ~26× | 6 换相一次选出 |
| S1b 闭环自检 | 0.20A | 0.20A | ~15× | 闭环方向自证 |
| S2 R 三档 | 0.20/0.40/0.60A | 同 | 15~46× | V-I 线性拟合 |
| S3 L 阶跃 | 0.10→0.50A | 同 | — | di/dt 窗口 |
| S4 阶跃 | 0→0.30A | 0.30A | ~23× | 电流环四判据 |
| S5 对齐 | 0.30A | 0.30A | — | 锁转子定零位 |

外部最后一道闸：**台电源 CC 限流设 ≥1.2A**（大于工作电流、小于危险电流），与软件 1A 钳位构成双保险。

## 8. 可迁移的方法论（6 条）

1. **先区分模型量与物理量。** 命令 Vd、目标 Id 是模型量；绕组真实电压、shunt 实测电流是物理量。动手调试前先列出两者之间的完整链路，给每一级标一个误差/损耗量级（error budget）。预测与实测不符，先怀疑链路前提，别先怀疑算法。

2. **信号尺度决定主导误差，方法随尺度切换。** 小尺度被固定损耗+加性噪声主导，大尺度被饱和+热+非线性主导，中间才是窗口。没有一套阈值、一种方法能打天下；先判断工作点在哪一段，再决定该压噪还是该防饱和。

3. **SNR 在物理层建立，算法层只守不创。** 信息在激励/传感器端就决定了。信号低于噪声底时，数据里没有可靠信息，平均/滤波/卡尔曼都无法凭空恢复——它们是"守成"，提高激励才是"创业"。判断顺序永远是：**原始数据在物理层够不够干净 → 再谈算法。**

4. **每个补丁做"溯源三问"。** 它在补偿哪个具体物理非理想项？这个非理想项在当前信号尺度下能不能直接避开（而不是补偿）？如果尺度一变它就不存在，那它就是在为错误前提还技术债，应回到源头消除，而不是永久背着。

5. **判据是工程裕量的显式表达，不是松紧旋钮。** 先把工作点挪进工程窗口，再让判据回到物理严格度；靠放宽判据换来的"通过"是借债，会让你失去对真故障的分辨力。判据值必须能说清"这个带对应多少 mA、为什么噪声越不过它"。

6. **敬畏但不恐惧硬件，判决性实验优先。** datasheet 额定区 + 软件钳位 + 电源 CC 限流是三重合法保护，在窗口内操作是工程自信，不敢用是浪费设计裕量，越界是蛮干。纸面争论十次，不如在可随时 `x` 断电、低压空载、CC 兜底下做一分钟判决性实验（前序 10V HOLD、本次 1.5V 相序都是这样一锤定音的）。

> 元原则：**工程 = 在多个互相矛盾的物理约束之间找到交叠的可行窗口并量化它；理想模型只是进入工程的第一张草图。** 小信号陷阱之所以是"忽略工程"，就在于它把草图当成了成品，然后在测量端拼命补偿草图与现实的差。

## 9. 诚实分层：哪些是"还债"，哪些必须留下

避免从一个极端摆到另一个极端——不是早期做的一切都白做。按"是否依赖小信号前提"分三类：

### 9.1 属于为小信号还债、大信号后简化/删除的
- P3 soft 精度软警位、`[P3Q]` 打印（大信号恒 clean）；
- 被放到作废的 S4 判据（收回正常值）；
- ADC 零偏 128 行逐样本打印、sp:* 成功流水、S4 10ms 高频打印、稳态刷屏 HBT（清理，不删能力）；
- 开环慢扫自动判向（0.04A 力矩克服不了齿槽静摩擦，开环慢扫 mech_delta=-0.0123rad 判失败；改为**手动旋转判向**，不上电、只读 MT6701 角位移符号，上板实测手转 0.3302rad(18.9°) 超过阈值 0.30rad 即判 direction=+1，更省更可靠——这也是"小力矩信号不足、用人的感知直接绕开"的一例）。

### 9.2 与信号尺度无关、必须保留的真工程能力
- **ISR 计算重构**（Q15 三角表、fdiv→乘倒数、启动顺序、DMA 优先级、栈扩容）：解决无 FPU 算力超预算，大信号照样需要；
- **全部保护逻辑**：矢量限幅、过流钳位、valid/saturated 标志、撞轨检测、安全失能——这些是安全底线，任何时候都不能为"简单"删掉；
- 零偏上电校准、MAD 稳健统计、拍均值/滑窗机制本身：是合理的信号链基础设施，只是窗宽/门限随尺度整定；
- S2/S3 失败回退标称值而非硬停机：流程皮实，辨识不可用时安全降级。

### 9.3 被正确否决、不再回头的方案
- 静止直接上 10V/满电压（纯电阻 2.9A 烧绕组）；
- 继续靠放宽判据/加卡尔曼救小信号；
- 用 PI 补偿环外零偏门禁噪声；
- 全自动开环慢扫判向（力矩不足，已由手动方案替代）。

## 10. 上板双轮验证：方法论的实测闭环（2026-09-11）

强信号干净版做了两轮**独立上电**（各自重新校零、从头走完整序列）。检验"是否真逃出小信号陷阱"的最终标准不是某一轮好看，而是**复现性**——小信号期同一台机器时好时坏（quality OK/NOISY 横跳、相序全 0、R 测出 0.49Ω 离谱值），工程窗口内两轮必须高度一致。

### 10.1 双轮结果对照

| 环节 | 第 1 轮 | 第 2 轮 | 复现性 / 结论 |
| --- | --- | --- | --- |

### 10.2 四条结论

1. **强信号的核心收益是"可复现"，不只是"数值大"。** 除 S3 外所有量两轮偏差都在个位数百分比，且符号、相序选择、方向这些离散结论完全一致。小信号期的本质毛病是结果被噪声掷骰子，工程窗口把随机性压到了判据之下——这才是"压噪"二字的准确含义。
2. **Voff≈0 定量坐实了固定损耗被越过。** 两轮三档 V-I 拟合截距 0.061V/-0.0002V，直线过原点；而小信号区反推固定压降 0.15~0.35V。硬件没变，是激励尺度让同一固定量从"主导"变"零头"（与 §6.2 互证）。
3. **S3 是"大信号不是万能"最硬的实测反例。** 0.1→0.5A 已是大信号，两轮 L 却跳到 0.79/1.31mH（差 65%）、IQR 都>1。根因是 τ≈0.24ms 对 10kHz(0.1ms/拍) 的时间分辨率不足（上升沿仅 2~3 拍，见 §6.3），属于方法/采样率维度，加电流无效。固件如实回退标称 0.86mH（两轮估计恰围绕标称），**没有为了"让 S3 也通过"而放宽 iqr 判据**——这正是 §8 方法论第 5 条"判据不迁就"的体现。
4. **"干净强信号 + 人在环"路线端到端成立。** 自动开环慢扫在 0.04A 力矩下转不动（-0.0123rad 失败），改成不上电、人手转 18.9° 即稳定判出 +1；随后 S5 以 0.30A 对齐得到圆周标准差 0.65°、正反差 1.30° 的高质量零位。去全自动化不是退而求其次，而是用最可靠的物理动作替掉最弱的小力矩环节。

### 10.3 零偏的三轮漂移：为什么必须每次上电重校

U/V zero 依次为 804/1450（09-10 早些）→ 858/1507（轮1）→ 842/1466（轮2），U 相批间最大漂 54code、V 相 57code（约 87/92mA）。漂移量不小，但**每次上电用本次 128 点校零后，运行时单点 [ADC] 残差仅 3~7code**。结论：零偏是随温度/上电状态慢变的量，既不能写死、也不必追求它绝对稳定——把"每次重校"做扎实，运行基准就是干净的。这与"靠运行期算法追零漂"的小信号思路形成对照。
