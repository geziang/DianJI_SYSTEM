## 0. 结论速览（TL;DR）

1. **第一个故障（已解决）**：发 `p` 进 S1 后串口卡死。用插桩定位到——20kHz 快路径中断里跑软浮点 FOC，在无 FPU 的 M3 上占满 CPU，主循环（串口/命令/状态机）被"饿死"。
2. **降载三改后已验证解决**：sin/cos 同角度只算一次、电流环 20kHz→10kHz、关闭 DMA 半传输空中断。降载后主循环恢复，`enter` 计数每 100ms 约 +1005，**自证电流环真实频率 = 10kHz**，样本全有效。
3. **第二个故障（进行中）**：算力解放后暴露出真问题——电流环不收敛：目标 Id=0.04A，实测 Id 在 0.14~0.19A 抖动、电机鸣叫、SETTLE 超时。已排除"PI 太猛"，**高度锁定为电流反馈极性未知却先闭环导致的正反馈**，根因是 S1"先闭环、后判符号"的顺序倒置。下一步用扩展探针（iq/vd/vq/du/dv）做事实确认。

## 3. 阶段一：卡死现象与插桩方案

### 3.1 现象
S0 通过、停在 `[SAFE] p=confirm`，发 `p` 后打印走到 `[ACTION] S1 ...` 与 `[POWER] enabled...` 的开头 **`[P` 就停住**，无 `[RESULT]`、无 `[FAULT]`。

### 3.2 四种候选假设
1. 使能序列某子调用死等/崩溃；
2. 20kHz 无 FPU 软浮点 FOC 占满 CPU，主循环被饿死（与 `[P` 现象最吻合）；
3. TIM3/ADC/DMA 触发链没产生快路径；
4. HardFault（原 `HardFault_Handler` 静默 `while(1)`，表现为莫名卡死）。

### 3.3 插桩方法学（三类探针，临时、不改控制逻辑）
- **顺序里程碑（breadcrumb）**：`control_loop_start_power()` 每个子调用返回后打一行
  `sp:enter → cfg ok → sync ok → rt ok → drv ok → target set → [POWER] → sp:done`，用"最后出现的标记"定位执行流断在哪两个子步之间。
- **ISR 计数器 + 主循环心跳**：快路径在 DMA 中断里，**中断内绝不能 printf**（一行毫秒级，会直接砸烂 50µs 实时性）。改为 ISR 内只对 `volatile` 计数器 `++`（纳秒级）：`enter`（进入快路径次数）、`bad`（坏样本）、`flt`（故障次数）、`lf`（最后故障码）；主循环每 100ms 汇总打一行 `[DBG] poll ...`。
- **异常兜底**：`HardFault_Handler` 绕过 HAL，直接轮询 USART1 寄存器（SR@0x40013800 的 TXE=bit7、DR@+0x04）逐字节吐出 `[DBG] HARDFAULT`，把静默死循环变成可见报错。

> 可复用原则：调"卡死"要同时回答三问——走到哪（里程碑）、并发单元还在不在动（计数器/心跳）、有没有异常（fault trap）；并区分"没跑 / 跑太慢被占满 / 跑了但数据错 / 直接崩"四种故障。

### 3.4 第一轮探针结果：卡在 `[D`
```
[DBG] sp:enter → cfg ok → sync ok → [D
```
`sp:rt ok` 只打出 `[D`。该日志在 `foc_runtime_start()` **返回之后**才打印；能打出 `[D` 说明 PWM 已启动、`state=RUNNING`——**从此刻起 20kHz 中断不再 return、开始每 50µs 跑完整 FOC，主循环随即连一行都发不完**。无 HARDFAULT。问题精确锁定在"FOC 真正开跑的运行负载"，而非使能序列。

## 4. 阶段二：负载分析（用代码事实，不猜）

### 4.1 周期预算
72MHz 下：20kHz = 每周期 **3600 cycles / 50µs**；10kHz = 7200 / 100µs；8kHz = 9000 / 125µs。

### 4.2 单次 FOC 的运算量
- `foc_transform.c`：Park 一次 `sinf+cosf`、反 Park 又一次（**同一电角度重复算**），共 4 次超越函数；
- `foc_controller.c`：每次 1 次 `sqrtf`（电压矢量限幅），其余全软浮点乘除；
- M3 无 FPU，软浮点 `sinf/cosf` 每次数百 cycles，单次 FOC 足以逼近甚至超过 3600 cycles → 中断占满、主循环饿死。
- 工程优化等级 `<Optim>4`（**非 -O0，已开优化**），故不是"忘开优化"，是**绝对计算量**问题。

### 4.3 排除"配置级中断风暴"（第 4 层核对）
| 检查项 | 实际配置 | 结论 |
| --- | --- | --- |
| ADC 连续转换 | `ContinuousConvMode=DISABLE`，由 TIM3 TRGO 触发、扫描 2 通道 | 无连续转换风暴 |
| TIM3 触发 | PSC=0、ARR=3599、TRGO=UPDATE，72e6/3600=20kHz 整齐 | 频率正确 |
| DMA | `DMA_CIRCULAR`、halfword、长度 2、高优先级 | 正常 |
| 回调 | 只实现 `ConvCpltCallback`(TC) 跑 FOC | — |
| **隐藏开销** | HAL 的 `HAL_ADC_Start_DMA` 默认同时使能 **TC + HT（半传输）**；长度 2 时每周期 HT 空跑一次 | DMA 中断实际 40kHz、一半空转，可关 |

## 5. 阶段三：降载三改（已实现并编译 0E/0W）

| # | 改动 | 文件/位置 | 内容 |
| --- | --- | --- | --- |
| 1 | **sin/cos 只算一次** | `foc_transform.*`、`foc_controller.c` | 新增 `foc_sin_cos` / `foc_park_transform_sc` / `foc_inverse_park_transform_sc`；快路径同角度算一次 s/c 供 Park 与反 Park 复用，4 次 trig→2 次；旧接口保留转调，数学完全等价 |
| 2 | **20kHz→10kHz** | `board_config.h`、`main.c`(TIM2/TIM3)、`foc_params.c` | 频率单一源宏改 10000，ARR 由频率自动推导 =7199；TIM2(PWM 载波)、TIM3(ADC 触发=电流环真实频率) Period 同步 7199；补掉 `foc_params.c` 漏网硬编码 3599；PI 的 Ts 经宏自动变 100µs |
| 3 | **关 DMA HT 空中断** | `motor_adc.c` `motor_adc_start_dma` | `HAL_ADC_Start_DMA` 后 `__HAL_DMA_DISABLE_IT(adc->DMA_Handle, DMA_IT_HT)`，DMA 中断 40kHz→20kHz(=电流环频率)，对零偏软件触发路径无害 |

明确**未做**（控制范围）：GPIO/DWT 测时、S1 锁角三角短路、去 sqrtf、-Otime/查表/定点化；`[DBG]` 探针保留用于继续验证。

> 关键认知：**电流环真实频率由 TIM3 触发 ADC 决定，TIM2 只是 PWM 载波，两者必须一起改**；SVPWM 周期上限、PI 的 Ts 都要随单一源联动，否则占空比尺度会错。

## 7. 阶段五：暴露真问题——电流环不收敛（进行中）

### 7.1 现象
`ph=2`（SETTLE）始终进不了 COLLECT，约 2s 后 `[FAULT] S1 current did not converge in time`；目标 Id=0.04A，实测 `id` 在 **0.14~0.19A 之间无规则抖动（中心约 0.16，为目标 4 倍且不下降）**，电机发出鸣叫。

### 7.2 排除"PI 太猛"
`foc_identification_derive_current_pi` 零极点对消，Tc=10ms：
- Kp = L/Tc = 0.00086/0.01 = **0.086 V/A**
- Ki = R/Tc = 2.3/0.01 = **230 V/(A·s)**
- 积分/输出限幅 ±0.5V；闭环带宽约 1/Tc≈100rad/s（约 16Hz），属**温和偏慢**，不可能振荡到 4 倍。

### 7.3 锁定正反馈 / 极性问题（推断，待实验终判）
带积分的 PI，只要 `实测 Id>目标`，误差恒负、积分必持续把 Vd 往负推，**理论上一定把实测拉回 0.04**。它停在 0.16 不降反振，唯一自洽解释：**Vd 往"减小"方向调、电流反而增大 = 环路某处极性反，构成正反馈**，积分走到 ±0.5V 饱和并极限振荡（鸣叫）。

代码顺序硬伤（`control_loop_prepare_test_parameters`）：
```
/* S1 未跑前符号用安全默认 +1，S1 通过后覆写 */
phase_a_sign = +1; phase_b_sign = +1;
```
**S1 的职责本就是确定 sign，却先用未验证的 +1 做电流闭环、再想在 COLLECT 判符号；符号若反，SETTLE 就正反馈发散，永远到不了 COLLECT——循环论证 / 顺序倒置。** 正解：先**开环固定小电压**在 raw 层判符号，符号写对后再做电流闭环。

> 附注：测量增益（候选 0.5V/A 未标定）只影响"真实物理电流大小"，带积分时**软件测量值仍应收敛到目标**，故增益未标定不是"测量值停在 0.16"的主因；但真实电流可能大于软件值，实验须严格限流、缩短通电。

### 7.4 关键换算（便于读探针）
- 1 raw code = 3.3V/4096 /(0.01Ω×50) = **1.611mA**；
- 目标 0.04A ≈ 24.8 code；实测 id≈0.16A ≈ **99 code**；
- θe=0 时 Park：Id≈Ia、Iq≈0（Iq 异常大说明相序/通道也可能错）。

## 10. 经验沉淀（可迁移）

1. 实时系统"卡死"先三问：执行流到哪（里程碑）、并发单元是否还在动（计数/心跳）、有无异常（fault trap）。
2. ISR 内只计数/翻转 IO，**不打印、不阻塞、不做浮点**；重活丢主循环底半部；跨上下文变量加 `volatile`。
3. 用"中断计数器涨速"反证真实中断频率，是验证定时器/触发链最省事的事实来源。
4. 无 FPU 的 M3 跑 FOC：先砍重复超越函数 → 同角 sin/cos 复用/查表 → 去 sqrt → 最后才降开关频率；改频率必须 PWM 载波与 ADC 触发一起改、Ts/周期上限单一源联动。
5. 带积分的环若"误差同号却消不掉"，优先怀疑**极性/正反馈**，而不是增益大小。
6. 标定顺序上，**任何依赖某未知量的闭环，都不能用来获取该未知量**（符号未知就不能先靠符号闭环去测符号）——先开环观测定符号，再闭环。

## 11. 阶段六：S1 两段式重构落地（2026-09-09，已编译待上板）

### 11.1 根因定性
阶段五的不收敛不是 PI 强弱问题，而是**控制层循环论证 / 正反馈**：旧流程在 `prepare` 里把 `phase_a/b_sign` 默认 +1，先用这套**未验证方向**建 Id 电流环，再想在 EVALUATE 判 sign；sign 一旦反了，SETTLE 即正反馈发散，永远到不了判 sign 的环节。早期设计只在*测量层*防循环论证（用 raw 不用 A），漏了*控制层*（建环本身就用了待标定 sign）。

### 11.2 方案：S1a 开环 → S1b 闭环（工业 bring-up "开环不顺不碰闭环"）
- **新增控制器开环电压模式**：`foc_control_mode_t {CURRENT,VOLTAGE}`；VOLTAGE 跳过两个 PI、直接采用给定 Vd/Vq（仍过分量 + 矢量限幅 0.5V，并持续清 PI 积分）。`foc_runtime_set_voltage_target/set_current_target` 切模式，`foc_runtime_start()` 按模式 + 验证标志门禁：**CURRENT 必须 `closed_loop_allowed`，test_mode 不再放行闭环；VOLTAGE 仅 test_mode 放行**。
- **S1a（开环双极性注入，raw 层判）**：θ=0，子时序 零矢量基线50ms → +Vd 3ms 缓升/跳10ms/保持150ms → 衰减15ms → -Vd 对称重复。`calib_sequence_s1a_evaluate` 五判据：激励达门限、正负反向（双极性）、对称度≤0.25、`dv/du=-0.5±0.15`、标准增益下 `R=Vtest/I` 在 0.5~2×2.3Ω。通过才写 sign、置 `direction_verified`。
- **S1b（闭环自证）**：短暂停功率（不在运行中切控制器）→ 以 CURRENT 重启建 Id=0.04A 环，step 引擎判 Id 收敛 + `|Iq|≤0.02A`、无振荡/正反馈，过则 arm S2。
- **标准增益定档**：INA240A2=50V/V（误差≤0.2%）×0.01Ω=0.5V/A 为板级设计常量，零偏 OK 即置 `scale_verified`；`closed_loop_allowed = scale && direction`，`sample_timing`(S4) 不参与首个电流环门禁；外部电流表校降为可选 D2。

### 11.3 起始参数（calib_config，待上板整定）
Vd=±0.09V（≈0.04A×2.3Ω，远低于 0.5V 上限）；时序 50/3/10/150/15ms；MIN_DELTA 40→18raw（0.04A≈24.8code）；对称 0.25；比值 -0.5±0.15；R 窗 0.5~2×；S1b Id=0.04A/band0.01/|Iq|≤0.02。1raw≈1.612mA。

### 12.2 根因（用标度链事实，不猜）
- 软件标度无错：SVPWM `duty=0.5+(phase-common)/bus`，0.09V→A 相 duty=0.51125、偏中点 81 ticks=1.125µs，伏秒平衡正确。
- 死区非主因：FD6287T 固定死区仅 100~300ns，10kHz/6V 下伏秒损失仅 6~18mV。
- 真因①信噪比崩：理论 0.09/2.3=39mA≈24code，但实测 |du| 仅 7~13code（≈16.8mA），而零偏 p2p 噪声本身就有 24~45code，信号比噪声带还小；旧 MIN_DELTA=18 小于噪声 p2p 本就不合理（禁止降门限凑通过）。
- 真因②反推等效 R≈0.09/16.8mA≈5.37Ω（标称 2.3 的 2.3 倍），可能电机实际 R 偏大或增益/shunt 偏差——正是 S1a 该摸出但固定小电压判不了的。

### 12.3 爬坡终点电压 VEND 的推导（对通用公式的项目化修正）
通用思想 `Vend=min(电流,功率,ADC,放大器摆幅)×裕量` 正确，但需两点修正：①电流/功率属电机注入层、ADC/摆幅属采样层，必须先把采样量经 shunt 换电流再乘电机 R 换算回注入电压，不能直接 min；②功率项是 `V=√(P·R)` 不是 `P·R`。逐项套本项目（Rmin=2.3Ω）：

| 限制 | 换算到注入电压 | 是否 binding |
| --- | --- | --- |
| 电流·软件 0.10A | 0.23V | 正常锁定主约束（目标带） |
| 电流·硬件限流 0.15A | 0.345V | **VEND 取它** |
| 堵转功率（0.1A 仅 0.023W；Pmax=1W→√PR） | 1.52V | 否 |
| ADC 满幅 6.6A / 非对称负向余量 1.19A | 2.74V | 否 |
| INA240 摆幅（近似轨到轨） | ≈2.7V | 否 |
| 软件矢量限幅 | 0.50V | 硬钳 |
| 母线线性调制 6/√3 | 3.46V | 否 |

结论：本项目只有"电流"和 0.5V 软件限幅 binding。**核心设计：爬坡以实测 raw（电流）为主闸门（进目标带即停），VEND 只是"采样反馈失效时开环也不过流"的兜底**，`VEND=min(0.15×2.3,0.50)×0.9≈0.31V`。R 未知时单一固定 Vend 无法同时保证"小 R 不过流、大 R 够激励"，故必须电流闭环找点、Vend 兜底。

### 12.9 静态三角度相序/符号探针 PROBE3（2026-09-09，电流对齐主路径）
**为什么不用单点 HOLD 直接定**：10V HOLD 在 θ=0 单点实测 ΔU=+74、ΔV=+170（同号、V≈2.3U），而 θ=0 纯 d 轴期望 ΔU:ΔV=1:−0.5；单点投影存在歧义，无法唯一归因是符号反还是通道交叉。电路原理：半桥 j 支路电流=(Vj−Vn)/R 只由 SVPWM 输出电压决定、与电机三相线排列无关，故**静态（电机不转、只看半桥1/2 电流）只能定两个采样符号与通道对应，定不了电机旋转线序/编码器方向**（后者归批次 B 的 S5/S6）。

**理论签名（s1=s2=+1，独大幅值 I）**：θ=0°→(U,V)=(+I,−I/2)；120°→(−I/2,+I)；240°→(−I/2,−I/2)，第三相 −(U+V) 在 240° 独大。

**实现（Keil AC5 0E/0W，Code=42940、ZI=5660）**：
- `calib_config.h`：`CALIB_S1A_PROBE3=1`（主路径）、`MANUAL_HOLD=0`；P3 电压 0.15V、基线40/建立10/采集40/衰减15ms、比值容差0.15、等幅容差0.20、复用 MIN_USABLE=30code。
- 纯函数 `calib_sequence_s1_probe3(du3,dv3,&out)`（零 HAL）：找各通道 |偏移| 独大落角（期望 U 在0、V 在1=120°）→ 符号取独大值符号 → 两个非独大/独大比值均≈−0.5 → 第三相 −(U+V) 独大在240° → U/V 等幅且独大≥30code；输出四 ok 位与 `fail_mask`（bit0 激励弱 / bit1 通道交叉 / bit2 不对称 / bit3 第三相 / bit4 幅值不一致），**全过才返回可绑定**。PC 单测加 5 个解析解用例（正常++/双反--/通道交叉/弱信号/不对称）。
- `control_loop.c`：S1a 子状态加 `P3_BASELINE/INJECT/DECAY/EVAL/DONE`，发一次 `p` 自动跑完三角度（约0.3s，电机锁定不转，换角瞬间可能轻跳≈机械17°属正常）；EVAL 通过才写 `phase_a/b_sign`、`s1_sign`、`motor_adc_set_direction_verified(1)`，随即 finish_power 断电、arm、停在 `P3_DONE`，**再按一次 p 才以 CURRENT 进 S1b 闭环自证**（不自动连跑，人工确认一次）；任一判据失败 enter_fault 且**不绑定**，按 fail_mask 打印对位原因。

**上板判读（10V、CC=0.15A、空载）**：S0 PASS→`p`，看三行 `[P3] ang= dU= dV=` 是否符合理论签名，再看 `[PROBE3] peakU/peakV/sign/ratio/amp/mask/ok`。基于 HOLD 单点，**首次有可能 NOGO**（现状相序/符号不自洽），这是诚实暴露而非 bug：mask bit1=U/V 采样通道交叉（查 CS 走线/焊接，硬件问题）；bit0=激励弱（查供电/接触/栅驱或略加 P3 电压）；bit2/4=三相接触/增益不一致。`ok=1 bind` 后再 `p` 进 S1b。

**首次上板（0.15V）结果与二次整定**：三角度净偏移最大仅 18code≈29mA（理论 0.15/2.3=65mA=40code 的 45%），全 <30 门限判 weak（mask=0x01）；方向上 ang0-U 负、ang1-V 负两次一致，已呈 s−− 雏形但太弱。对照发现关键事实：HOLD 的"大电流"是相对**未使能零偏**，混入了"使能零矢量跳变 + 零偏慢漂移"（两次开机 zero-U 839→987 漂 148code≈239mA，比信号还大），PROBE3 就近减"通电零矢量基线"剥掉该假象后才是净电流——方法正确，是小电压被死区/管压降压到 45%。二次整定：注入电压 0.15→**0.30V**（CC=0.15A×2.3=0.345V 顶死电源限流会导致母线塌陷，故取不触发 CC 的最大可用值 0.30V≈130mA≈81code）、SETTLE 10→20ms、COLLECT 40→80ms，并把每角度打印扩成 `zero(未使能)/base(通电零矢量)/inj(注入均值)/d(净偏移)` 四值对照以实证使能跳变；门限 30 不降。0E/0W，Code=43048、ZI=5660。

### 12.10 0.30V 二次上板：S1a 定性成功（sign=−1/−1、通道正确）与"判据分层"决策（2026-09-09）
**原始四值对照（zero=未使能零偏 875/1572）**：

| 电角度 | base(通电零矢量) | inj(0.30V 均值) | d=inj−base（净偏移 code） |
| --- | --- | --- | --- |
| 0° | 883.1 / 1594.7 | 831.8 / 1614.3 | **dU=−51.3（U 独大）**、dV=+19.7 |
| 120° | 876.3 / 1596.6 | 899.2 / 1552.9 | dU=+22.9、**dV=−43.6（V 独大）** |
| 240° | 883.0 / 1601.8 | 900.2 / 1611.0 | dU=+17.2、dV=+9.2（双半幅，偏小） |

固件输出 `peakU=0 peakV=1 sign=-1/-1 ratio=-0.361 amp=47.5 mask=0x0C ok=0`。

**逐项对账（calculator 复核，与打印一致）**：
- *硬门（定性，全过）*：① 通道落角 peakU=0°/peakV=120° → U↔半桥1、V↔半桥2 **无交叉**（无 bit1）；② 独大 51.3/43.6 code（≈83/70mA）均 >30 噪声门，**不弱**（无 bit0）；③ U/V 独大差 |51.3−43.6|/47.5=**16.2%<20%**，两通道增益一致（无 bit4）。
- *软门（定量，失败但不影响定性）*：四个非独大/独大比值 = −0.446 / −0.335 / −0.211 / −0.452，均值 −0.361；0°、120° 主方向的 −0.446/−0.452 已很接近 −0.5，唯独 240°（两相都只有半幅、电流最小）的 −0.335/−0.211 出 ±0.15 带 → bit2；第三相重构 Iw=−(U+V)=+31.6/+20.7/−26.4，独大本应在 240°(26.4) 被 0°(31.6) 抢走 → bit3。
- *机理（非接错线）*：误差严格只出现在电流最小的双半幅点——死区/管压降在小电流下占比更大，半幅相被多压；第三相由两相测量相加重构、误差叠加，本就最不稳。若接错，落角/符号会乱，不会恰好只在最小信号处偏差。
- *使能跳变实证*：base−zero 在 U 相 +1~8 code、**V 相 +23~30 code**，坐实 12.8 的推断——HOLD 用未使能零偏当零点，给 V 相凭空多算约 25 code，是 HOLD 数值虚高/波动的来源；PROBE3 就近减"通电零矢量基线"正确。

**结论：S1a 电流对齐定性成功，应绑定 `sign_u=sign_v=−1`（两相采样整体反接）、通道对应正确。** 当前固件旧判据把对称性/第三相当硬门，故仍打印 `ok=0 NOGO`——属判据过严，非测量失败；`p3_bound` 未置位、S1b 进不去。

**决策（低端硬件、接线粗糙，不陷入精度陷阱，但不降硬门数字）**：判据分两层——
- *硬门（不过绝不绑定，挡真错误）*：通道落角 + 非弱 + U/V 等幅；
- *软门（降级为质量警告、不阻断，仍填 fail_mask 可追溯）*：精确 −0.5 对称性、第三相重构落角；`RATIO_TOL=0.15` 等数值**不下调**（不做"放宽数字凑通过"）。
**已落地（2026-09-09，Keil AC5 0E/0W，Code=43324、ZI=5660）**：`calib_probe3_result_t` 增 `hard_mask`，`ok=(hard_mask==0)` 只看方向硬门（通道落角/非弱/U/V等幅），对称度与第三相降为软门（只填 `fail_mask` bit2/bit3）；EVAL 打印改为方向行 `[P3] DIR ... -> BINDABLE/NOT-BOUND`，硬门失败才 `[FAULT] NOT bound`，硬门过但有软瑕疵时打 `[P3Q] soft-warn ... recorded not blocking sign` 并仍绑定，RESULT 区分 `(clean)` 与 `(direction OK, soft precision warn)`；S1b 结果行补 target/err 稳态静差。PC 单测同步：不对称用例改为"硬门过→ok=1、symmetry_ok=0 仍可绑"，通道交叉/弱信号用例验证仍被硬门拦截（不放水）。按 12.10 数据，重烧后预期 `[P3] DIR ... sign=-1/-1 hard=0x00 -> BINDABLE`、`[P3Q] soft=0x0C`、`[RESULT] sign=-1/-1 bound`，再按 p 进 S1b。

**下一步**：① 落地判据分层并重烧，PROBE3 应 `ok=1 sign=-1/-1 bound` 自动断电；② **下一个上板断点 S1b 闭环自证**——用绑对的 sign 建 Id=0.04A 小电流环，要求 Id 平稳收敛、Iq≈0、不再鸣叫/振荡（对比早期默认 sign 闭环鸣叫）；③ S1b 过后 S2 测 R / S3 测 L / S4 验 PI 成组开发再一次上板，S2 三档最小二乘顺带拟合死区等效 Voff（定量解释本节半幅偏小）；④ 电机旋转线序、编码器方向仍归批次 B，本步不管。

### 12.11 实验方法论：强信号压噪优先、警惕"精度陷阱"（0.15V→0.30V 的决策与感悟，2026-09-09）
**过程事实（时间线续）**：0.15V 首次 PROBE3 净偏移最大仅 ~18code，被零偏噪声带（p2p≈25~30code）淹没，三角度签名出不来、判 weak。当时没有去抠滤波、平均、降门限，而是直接把注入电压拉到**不触发电源 CC=0.15A 的理论最大 0.30V**（0.15A×2.3Ω=0.345V 正好顶死限流、会让母线恒流塌陷、SVPWM 失真，故停在 0.30V≈130mA）。上板独大立刻升到 47.5code（≈83/70mA），方向/通道/符号一次干净解出。**结论：信号幅度先于信号处理——强信号本身就是最有效的抗噪，与其在弱信号里做复杂处理，不如先把信号抬出噪声带。**

**两条研发感悟（本项目亲历，沉淀为准则）：**

1. **低端硬件不要陷入"精度陷阱"，目标大概率达成就适可而止、先转起来。**
   本项目接线粗糙、用的是低成本硬件，物理上就不具备高精度条件。S1a 的本质是**方向问题**（采样符号、通道对应，都是"独大落在哪个角度、符号是正是负"的离散量），不是精确测量；当 0°/120° 主方向的落角、符号、主比值都已正确，就不该为 240° 那个 −0.361 与理想 −0.5 的偏差反复栽进去。精度陷阱最容易耗死人：硬件到不了的精度，软件再怎么补偿也是在追噪声。正确做法是**定性步骤用离散、鲁棒的判据，达到大概率正确就往下走（先让电机转起来），把精确量（死区 Voff、精确 R/L、对称度）交给后续 S2/S3 的多档拟合去定量处理**，而不是在定方向阶段死磕小数。

2. **做实验/研发不是做产品：安全兜底到位，就把信号推到极限，别唯唯诺诺。**
   实验台阶段要尽量保证硬件工作在高功率/强信号状态——这次正是发现"电流被噪声淹没"，就直接把注入拉到极限去试，只要不坏，先做出一套能跑的链路。如果一直不敢上电流、在微弱信号里反复测，信号永远埋在噪声里，问题也永远定位不了，时间全耗在似是而非的数据上。**"只要不坏"的边界必须先划清楚并靠硬件兜底**：本项目的红线是母线 ≤10V、电源 CC=0.15A 硬限流、电机空载、随时可按 `x` 急停；在这四条之内可以大胆加压加流做判决性实验。同时记住这些是**实验台激进参数，产品化时必须收回**（额定工况、保护裕量、EMC/温升都要重做），不能把研发期的"拉满"直接带进产品。

**与既有方法论的关系**：这两条与 §12.10 的"定性硬门/定量软门"判据分层、以及复盘文档"讨论十次不如动手一次"是同一条主线——**安全兜底做足就大胆实验，用强信号和事实快速裁决；定性求对、定量求准，不在定性阶段追精度。**

**续：0.30V→0.50V 再强信号（2026-09-09 晚）**：判据分层落地后首次上板，方向形态仍正确（U 独大@0、V 独大@1、s−−），但 V 独大只有 24.9code（U=46.5），低于 weak 硬门 30，被诚实拦下（`hard=0x01`，amp/sign 因提前返回显示 0 属设计）。由 0.30V 实测反推等效阻抗 **U≈4.0Ω、V≈7.5Ω**（V 相明显偏大，疑似该相接触/绕组，记录待物理排查；两相同步降幅不一致也排除了"统一母线偏低"）。按"强信号压噪、拉到不坏的极限"原则，注入电压 0.30→**0.50V**，并把测试电压上限 `TEST_MAX_VOLTAGE_V` 0.50→**0.55V** 给命令留 10% 裕量（开环有分量 clamp + 矢量限幅两道，顶格会被削）。按实测等效阻抗预计 0.50V→U≈125mA/78code、V≈67mA/41code，均 <CC=0.15A 不顶限流（理论 R=2.3 口径 217mA 由 CC 硬兜）；weak 硬门 30 不降。0E/0W，Code=43332。注意 V 即便 0.50V 也仅 ~41code、裕量偏薄，若仍在门限附近飘即为 V 相物理问题，不再从软件找补。
