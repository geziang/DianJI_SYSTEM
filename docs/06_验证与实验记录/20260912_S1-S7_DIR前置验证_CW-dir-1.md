## 5. 结果与判定（分步判，不写总括通过）

| 判据 | 实测 | 阈值/预期 | 通过? |
| --- | --- | --- | --- |
| 步骤顺序 | DIR 在 PHASE_SEQ 前 | 方案 A 顺序 | 是 |
| DIR 无联动镜像打印 | 仅 "in RAM updated" | 旧 "direction flipped ... mirror" 应消失 | 是 |
| 物理 CW → dir | −1（−0.3179 rad） | e=−1 时应为 −1 | 是 |
| verify 终态相序 | perm5（best4 经一次镜像） | 与 dir=−1 功能自洽（m·dir=−1=e；≡ CCW 轮 perm4/dir+1 镜像等价对） | 是 |
| S5 零位 | 1.324209，std 0.0054，fr 0.0107 | std≤0.05、fr≤0.08 | 是 |
| 电机实际转动 | 是（用户直接观察，转向跟随手转正方向） | 应转动 | 是 |
| S7 电流收敛 | id 均值≈0.31（目标0.10）、iq −0.119~+0.066（目标0.18） | id≈0.10、iq≈0.18 | **否** |
| S7 dyn_R | 9.0172Ω（2.36×base） | [1.908,5.724] | **否（软拒绝，无失控）** |

- **结论**：S0–S5 + 方向/相序链**通过**；S7 **未通过**（dyn_R 超窗被拒），但全程无鸣叫、无复位、电机可转动。
- 输出参数（RAM only，this boot）：encoder_direction=−1、phase_map=perm5(a->2,b->1,c->0)、encoder_offset=1.324209 rad、R=3.8159Ω（trusted）、L 回退标称 0.86mH。

## 6. 问题与下一步

- S7 异常形态：电流幅值正确（vq/R≈0.34A 与实测 0.31A 同量级）但几乎全落在测量 d 轴、iq≈0，dyn_R 超标是 iq≈0 的派生结果；挂为 L4「dq 固定偏转嫌疑」，详见复盘 §5（L4 挂账），不在本记录下结论。
- 与 CCW 轮（dir+1/perm4/offset4.920627）物理等价（镜像+反号+offset 互补，残差 0.038rad），证明方案 A 后结果不依赖手转方向。
- 下一步：L4 判决实验（两轴分别开环加小电压），优先于任何参数固化。
