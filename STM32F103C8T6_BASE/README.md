# 实验室关节电机底层系统（分层基座，v0.5）

> **定位**：实验室统一维护的**分层电机底层系统**——在粗糙实验硬件上开发、验证了功能主体（标定体系 / 参数 Flash 固化 / 电流闭环 FOC-4 已验收 / 速度环代码就绪），**换芯片只动板级与驱动两层，算法与流程层免改**；上位机与上层控制算法（轨迹、位置、多机协同）在本系统之上交叉适配。
> 当前参考实现：STM32F103C8T6 + V3P + 2804 + MT6701（其它芯片=按 §9 适配指南微调）。
> 交接日期 2026-09-14。新人验收标准：**30 分钟内复现 boot → READY → 零流使能 → 速度环旋转**。

## 0. 分层架构（本系统的骨架，适配与上层接入都按层找）

```
┌─ 上层（实验室各项目自带：上位机 / 轨迹规划 / 位置环 / 多机协同）   ← 接入契约见 §10
├─ 流程层  app_run / control_loop        标定序列、运行状态机、安全准入   ┐
├─ 契约层  motor_parameter_core          参数包格式+CRC+五道校验（跨芯片、跨固件的合同）
├─ 算法层  foc_* 数学内核 / calib_* 判据 / speed_estimate  零 HAL 纯函数，可 PC 单测，芯片无关 ┘ 免改
├─ 驱动层  motor_pwm / motor_adc / motor_drv / mt6701 / encoder_cache   HAL 调用封装
└─ 板级层  board_config + CubeMX .ioc    引脚/时钟/定时器映射           ← 换芯片改这两层
```

## 1. 硬件构成与红线

| 项 | 选型 | 说明 |
| --- | --- | --- |
| MCU | STM32F103C8T6 | 72MHz Cortex-M3 **无 FPU**，20KB RAM / 64KB Flash（代码区上限 62KB，末 2KB 为参数双页） |
| 功率级 | DengFOC V3P/V3Pro | 本项目用 M0 通道；栅驱 FD6287T |
| 电机 | 2804 表贴 PMSM | 7 对极，R 实测≈2.8-3.7Ω，L 标称 0.86mH |
| 编码器 | MT6701 | 14bit 磁编码，I2C2（PB10=SCL/PB11=SDA），100kHz（诊断姿态 5ms 轮询，见 §6） |
| 相电流采样 | 两相低边分流 | 0.01Ω + INA240A2(50V/V) = **0.5V/A 已定档（D2，勿再标定）** |
| PWM | TIM2 CH1/2/3 | PA0/PA1/PA2，**ARR=7199，10kHz**；ADC 由 TIM3 TRGO 10kHz 同步触发 |
| 使能 | PA8 `MOTOR_EN` 高有效 | 串口 USART1 PA9/PA10 115200 |

> ⚠️ **强制安全：供电严禁超过 10V（12V 烧驱动板）；上电默认功率失能，一切功率步骤须人工按 `p`。**

## 2. 双 Target 架构（本仓库核心形态）

同一 `.uvprojx` 两个 target，共享源码树与 scatter（**参数页 0x0800F800/FC00 布局是两态合同**）：

| | 测试 target `STM32F103C8T6_BASE` | 运行 target `F103-run` |
| --- | --- | --- |
| 用途 | 标定全序列 + 参数固化 + VJ 诊断 | 读固化包直入运行态 + 速度环 |
| 入口 | app_baseline.c（control_loop S0-S8） | app_run.c（BOOT→READY→ENABLED/EXPERIMENT→FAULT） |
| 预定义 | `...,CALIB_VJ_DIAG_ENABLE=1` | `...,APP_MODE_RUN` |
| 排除文件 | app_run.c（IncludeInBuild=0） | control_loop/calib_*/resistance_learning/app_baseline（7 个） |
| ROM | 62352B（余 1136B） | ~35600B（余 ~28KB） |

参数包（`motor_parameter_core`，Flash 双页 A/B 交替，rev 单调递增）是两态之间**唯一合同**：测试态标定 `a` 固化，运行态 boot `[LOAD]` 直接吃。

## 3. 构建与烧录

- **GUI**：Keil 打开 `MDK-ARM/STM32F103C8T6_BASE.uvprojx`，顶部下拉切 target，F7/LOAD；

## 4. 上板操作速查

**运行固件 F103-run**（先烧这个跑 demo）：

| 命令 | 作用 |
| --- | --- |
| `p` / `x` | 使能（零流保持）/ 停机失能 |
| `s` | 切换 IQ 手动模式 ⇄ 速度模式 |
| `+` / `-`（或 `=`/`_`） | IQ 模式：iq 步进 ±0.05A（限 ±0.5A）；速度模式：n* 步进 ±20rpm（限 ±300rpm，500rpm/s 斜坡） |
| `0` | 目标回零 |
| `1`/`2`、`3`/`4` | 速度环 kp ×/÷1.25、ki ×/÷1.25（初值 0.005 / 0.025，**待整定**） |
| `e` | 编码器 EMI 分段实验（A 驱动静态 / B 50% 开关 / C 零流闭环，各 2s 定凶） |
| `c` | FAULT 态清故障（回 BOOT 重走准入） |
| `i` / `?` | 全量静态诊断明细（boot 只打一行汇总，PASS 静默 / WARN+FAIL 必打） |

正常 boot 序列：banner → `[LOAD] run package (rev=N)` → `RUN_READY`。无包时提示烧测试固件标定。BOOT 具自愈（零偏每 2s 重试×10、编码器 I2C 复活×3，超时明确 FAULT）。

**测试固件**：`r` 重启序列 → 逐步 `p`（S1a→S1b→S2→S3→S4→手转判向→PHASE_SEQ→S5→S7）→ `[NEXT] a=apply` → `a` 写 Flash（rev+1，页交替）。`v` 进 VJ 电压注入诊断（L4 工具）。

## 6. 已知问题（红线级，详见 docs/08_交接文档）

1. **编码器已损坏（2026-09-14 判决）**：拖拽 3.3V 轨致 I2C+ADC 同时劣化——待换 MT6701。教训全史见调试日志经验10；
2. **诊断姿态参数（换编码器验证稳定后收回）**：编码器轮询 5ms（原 1ms）、有效门 50ms（原 20ms）——角度滞后 ~16°@110rad/s elec，速度环品质打折；
3. **实验台硬件脆弱**：杜邦线+转接板，EMI/接触问题高发（编码器全程斗争史）；硬件组建议见 docs/08 §3；
4. **I2C 400kHz 计划已反转**（低速更稳，勿按旧文档升频）；
5. **ROM 余量**：测试 target 仅 1136B——加代码前先量（`_build_cli.cmd`）。

## 7. 交接验收链（新人 30 分钟剧本）

```
换装新 MT6701 → 烧 F103-run.hex → 115200 串口：
  期待：[LOAD] → RUN_READY（无任何 waiting 行）
  p        → 零流保持（id/iq ±0.05A 内，无声无转矩）
  s +++    → 速度环首航：n 爬坡咬住 n*=60rpm（振荡按 2、偏软按 1、有稳差按 3）
  - 越零   → 反向验证
  手捏轴   → 看抗扰（n* 不变 n 回落恢复）
  0 → x   → 收工；FR-4.5 指标回填 SPEC-RUN
```

失败时按固件打印走：BOOT 自愈行/分段实验 `e`/诊断 `i` 会直接点名卡点；方法论见调试日志经验 1-10。

## 9. 新芯片适配指南（换 MCU 只动下两层）

| 步 | 动作 | 工作量特征 |
| --- | --- | --- |
| 1 | CubeMX 新建目标芯片工程（TIM×2：PWM+TRGO 触发 ADC；ADC 两通道+DMA；I2C；USART） | 配置工作，.ioc 为唯一事实源 |
| 2 | `board_config.h/c`：引脚/定时器/时钟/`BOARD_CONFIG_*` 常量与访问器 | 机械搬运 |
| 3 | `motor_*` 驱动层：HAL 调用按新芯片 API 对齐（PWM set_raw / ADC 同步启动 / DRV 使能 / mt6701 I2C 句柄） | 唯一需要动脑的层——**保持接口签名不变**，上层即免改 |
| 4 | 时基：`BOARD_CONFIG_CURRENT_LOOP_PERIOD_S` 等宏按新时钟重算；重编双 target | 一处宏 |
| 5 | 跑测试固件全序列（S0-S7）→ `a` 固化 → 运行固件验收链 | 全链回归，质量门自动把关 |

**免改资产**（算法层+流程层+参数包格式，全部零 HAL 或纯编排）：FOC 内核、S0-S8 判据、速度估计/速度环 PI、R 自学习、安全状态机模式、两态固件架构。参数包含 `hardware_id` 字段——换板自动拒绝加载旧包，防串台。

## 10. 上层接入契约（上位机 / 上层算法怎么接）

| 接入方式 | 契约 | 现状 |
| --- | --- | --- |
| **遥测流** | `[RUN] id=%.3fA iq=%.3fA n=%.0f n*=%.0frpm`（500ms/行）+ 状态行 `[HBT] state=RUN_*` | 已可用，可直接脚本解析画曲线 |
